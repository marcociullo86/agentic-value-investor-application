## Key Metrics, Ratios & Enterprise Value

### Key Metrics & TTM Key Metrics API [Globe Flag]
Evaluate revenue, net income, P/E ratio, etc.
**Parameters:**
- `symbol`* (string), `limit` (number), `period` (string)

### Financial Ratios & TTM Financial Ratios API [Globe Flag]
Detailed profitability, liquidity, and efficiency ratios.
**Parameters:**
- `symbol`* (string), `limit` (number), `period` (string)

### Financial Scores API [Globe Flag]
Altman Z-Score, Piotroski Score, etc.
**Parameters:**
- `symbol`* (string)

### Enterprise Value & TTM Enterprise Value API
Calculate the Enterprise Value of a company.
**Parameters:**
- `symbol`* (string), `limit`, `period`

### Discounted Cash Flow (DCF) API
Get calculated DCF value for a company.
**Parameters:**
- `symbol`* (string)
