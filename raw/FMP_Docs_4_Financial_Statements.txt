## Financial Statements

### Income Statement, Balance Sheet, Cash Flow Statement API [Globe Flag]
Access detailed financial statements.
**Parameters:**
- `symbol`* (string)
- `limit` (number): Max 1000
- `period` (string): Q1, Q2, Q3, Q4, FY, annual, quarter

### Latest Financial Statements API [Globe Flag]
**Parameters:**
- `page` (number), `limit` (number)

### TTM Financial Statements (Income, Balance Sheet, Cashflow) API [Globe Flag]
Trailing Twelve Months financial data.
**Parameters:**
- `symbol`* (string), `limit` (number)
