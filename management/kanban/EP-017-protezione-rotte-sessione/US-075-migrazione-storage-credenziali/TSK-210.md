# TSK-210 — BE OpenAPI: rimuovi refreshToken da response schema

## Context
US-075 migrazione richiede aggiornamento OpenAPI per riflettere la rimozione del refreshToken dal response body.
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-075-migrazione-storage-credenziali/US-075.md §AC]
[^src: design_&_architecture/decisions/ADR-024-session-lifecycle-credential-storage.md §API Changes]

## Technical Specs
- **BE:** Aggiornamento springdoc-openapi annotations
- **Endpoint login:** response schema senza campo `refreshToken`
- **Endpoint refresh:** response schema senza campo `refreshToken`
- **Documentare:** Set-Cookie header nella response description

## Implementation Steps
1. Rimuovere campo `refreshToken` dal DTO response di login
2. Rimuovere campo `refreshToken` dal DTO response di refresh
3. Aggiungere documentation del Set-Cookie header nelle OpenAPI annotations
4. Verificare OpenAPI spec generata
