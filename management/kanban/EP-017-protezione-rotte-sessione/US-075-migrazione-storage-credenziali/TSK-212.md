# TSK-212 — QA Test migrazione storage: localStorage, cookie, rehydration, revoca

## Context
US-075 AC richiede verifica completa: nessun token in localStorage, cookie httpOnly, access <= 15min, rehydration F5, riuso token → revoca.
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-075-migrazione-storage-credenziali/US-075.md §AC]

## Technical Specs
- **QA:** Playwright + JUnit 5 Integration
- **Scenari:**
  - Nessun token/credenziale in localStorage (audit DevTools simulato)
  - Cookie refresh_token: httpOnly, Secure, SameSite=Strict (verificato via response headers)
  - Access token durata <= 15 minuti (verificato nel payload JWT)
  - F5 su rotta protetta da utente autenticato → pagina carica senza passare per /login
  - Riuso refresh token già ruotato → revoca tutti i refresh token dell'utente

## Implementation Steps
1. Test localStorage: dopo login, verifica assenza token
2. Test cookie: verifica Set-Cookie headers (HttpOnly, Secure, SameSite)
3. Test JWT: decode access token, verifica exp <= 15min
4. Test rehydration: Playwright F5 su /watchlist autenticato → no redirect
5. Test riuso: simula riuso token ruotato → verifica revoca

## Definition of Done
- [ ] localStorage vuoto post-login
- [ ] Cookie attributes verificati
- [ ] Access token <= 15min
- [ ] Rehydration F5 funzionante
- [ ] Riuso → revoca verificato
- [ ] Code review approvata

## Dependencies
- TSK-209 (BE cookie-based)
- TSK-211 (FE rehydration)
