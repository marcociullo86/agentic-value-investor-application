# TSK-218 — QA Test E2E logout: revoca, cookie, store, back button, resilienza

## Context
US-078 AC richiede verifica completa del flusso logout.
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-078-flusso-logout-completo/US-078.md §AC]

## Technical Specs
- **QA:** Playwright + Vitest
- **Scenari:**
  - Post-logout: refresh token revocato BE (riuso → errore)
  - Post-logout: nessun cookie di sessione nel browser
  - Post-logout: store auth vuoto (stato non autenticato)
  - Post-logout: back button → /login (non rientra in area protetta)
  - Revoca fallita (simulato backend offline) → logout locale procede (pulizia + redirect)
  - E2E: login → nav in area protetta → logout → back → verifica /login

## Implementation Steps
1. Test revoca: post-logout, tentativo riuso token → errore
2. Test cookie: verificare assenza cookie sessione
3. Test store: verificare stato non autenticato
4. Test back button: Playwright back() → verifica URL /login
5. Test resilienza: mock revoca 500 → logout locale comunque
6. Test E2E completo: login → nav → logout → back → /login

## Definition of Done
- [ ] Revoca verificata
- [ ] Cookie assente
- [ ] Store vuoto
- [ ] Back button bloccato
- [ ] Resilienza confermata
- [ ] Code review approvata
