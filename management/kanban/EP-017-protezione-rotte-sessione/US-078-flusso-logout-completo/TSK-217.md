# TSK-217 — FE useLogout hook: revoca + pulizia + blocco history

## Context
US-078 richiede un flusso logout completo con sequenza: revoca BE, cancellazione cookie, pulizia store, pulizia SWR cache, blocco back button.
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-078-flusso-logout-completo/US-078.md §AC]
[^src: design_&_architecture/decisions/ADR-024-session-lifecycle-credential-storage.md §6]

## Technical Specs
- **FE:** `hooks/use-logout.ts`
- **Sequenza logout:**
  1. POST /api/auth/logout (revoca refresh token BE). Se fallisce: log errore, prosegui
  2. Cookie cancellato server-side (Max-Age=0 nella response)
  3. Zustand store auth: clear (access token, user data)
  4. SWR cache: `mutate(() => true, undefined, { revalidate: false })` (pulizia globale)
  5. `history.replaceState` + `router.push('/login')` (blocco back button)
- **Resilienza:** logout locale procede anche se POST revoca fallisce

## Implementation Steps
1. Creare hook useLogout
2. Implementare chiamata POST /api/auth/logout con error handling
3. Implementare pulizia Zustand store
4. Implementare pulizia SWR cache
5. Implementare history.replaceState + redirect
6. Verificare resilienza: revoca fallita → logout locale comunque

## Definition of Done
- [ ] Revoca BE chiamata
- [ ] Store auth vuoto post-logout
- [ ] SWR cache pulita
- [ ] Back button → /login (non rientra in area protetta)
- [ ] Resilienza: logout procede anche se revoca fallisce
