# TSK-267 — FE Applicazione guard alle rotte protette e returnUrl

## Context
Dopo l'estrazione del guard client-side, ADR-026 richiede l'applicazione effettiva sulle pagine/layout protetti in produzione static export, mantenendo returnUrl e gestione sessione scaduta.
[^src: design_&_architecture/decisions/ADR-026-frontend-authguard-static-export-runtime.md §Migration steps (minimi)]
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-087-authguard-client-side-static-export/US-087.md §Acceptance Criteria]

## Technical Specs
- **FE scope:** proteggere `/analysis`, `/analysis/deep`, `/watchlist`, `/top-picks` e aree admin/profilo presenti.
- **Return URL:** preservare path+query originali nel redirect a login e nel post-login.
- **Forbidden:** mantenere redirect a pagina `/403` esistente.
- **Session expired:** riuso flusso logout silente + stato esplicito su login.

## Implementation Steps
1. Applicare `ClientAuthGuard` nei layout/pagine protette.
2. Uniformare costruzione `returnUrl` (path + query) in tutti i redirect.
3. Verificare redirect `/403` per ruolo insufficiente tramite metadata route.
4. Collegare stato `sessionExpired` al flusso login gia' presente.

## Acceptance Criteria
- [ ] Accesso diretto non autenticato a ciascuna rotta protetta -> `/login?returnUrl=...`.
- [ ] Login riuscito da redirect -> ritorno alla rotta completa originale.
- [ ] Utente con ruolo insufficiente -> `/403` senza toast sostitutivi.
- [ ] Sessione scaduta durante navigazione -> logout silente + redirect login con stato esplicito.

## Definition of Done
- [ ] Guard applicato a tutte le sezioni protette elencate in ADR-026
- [ ] `returnUrl` supporta anche query string
- [ ] Redirect `/403` e `sessionExpired` verificati manualmente
- [ ] Code review approvata

## Dependencies
- TSK-266 — guard client-side riusabile
- TSK-207 — pagina `/403`
- TSK-217 — flusso logout centrale

## Risk Notes
- Rischio loop redirect login/rotte pubbliche: mitigare con allowlist esplicita.
- Rischio inconsistenza returnUrl tra pagine: mitigare con util condivisa.
