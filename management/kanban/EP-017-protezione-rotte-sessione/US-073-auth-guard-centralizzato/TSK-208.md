## Context
US-073 e US-074 AC richiedono test completi: accesso non autenticato, returnUrl, ruolo insufficiente, sessione scaduta, rotta pubblica, aggiunta rotta dichiarativa.

## Technical Specs
- **QA:** Playwright E2E
- **Scenari AuthGuard:**
  - Non autenticato → /watchlist → redirect /login?returnUrl=%2Fwatchlist
  - Login riuscito → redirect a returnUrl
  - Autenticato ruolo user → rotta admin → pagina /403
  - Sessione scaduta → logout silente → /login con messaggio
  - Rotta pubblica → accessibile senza auth
- **Scenari route map:**
  - Aggiunta rotta test → protetta senza modifica AuthGuard
  - roles: ['admin'] → non accessibile a user

## Implementation Steps
1. Test non autenticato: navigazione /watchlist → redirect /login con returnUrl
2. Test returnUrl: login → redirect alla rotta originale
3. Test 403: utente user → rotta admin → pagina /403
4. Test sessione scaduta: simula token scaduto → redirect login con messaggio
5. Test rotta pubblica: / e /analysis accessibili
6. Test route map: verifica aggiunta rotta dinamica
