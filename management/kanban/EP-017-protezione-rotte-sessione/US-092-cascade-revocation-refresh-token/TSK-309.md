# TSK-309 — BE Cascade revocation refresh token

## Obiettivo

Implementare la cascade revocation di tutti i refresh token attivi dell'utente quando viene rilevato
il riuso di un token già ruotato, seguendo la decisione contrattuale di ADR-027.

## Scope

1. **`RefreshTokenRepository`** — aggiungere il metodo:
   ```kotlin
   @Modifying(clearAutomatically = true, flushAutomatically = true)
   @Query("UPDATE RefreshToken t SET t.revokedAt = :now " +
          "WHERE t.userId = :userId AND t.revokedAt IS NULL")
   fun revokeAllActiveByUserId(userId: UUID, now: Instant): Int
   ```
   Sfrutta l'indice esistente `refresh_tokens_user_active_idx (user_id, revoked_at)` (V001). Nessuna migration.

2. **`InvalidRefreshTokenException`** — aggiungere il nuovo reason code:
   ```kotlin
   private const val REASON_REUSE_DETECTED: String = "reuse_detected"
   ```
   Il `GlobalExceptionHandler` mappa l'eccezione su `401 ProblemDetail type=https://api/errors/invalid-refresh`
   (testo opaco, anti-enum — invariato rispetto agli altri reason).

3. **`SecurityEventLogger`** — aggiungere il metodo:
   ```kotlin
   fun refreshTokenReuseDetected(userId: UUID, family: Instant, revokedCount: Int)
   ```
   Severity `warn`, marker `SECURITY_EVENT`, retention 365 giorni (ADR-021 §7).

4. **`AuthService.refresh()`** — modificare lo step 2 di detection riuso:
   - Se `token.revokedAt != null` → detection riuso.
   - Invoca `revokeAllActiveByUserId(token.userId, now)`.
   - Emetti `SecurityEventLogger.refreshTokenReuseDetected(userId, family=token.firstIssuedAt, revokedCount)`.
   - Throw `InvalidRefreshTokenException(REASON_REUSE_DETECTED)`.
   - L'operazione gira nella stessa `@Transactional` di `AuthService.refresh()`.

## Invarianti

- Il path "refresh token valido non ruotato → nuovo access token + nuovo refresh ruotato" rimane invariato.
- Nessuna modifica allo schema DB (V001 + V009 sufficienti).
- L'API esterna (`POST /api/auth/refresh`) ritorna sempre `401 invalid-refresh` opaco per tutti i reason.
- `GlobalExceptionHandler` invariato.
