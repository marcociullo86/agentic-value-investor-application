# TSK-215 — FE IdleTimeoutProvider: idle + prompt + absolute timeout

## Context
US-077 richiede timeout inattività con prompt estensione sessione e timeout assoluto per sessioni lunghe.
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-077-timeout-inattivita-assoluto/US-077.md §AC]
[^src: design_&_architecture/decisions/ADR-024-session-lifecycle-credential-storage.md §5]

## Technical Specs
- **FE:** `components/auth/idle-timeout-provider.tsx`
- **Idle timeout:** 15 min (configurabile NEXT_PUBLIC_IDLE_TIMEOUT_MINUTES)
  - Timer si resetta ad ogni interazione (mousemove, keydown, click, scroll)
  - Allo scadere: prompt modale
- **Prompt:** "Estendi sessione" button; timeout prompt 60s; se non interagisce → logout
- **Absolute timeout:** 8h (configurabile NEXT_PUBLIC_ABSOLUTE_TIMEOUT_HOURS)
  - Dopo N ore dall'inizio sessione → logout indipendentemente dall'attività
- **Accessibilità:** prompt annunciato da screen reader, navigabile da tastiera
- **Config:** env vars senza rebuild

## Implementation Steps
1. Creare IdleTimeoutProvider con event listener per interazioni
2. Implementare timer idle con reset ad ogni interazione
3. Implementare prompt modale accessibile
4. Implementare "Estendi sessione" → reset timer
5. Implementare absolute timeout parallelo
6. Configurare env vars

## Definition of Done
- [ ] Idle timeout → prompt dopo 15min inattività
- [ ] "Estendi sessione" resetta timer
- [ ] No interazione prompt → logout
- [ ] Absolute timeout → logout
- [ ] Prompt accessibile (screen reader + tastiera)
- [ ] Config env vars funzionante
- [ ] Code review approvata
