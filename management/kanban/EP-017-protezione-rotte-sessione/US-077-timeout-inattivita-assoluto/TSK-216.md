# TSK-216 — QA Test timeout: idle, prompt extend, no-interaction, absolute, a11y

## Context
US-077 AC richiede verifica idle, estensione, logout automatico, timeout assoluto e accessibilità prompt.
[^src: management/kanban/EP-017-protezione-rotte-sessione/US-077-timeout-inattivita-assoluto/US-077.md §AC]

## Technical Specs
- **QA:** Vitest (mock timer) + Playwright
- **Scenari:**
  - 15 min inattività → prompt appare
  - Click "Estendi sessione" → no logout nei successivi 15 min di attività
  - Prompt senza interazione entro timeout → logout automatico
  - Sessione > absolute timeout → terminata indipendentemente dall'attività
  - Prompt accessibile da tastiera + annunciato screen reader

## Implementation Steps
1. Test idle: mock timer avanza 15min, verifica prompt
2. Test extend: click extend, verifica timer resettato
3. Test no-interaction: prompt timeout → verifica logout
4. Test absolute: mock timer avanza oltre absolute → verifica logout
5. Test a11y prompt: axe-core + keyboard navigation

## Definition of Done
- [ ] Idle → prompt verificato
- [ ] Extend → reset verificato
- [ ] No interaction → logout verificato
- [ ] Absolute timeout verificato
- [ ] Prompt accessibile
- [ ] Code review approvata
