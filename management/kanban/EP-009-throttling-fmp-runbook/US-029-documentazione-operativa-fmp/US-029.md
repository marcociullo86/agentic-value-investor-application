# US-029 — Documentazione operativa FMP (rate limit, URL, errori)

## Descrizione
Come sviluppatore che integra il data provider finanziario, voglio nel wiki limiti di rate, URL base ufficiali degli endpoint e codici/formato errore HTTP documentati, affinché runbook e adapter non si basino su pattern ipotetici non verificati.

## Business Rules
- I tre gap `fmp-rate-limiting`, `fmp-endpoint-base-urls`, `fmp-error-codes` devono essere copribili da pagine wiki o raw ingeriti — chiusura gap a cura di wiki-keeper post-ingest.
- Il runbook quickstart FMP riporta solo URL verificati (versione API, path) con citazione raw.
- Se la documentazione ufficiale non è disponibile, il gap resta aperto con nota esplicita — non inventare numeri di quota.
- EP-002 US-004/005/006 restano validi; questa US estende la knowledge base operativa.

## UI Reference
N/A — documentazione wiki/runbook.

## Acceptance Criteria
- [ ] Runbook FMP include sezione rate limiting con valori citati a fonte raw (o gap esplicito se assente).
- [ ] Runbook elenca URL base ufficiali per income/balance/cashflow/key-metrics/profile/search.
- [ ] Runbook documenta almeno codici HTTP errore comuni (401, 403, 404, 429, 5xx) e forma risposta errore provider.
- [ ] Tre gap FMP in `wiki/gaps.md` marcati risolvibili o con piano ingest documentato.
