# TSK-162 — BE: aggiorna prompt Munger LLM con ROE dual lookback

## Obiettivo
Aggiornare il template del prompt `MungerInversionAnalyzer` per includere entrambe le metriche ROE come parte del contesto strutturato pre-RAG, con nota interpretativa sulla divergenza, secondo ADR-020 §"Input al report Munger LLM".

## Scope
- Aggiornamento risorsa Spring `classpath:munger-queries.json` (o template prompt Kotlin equivalente per il contesto strutturato): aggiungere nel blocco di contesto pre-RAG i due campi ROE:
  ```
  ROE 5y: <fiveYearAvg> (growth/turnaround signal).
  ROE 10y: <tenYearAvg> (Graham defensive stability signal).
  Discutere divergenza significativa (|5y − 10y| > 5pp) come indicatore di cambio strutturale del business.
  ```
- Valore `fiveYearAvg` e `tenYearAvg` iniettati dal `DeepAnalysisService` nel context bag prima di invocare `MungerInversionAnalyzer`. Se uno dei valori è `null` (dati insufficienti), il placeholder mostra "N/A (dati insufficienti)".
- Golden test aggiornato: il test esistente su `MungerInversionAnalyzer` (TSK-107) riceve un context con entrambi i lookback ROE → verificare che il placeholder venga sostituito correttamente e che il mock LLM response non venga rotto (nessun cambio strutturale al formato di output JSON).
- Nuovo golden test su divergenza: contesto con `fiveYearAvg=0.30`, `tenYearAvg=0.18` (divergenza > 5pp) → verificare che il prompt inviato al mock LLM contenga la nota sulla divergenza.

## DoD
- Template prompt contiene entrambi i placeholder ROE.
- Golden test esistente (TSK-107 scope) non rotto.
- Nuovo golden test sulla divergenza (> 5pp) supera.
- Nessuna modifica al formato di output JSON di `MungerInversionAnalyzer` (backward-compat).
