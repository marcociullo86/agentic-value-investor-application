# TSK-107 — Test MungerInversionAnalyzer — mock Anthropic SDK + golden response test

## Cosa fare

1. Creare `MungerInversionAnalyzerTest.kt` con mock del `AnthropicClient`.
2. **Golden response test**: preparare una risposta JSON fissa ("golden") per le 10 query e la sintesi. Verificare che `MungerInversionAnalyzer.analyze()` produca un `MungerInversionReport` con:
   - `livelloRischio = RISCHIO_MODERATO`.
   - `rischiPrincipali` con 3 elementi, ognuno con `chunkIndex` valorizzato.
   - `puntiDiForza` con almeno 2 elementi.
   - `segnaliRecenti10Q` con almeno 1 elemento.
3. **Cache test**: seconda chiamata con stesso filing combo → verifica che `AnthropicClient.call()` non venga invocato (cache hit da DB).
4. **LLM malformato**: mock restituisce JSON non valido → verifica retry + fallback (report con `livelloRischio = RISCHIO_ALTO`, flag `parseError = true`).
5. **LLM timeout**: mock lancia `EmbeddingTimeoutException` → verifica log evento + eccezione propagata.

## Acceptance Criteria

- [ ] Golden response: report con tutti i campi popolati.
- [ ] Cache hit: 0 chiamate LLM alla seconda invocazione.
- [ ] JSON malformato: retry + fallback report.
- [ ] Timeout: log evento + eccezione.
