# TSK-108 — Estendi FmpAdapter con getStockNews (endpoint /stable/news/stock, finestra 90gg)

## Cosa fare

1. Aggiungere il metodo `getStockNews(ticker: String, days: Int = 90): List<StockNewsItem>` all'interfaccia `FmpAdapter`.
2. Creare il DTO `StockNewsItem` con: `newsId: String?`, `publishedAt: LocalDateTime?`, `title: String?`, `text: String?`, `url: String?`, `source: String?` (nullable-aware per US-004).
3. Implementare il metodo in `FmpAdapterRestClient` chiamando `GET /stable/news/stock?tickers={ticker}&from={date-90d}&to={today}&apikey={key}`.
4. Filtrare risultati per finestra temporale `publishedAt >= today - days`.
5. TTL cache: 6h (news cambiano più frequentemente dei dati finanziari).
6. Il metodo è additive rispetto ai metodi FmpAdapter preesistenti.

## Acceptance Criteria

- [ ] `FmpAdapter.getStockNews("AAPL", 90)` restituisce lista di news con `title` e `url` valorizzati.
- [ ] Nessuna news con `publishedAt` fuori dalla finestra 90gg.
- [ ] Cache hit entro TTL 6h.
- [ ] Nessuna regressione sui metodi FmpAdapter preesistenti.
