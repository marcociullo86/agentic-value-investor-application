# TSK-091 — Implementa SecEdgarAdapter interface + SecEdgarRestClient con fair-access headers

## Cosa fare

1. Creare l'interfaccia `SecEdgarAdapter` in `./src/backend/src/main/kotlin/com/valueinvesting/adapter/SecEdgarAdapter.kt` con i metodi:
   - `resolveCikFromTicker(ticker: String): String?`
   - `listFilings(cik: String, formTypes: List<String> = listOf("10-K", "10-Q"), limit: Int = 10): List<SecFilingMetadata>`
   - `downloadFilingHtml(url: String): String?`
2. Creare il DTO `SecFilingMetadata`: `accessionNumber: String?`, `formType: String?`, `filedAt: LocalDate?`, `primaryDocumentUrl: String?`.
3. Creare `SecEdgarRestClient : SecEdgarAdapter` usando Spring `RestClient`.
4. Ogni richiesta HTTP imposta header `User-Agent: ValueInvesting-App/1.0 {sec.edgar.user-agent.email}` (email da `application.yaml`).
5. Configurare `SecEdgarResilienceConfig` con `RateLimiter` Resilience4j: `limitForPeriod = 10`, `limitRefreshPeriod = 1s` (≤ 10 req/s).
6. Mappare errori HTTP: 403 → `SecEdgarAccessDeniedException`, 429 → `SecEdgarRateLimitException`, 5xx → `SecEdgarServiceException`.
7. Esporre proprietà in `application.yaml`: `sec.edgar.base-url`, `sec.edgar.user-agent.email`, `sec.edgar.rate-limit-per-second`.

## Acceptance Criteria

- [ ] L'interfaccia `SecEdgarAdapter` esiste con i 3 metodi.
- [ ] `SecEdgarRestClient` invia `User-Agent` identificativo su ogni richiesta.
- [ ] `RateLimiter` Resilience4j limita a ≤ 10 req/s.
- [ ] Le 3 eccezioni applicative sono definite e mappate.
- [ ] Le 3 proprietà sono in `application.yaml`.
- [ ] Nessuna regressione sui test FMP esistenti.

## Note implementative

- Base URL SEC EDGAR: `https://data.sec.gov/` per EDGAR full-text search; `https://efts.sec.gov/` per ricerche avanzate. Il `resolveCikFromTicker` usa `https://data.sec.gov/submissions/CIK{padded10}.json`. [^src: wiki/gaps.md §vi-sec-narrative-gap]
- Il RateLimiter è separato dal `fmp-online` per non intaccare il throughput FMP. [^src: US-038 §Business Rules]
- Stack: Kotlin 2.2 + Spring Boot 3.5 + Resilience4j. [^src: raw/tech_stack.md]
