# TSK-093 — Test integrazione WireMock per SecEdgarRestClient — rate-limit, 429, 5xx, CIK cache

## Cosa fare

1. Creare `SecEdgarRestClientIntegrationTest.kt` con WireMock per simulare SEC EDGAR.
2. Test da implementare:
   - **Rate-limit applicato**: inviare 12 richieste in rapida successione; verificare che l'adapter rispetti ≤ 10 req/s (controllare la durata totale ≥ 1 secondo per 11+ richieste).
   - **Gestione 429**: WireMock risponde 429; verificare `SecEdgarRateLimitException` propagata.
   - **Gestione 5xx**: WireMock risponde 503; verificare `SecEdgarServiceException` propagata.
   - **Ticker inesistente**: WireMock risponde 404; verificare `resolveCikFromTicker` restituisce `null`.
   - **Cache CIK hit**: due chiamate per lo stesso ticker → 1 sola richiesta HTTP a WireMock.
3. Verificare che ogni richiesta HTTP contenga l'header `User-Agent` corretto.

## Acceptance Criteria

- [ ] Rate-limit test: 12 richieste in 1.5s → ≤ 10 arrivano in 1s (throttling verificato).
- [ ] 429 → `SecEdgarRateLimitException` propagata.
- [ ] 5xx → `SecEdgarServiceException` propagata.
- [ ] Ticker inesistente → `null` (nessuna eccezione).
- [ ] Cache hit: 2 chiamate ticker uguale → 1 sola HTTP request a WireMock.
- [ ] `User-Agent` header presente in ogni richiesta.
