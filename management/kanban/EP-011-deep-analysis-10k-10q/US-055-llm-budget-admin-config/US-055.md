# US-055 — LLM cost telemetry + budget admin config runtime

## Descrizione
Come admin/team operativo, voglio che ogni chiamata LLM (Anthropic Claude Opus + Google Gemini Flash) sia tracciata in DB con costo stimato, ticker, user e purpose, che il budget mensile corrente ($50 default) sia visibile in tempo reale, e che io possa modificare il cap mensile tramite un pannello admin senza redeploy, affinché io possa controllare la spesa LLM e intervenire tempestivamente in caso di anomalia.
[^src: ADR-019 §4.bis Configurazione runtime]
[^src: ADR-019 §2 Telemetria persistente]

## Business Rules
- Tabella `llm_cost_counter` (1 row per mese, UPSERT atomico): `year_month`, `total_cost_usd`, `total_calls`, `total_tokens_in`, `total_tokens_out`, `cache_hits`, `alert_80_sent_at`, `alert_100_sent_at`, `last_updated`.
- Tabella `llm_call_log` (1 row per chiamata): log granulare con `ticker`, `user_id`, `model`, `cost_usd`, `cache_hit`, `latency_ms`, `error_code`. Retention 90 giorni.
- Tabella `llm_budget_config` (singleton row `id=1`): `monthly_cap_usd` (seed `50.00`), `alert_threshold_percent` (default `80`), `updated_at`, `updated_by`.
- `LlmCostCounterService`: UPSERT atomico PostgreSQL post-call.
- `LlmCallLogger` AOP `@Around` su `AnthropicClient.complete` + `GeminiClient.complete`.
- `LlmBudgetConfigService`: lettura `monthly_cap_usd` da `llm_budget_config` con cache in-memory; invalidata via Spring event al `PUT /admin/llm-cost/budget`.
- Endpoint `GET /admin/llm-cost` (`ROLE_ADMIN`): utilization%, cap corrente, breakdown per purpose, history 30gg, freeze status.
- Endpoint `PUT /admin/llm-cost/budget` (`ROLE_ADMIN`): body `{ "monthlyCapUsd": <decimal>, "reason": "<string>" }`; valida `> 0 && <= LLM_BUDGET_ABSOLUTE_MAX_USD (10000)`; persiste in `llm_budget_config`; emette audit `LLM_BUDGET_CAP_CHANGED` con `old/new value, actor, timestamp`; risposta `400 BUDGET_CAP_INVALID` (RFC 9457) se fuori range; idempotenza (stesso valore = no-op).
- Endpoint `POST /admin/llm-cost/freeze` / `POST /admin/llm-cost/unfreeze` (`ROLE_ADMIN`): toggle live freeze senza restart.
- Alert cron ogni 5 min: 80% cap → Slack webhook idempotente (`alert_80_sent_at`); 100% → log ERROR + Slack.
- `LlmBudgetAdminPanel` FE (solo ADMIN): lettura cap via `GET /admin/llm-cost`, campo numerico + reason opzionale, modal conferma diff `old → new`, chiamata `PUT /admin/llm-cost/budget`, gestione `400 BUDGET_CAP_INVALID` via toast.
- Freeze attivo → endpoint LLM-dependent restituiscono `HTTP 503 LLM_FROZEN_BY_ADMIN` (RFC 9457).

## Acceptance Criteria
- [ ] Ogni chiamata LLM produce una row `llm_call_log` con `cost_usd` calcolato correttamente.
- [ ] `GET /admin/llm-cost` restituisce `monthlyCapUsd` aggiornato dopo un `PUT /admin/llm-cost/budget`.
- [ ] `PUT /admin/llm-cost/budget` con `monthlyCapUsd=75.00` aggiorna `llm_budget_config`, emette audit `LLM_BUDGET_CAP_CHANGED`, invalida cache in-memory.
- [ ] `PUT /admin/llm-cost/budget` con `monthlyCapUsd=0` o negativo restituisce `400 BUDGET_CAP_INVALID` (RFC 9457).
- [ ] Utente con ruolo `USER` su `PUT /admin/llm-cost/budget` riceve `403`.
- [ ] `POST /admin/llm-cost/freeze` → successive chiamate LLM restituiscono `503 LLM_FROZEN_BY_ADMIN`.
- [ ] `LlmBudgetAdminPanel` visibile solo ad ADMIN; modal conferma; toast su 400.
- [ ] Alert 80% inviato una sola volta per mese (idempotenza `alert_80_sent_at`).
