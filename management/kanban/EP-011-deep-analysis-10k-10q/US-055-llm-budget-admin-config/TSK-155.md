# TSK-155 — DB: migration V0XX__llm_cost_tracking

## Obiettivo
Creare la migration Flyway che introduce le tre tabelle di telemetria LLM definite in ADR-019.

## Scope
- Flyway `V0XX__llm_cost_tracking.sql` (numero da assegnare in sequenza dopo V016 esistente — verificare migration più alta presente).
- Tabella `llm_cost_counter`: colonne `year_month CHAR(7) PRIMARY KEY`, `total_cost_usd NUMERIC(10,4) NOT NULL DEFAULT 0`, `total_calls BIGINT NOT NULL DEFAULT 0`, `total_tokens_in BIGINT NOT NULL DEFAULT 0`, `total_tokens_out BIGINT NOT NULL DEFAULT 0`, `cache_hits BIGINT NOT NULL DEFAULT 0`, `alert_80_sent_at TIMESTAMPTZ NULL`, `alert_100_sent_at TIMESTAMPTZ NULL`, `last_updated TIMESTAMPTZ NOT NULL DEFAULT now()`.
- Tabella `llm_call_log`: colonne `id BIGSERIAL PK`, `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`, `endpoint VARCHAR(64)`, `purpose VARCHAR(32)`, `ticker VARCHAR(16)`, `user_id BIGINT NULL`, `request_id UUID`, `model VARCHAR(64)`, `input_tokens INT NOT NULL`, `output_tokens INT NOT NULL`, `cost_usd NUMERIC(10,6) NOT NULL`, `cache_hit BOOLEAN NOT NULL DEFAULT false`, `error_code VARCHAR(32) NULL`, `latency_ms INT NOT NULL`. Indici: `(created_at)`, `(purpose, created_at)`, `(ticker, created_at)`, `(user_id, ticker, created_at)`.
- Tabella `llm_budget_config` (singleton row): `id SMALLINT PRIMARY KEY CHECK (id = 1)`, `monthly_cap_usd NUMERIC(10,2) NOT NULL`, `alert_threshold_percent SMALLINT NOT NULL DEFAULT 80`, `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`, `updated_by BIGINT NULL REFERENCES app_user(id)`. Seed: `INSERT INTO llm_budget_config (id, monthly_cap_usd) VALUES (1, 50.00) ON CONFLICT DO NOTHING`.

## DoD
- Migration applica senza errori su DB pulito (Testcontainers PostgreSQL 17).
- Seed row `id=1` presente dopo migration.
- Rollback documentato (V0XX__rollback script o commento).
