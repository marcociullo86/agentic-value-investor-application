# TSK-120 — Integration test E2E /deep — tutti i mock provider (cache hit, cold call, ticker invalido, no filing)

## Cosa fare

1. Creare `DeepAnalysisIntegrationTest.kt` con Testcontainers PostgreSQL pgvector + WireMock (FMP + SEC EDGAR) + mock `AnthropicClient` + mock `EmbeddingService`.
2. Test da implementare:
   - **Cache hit**: pre-popolare tutte le cache (filing_blob, filing_chunks, deep_analysis_report, news_classification, price_action_snapshot) → `GET /api/analysis/AAPL/deep` risponde 200 in < 2s.
   - **Cold call**: nessuna cache → `GET /api/analysis/AAPL/deep` risponde 200 entro 30s (con mock veloci).
   - **Ticker invalido**: WireMock SEC 404 per CIK → risposta 404 `problem+json`.
   - **No filing SEC**: WireMock FMP `getSecFilings` vuoto + SEC lista filing vuota → risposta 422 con `reason = "no_sec_filings"`.
3. Verificare che `deep_analysis_event_log` abbia un record per ogni esecuzione.

## Acceptance Criteria

- [ ] Cache hit: risposta 200 in < 2s.
- [ ] Cold call: risposta 200 entro 30s con tutti i campi.
- [ ] Ticker invalido: 404 `problem+json`.
- [ ] No filing: 422 con `reason = "no_sec_filings"`.
- [ ] Event log: 1 record per test case.
