# TSK-160 — BE: implementa RoeCalculator.fiveYearAverage (ROE_5Y_AVG)

## Obiettivo
Portare in Kotlin il calcolo `ROE_5Y_AVG` di `agent.py` v2.6.1, affiancandolo a `ROE_10Y_AVG` già presente nel Rule Engine.

## Pre-flight verification (2026-05-25)

Ispezione completa di `src/backend/src/main/kotlin/` effettuata il 2026-05-25 dal tpm. Pattern cercati:

| Pattern | Esito |
|---|---|
| File `*RoeCalculator*` o classe `RoeCalculator` | Non trovato |
| Metodo `fiveYearAverage` in qualsiasi file Kotlin | Non trovato |
| Costante/ruleId `ROE_5Y_AVG` | Non trovato |
| `lookbackYears = 5` o parametro lookback nel calcolo ROE | Non trovato |
| Variante 5y della funzione `averageOf` / `averageOfMetric` | Non trovato |

File ispezionati rilevanti:
- `src/backend/src/main/kotlin/com/valueinvesting/webapp/ruleengine/rules/RoeRule.kt` — implementa solo `ROE_10Y_AVG` tramite `averageOf(dataset.keyMetrics) { it.roe }` con lista passata dal chiamante (FMP `limit=10`). Nessun parametro lookback.
- `src/backend/src/main/kotlin/com/valueinvesting/webapp/ruleengine/rules/TenYearAverage.kt` — helper condiviso `averageOf` e `averageOfMetric`. Non parametrizza il lookback; lavora sulla lista intera passata dal chiamante.
- `src/backend/src/test/kotlin/com/valueinvesting/webapp/ruleengine/rules/RoeRuleTest.kt` — testa solo `ROE_10Y_AVG`.

**Conclusione: non implementato. TSK procede come da scope originale.**

## Scope
- Aggiungere `RoeCalculator.fiveYearAverage(incomeStatements: List<IncomeStatement>): BigDecimal?` accanto al metodo `tenYearAverage(...)` esistente.
- Algoritmo: media aritmetica del ROE (Net Income / Shareholders Equity) sugli ultimi 5 anni fiscali disponibili. Stessa logica di `agent.py` v2.6.1 (porting).
- Edge case:
  - IPO recente (< 5 anni disponibili): calcola su anni disponibili, `fiveYearDataPoints` riflette il conteggio reale.
  - Anno con Shareholders Equity ≤ 0: escludi dall'average (non dividere per zero); se tutti gli anni hanno equity ≤ 0 → `null`.
  - ROE negativo: incluso nel calcolo (non filtrato).
- Riusa la stessa fetch FMP `income-statement` già caching-aware (ADR-003/v2 + ADR-014); **nessuna nuova chiamata FMP esterna**.
- Aggiungere test unitari: edge case IPO recente, anni mancanti, ROE negativo, equity ≤ 0.

## DoD
- `RoeCalculator.fiveYearAverage` presente e testato (unit test JUnit 5).
- Edge case IPO (< 5 anni) e equity ≤ 0 coperti da test.
