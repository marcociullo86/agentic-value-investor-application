# TSK-119 — DTO RuleEngineDeepResult + OpenAPI schema /deep + migration V016__deep_analysis_event_log

## Cosa fare

1. Creare il DTO `DeepAnalysisResultDto` con i campi:
   - `ticker`, `generatedAt: Instant`, `verdictPayload: VerdictPayloadDto`, `deepAnalysisReport: MungerInversionReportDto`, `sentimentSummary: SentimentSummaryDto`, `priceActionSnapshot: PriceActionSnapshotDto`, `ruleEngineResults: List<RuleResultDto>` (13 ruleId), `filingsUsed: List<FilingReferenceDto>`.
2. Aggiornare il contratto OpenAPI canonico con lo schema completo di `DeepAnalysisResultDto` per `GET /api/analysis/{ticker}/deep`.
3. Creare `V016__deep_analysis_event_log.sql`:
   ```sql
   CREATE TABLE deep_analysis_event_log (
     id             BIGSERIAL PRIMARY KEY,
     ticker         VARCHAR(20)  NOT NULL,
     generated_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
     cache_hits     INT,
     llm_calls      INT,
     total_duration_ms BIGINT
   );
   CREATE INDEX idx_deep_event_log_ticker ON deep_analysis_event_log (ticker, generated_at DESC);
   ```

## Acceptance Criteria

- [ ] Il DTO `DeepAnalysisResultDto` ha tutti i campi dell'US-045.
- [ ] Il contratto OpenAPI include lo schema completo per `/api/analysis/{ticker}/deep`.
- [ ] `V016__deep_analysis_event_log.sql` applicata da Flyway senza errori.
- [ ] `flyway validate` passa.
