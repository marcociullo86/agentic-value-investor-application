# TSK-116 — Implementa PositionSizeCalculator — port da agent.py:_calcola_position_size

## Cosa fare

1. Creare `PositionSizeCalculator` in `./src/backend/src/main/kotlin/com/valueinvesting/service/PositionSizeCalculator.kt`.
2. Il servizio espone: `calculate(verdettoCLasse: VerdictClass, marginOfSafetyPct: Double): PositionSizeResult`.
3. Logica di calcolo (port da `agent.py:_calcola_position_size`):
   - `APPROVATO_PANIC_BUY`: base 5%, amplificato proporzionalmente a MoS (es. MoS = 50% → 6%; MoS = 20% → 4%); range [4%, 6%].
   - `APPROVATO`: base 3%, range [2%, 4%]; proporzionale a MoS.
   - `WATCHLIST`, `BOCCIATO_*`: 0%.
4. Formula MoS-proportional: `positionSize = basePct + (mos_pct / 100.0) * scaleFactor` (clamp al range).
5. Output `PositionSizeResult`: `recommendedPct`, `range: Pair<Double, Double>`, `basisVerdict`, `marginOfSafetyPct`.
6. Nota legale da includere nel payload: `"Indicazione tecnica, non consiglio finanziario"`.

## Acceptance Criteria

- [ ] `APPROVATO_PANIC_BUY` con MoS 50% → position 5.5-6%.
- [ ] `APPROVATO` con MoS 20% → position ≈ 2.4-2.8%.
- [ ] `BOCCIATO_*` → 0% sempre.
- [ ] Range sempre rispettato (clamp).
- [ ] Il campo `basisVerdict` è valorizzato.
