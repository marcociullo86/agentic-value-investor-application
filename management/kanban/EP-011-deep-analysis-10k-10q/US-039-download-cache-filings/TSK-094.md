# TSK-094 — Estendi FmpAdapter con getSecFilings (endpoint /stable/sec-filings-search/symbol)

## Cosa fare

1. Aggiungere il metodo `getSecFilings(ticker: String, formTypes: List<String> = listOf("10-K", "10-Q")): List<SecFilingReference>` all'interfaccia `FmpAdapter`.
2. Creare il DTO `SecFilingReference` con: `ticker: String?`, `formType: String?`, `filedAt: LocalDate?`, `accessionNumber: String?`, `documentUrl: String?` (nullable-aware per US-004).
3. Implementare il metodo in `FmpAdapterRestClient` chiamando `GET /stable/sec-filings-search/symbol?symbol={ticker}&type={formType}&apikey={key}`.
4. Filtrare il risultato per `formTypes` specificati.
5. Il metodo è additive (non breaking) rispetto ai metodi FmpAdapter preesistenti.
6. Caching: TTL 24h tramite `FmpCacheService`.

## Acceptance Criteria

- [ ] `FmpAdapter.getSecFilings("AAPL", ["10-K", "10-Q"])` restituisce lista non vuota con `documentUrl` valorizzati.
- [ ] `formTypes` filtra correttamente (solo i tipi richiesti).
- [ ] I campi nullable non generano NPE su payload FMP incompleti.
- [ ] Cache hit entro TTL 24h (nessuna nuova HTTP call).
- [ ] Nessuna regressione sui metodi FmpAdapter preesistenti.
