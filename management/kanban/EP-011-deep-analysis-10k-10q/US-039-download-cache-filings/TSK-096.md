# TSK-096 — Implementa Filing10KQDownloaderService — download, HTML strip, persist filing_blob

## Cosa fare

1. Creare `Filing10KQDownloaderService` in `./src/backend/src/main/kotlin/com/valueinvesting/service/Filing10KQDownloaderService.kt`.
2. Il servizio espone il metodo: `fetchAndCache(ticker: String): List<FilingBlobEntity>`.
3. Il flusso interno:
   a. Chiama `FmpAdapter.getSecFilings(ticker)` per ottenere la lista dei filing (indice secondario).
   b. Per ogni filing non già in `filing_blob` (o scaduto): chiama `SecEdgarAdapter.downloadFilingHtml(url)`.
   c. Stripping HTML → `chunkable_text` usando `Jsoup.parse(html).text()` (libreria Jsoup).
   d. Calcola `blob_size_bytes`; se > 50MB, log evento + skip (nessun persist).
   e. Persiste `FilingBlobEntity` in `filing_blob` con `expires_at = now() + 90 giorni`.
   f. Restituisce lista degli `FilingBlobEntity` disponibili (include cache hit + nuovi download).
4. Creare `FilingBlobEntity` (Spring Data JPA) + `FilingBlobRepository`.
5. Cache hit check: se `filing_blob` ha record per `accessionNumber` con `expires_at > now()`, non rifetcha.

## Acceptance Criteria

- [ ] Per AAPL: `fetchAndCache("AAPL")` persiste almeno 2 10-K + 4 10-Q in `filing_blob`.
- [ ] Seconda chiamata entro 90 giorni: nessun download HTTP (cache hit verificato).
- [ ] Filing > 50MB: log evento + skip, nessuna eccezione unchecked.
- [ ] `chunkable_text` è testo leggibile (HTML stripped) non vuoto.
- [ ] `expires_at = fetched_at + 90 giorni` per ogni record.
