# TSK-122 — Route /analysis/{ticker}/deep + page component Next.js (App Router)

## Cosa fare

1. Creare la route `./src/frontend/app/analysis/[ticker]/deep/page.tsx` (App Router, Next.js 16.x).
2. La pagina ha la struttura dello scheletro con 5 sezioni (placeholder per i componenti di TSK-123):
   1. `<DeepVerdictBadge />` (verdict class + position size).
   2. `<MungerReportCollapsible />` (rischi/punti di forza/segnali).
   3. `<NewsSentimentChip />` (distribuzione news).
   4. `<DrawdownChart />` (grafico prezzi 52w).
   5. `<EdgarFilingLinks />` (lista filing).
3. Aggiungere tab navigation sulla pagina `/analysis/{ticker}` esistente per lineare con `/analysis/{ticker}/deep`.
4. Stato di caricamento: skeleton loader (`<Skeleton />`) durante la cold call con messaggio "Sto analizzando i filing SEC, potrebbero servire fino a due minuti".
5. Stato errore gestito per 404, 422, 503 (render dedicato per ciascuno).
6. `generateStaticParams()` non richiesto per questa route (non è export statico — la pagina usa client-side fetching via SWR).

## Acceptance Criteria

- [ ] La route `/analysis/AAPL/deep` carica senza errori 404 Next.js.
- [ ] La tab "Deep Analysis" è visibile nella navigazione di `/analysis/{ticker}`.
- [ ] Skeleton loader visibile durante il fetching.
- [ ] Errori 404/422/503 hanno render dedicati con messaggi corretti.
- [ ] La pagina compila senza errori TypeScript.
