# TSK-125 — Test E2E Playwright Deep Analysis — happy path AAPL + value-trap scenario + ticker invalido

## Cosa fare

1. Creare `deep-analysis.spec.ts` in `./src/frontend/e2e/`.
2. Test da implementare:
   - **Happy path AAPL**: navigare a `/analysis/AAPL/deep` → skeleton loader visibile → dopo il fetch (mock backend) → badge `APPROVATO` o `WATCHLIST` visibile → le 5 sezioni sono presenti.
   - **Value-trap scenario**: mock backend con `verdettoCLasse = BOCCIATO_VALUE_TRAP` → badge rosso con testo "Bocciato: Value Trap" visibile.
   - **Ticker invalido**: navigare a `/analysis/XYZINVALID/deep` → messaggio "Ticker non trovato" + link al search.
   - **No SEC filings**: mock backend 422 con `reason = "no_sec_filings"` → messaggio "Nessun filing SEC disponibile".
   - **Force refresh**: click "Rigenera" → skeleton loader appare → nuovo fetch avviene.
3. Verificare accessibilità: il badge verdict ha `aria-label` o testo alternativo.

## Acceptance Criteria

- [ ] Happy path: badge verdict visibile e le 5 sezioni popolate.
- [ ] Value-trap: badge rosso con testo corretto.
- [ ] Ticker invalido: messaggio "Ticker non trovato".
- [ ] No filing: messaggio dedicato.
- [ ] Force refresh: skeleton appare + fetch avviene.
- [ ] Accessibilità: `aria-label` presente sul badge.
