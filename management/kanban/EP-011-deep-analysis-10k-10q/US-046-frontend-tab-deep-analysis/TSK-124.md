# TSK-124 — API client estensione + SWR hook useDeepAnalysis per /api/analysis/{ticker}/deep

## Cosa fare

1. Estendere il client API in `./src/frontend/lib/api.ts` (o path equivalente) con la funzione `fetchDeepAnalysis(ticker: string): Promise<DeepAnalysisResultDto>`.
2. Creare il hook `useDeepAnalysis(ticker: string)` usando SWR:
   - `key`: `["/api/analysis", ticker, "deep"]`.
   - `fetcher`: `fetchDeepAnalysis(ticker)`.
   - `revalidateOnFocus: false` (la deep analysis è costosa, no auto-refresh).
   - Espone: `data`, `isLoading`, `error`, `refresh: () => mutate()`.
3. Aggiornare i tipi TypeScript `DeepAnalysisResultDto` per riflettere lo schema OpenAPI di TSK-119.
4. Gestire le risposte di errore: 404 → error con `reason: "not_found"`; 422 → `reason: "no_sec_filings"`; 503 → `reason: "llm_unavailable"`.
5. Il bottone "Rigenera" chiama `refresh()` con `{ revalidate: true }`.

## Acceptance Criteria

- [ ] `useDeepAnalysis("AAPL")` chiama `GET /api/analysis/AAPL/deep` via SWR.
- [ ] `isLoading = true` durante il fetching; `isLoading = false` a completamento.
- [ ] Errore 404 → `error.reason = "not_found"`.
- [ ] `refresh()` forza un nuovo fetch.
- [ ] I tipi TypeScript `DeepAnalysisResultDto` sono allineati con lo schema OpenAPI.
