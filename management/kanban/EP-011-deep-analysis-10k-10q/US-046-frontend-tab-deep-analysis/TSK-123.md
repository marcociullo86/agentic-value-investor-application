# TSK-123 — Componenti UI Deep Analysis — DeepVerdictBadge + MungerReportCollapsible + NewsSentimentChip + DrawdownChart + EdgarFilingLinks

## Cosa fare

1. Creare `DeepVerdictBadge.tsx`: badge con classe verdetto + position size suggerito. Colori: `APPROVATO*` → verde, `WATCHLIST` → giallo, `BOCCIATO_*` → rosso. Accessibilità: alternativa testuale + icona (coerente con US-014).
2. Creare `MungerReportCollapsible.tsx`: sezione collapsibile con livello rischio, lista top-3 rischi, lista top-3 punti di forza, segnali recenti 10-Q. Ogni rischio mostra il `chunkIndex` come tooltip.
3. Creare `NewsSentimentChip.tsx`: distribuzione classi (barra o donut), top-3 news per classe con link esterno. Ogni chip ha etichetta testuale.
4. Creare `DrawdownChart.tsx`: grafico linea (Recharts) con serie `price`, `max52w`, `min52w` su asse temporale 52w. Evidenziare visivamente il `panicDiscount` e `deteriorationWarning` flag.
5. Creare `EdgarFilingLinks.tsx`: lista filing analizzati con `formType`, `filedAt`, link diretto a SEC.gov.
6. Tutti i componenti ricevono i dati come props (no fetching interno: il fetching è in TSK-124).
7. Footer: `generatedAt` timestamp + bottone "Rigenera" (force refresh, clic → `mutate()` SWR con `revalidate: true`).

## Acceptance Criteria

- [ ] `DeepVerdictBadge` mostra la classe con colore e icona corretti.
- [ ] `MungerReportCollapsible` è espandibile/collassabile.
- [ ] `DrawdownChart` mostra le 3 serie (price, max, min) sull'asse temporale.
- [ ] `EdgarFilingLinks` mostra link cliccabili a SEC.gov.
- [ ] Accessibilità: tutti i badge hanno alternativa testuale.
- [ ] I componenti compilano senza errori TypeScript.
