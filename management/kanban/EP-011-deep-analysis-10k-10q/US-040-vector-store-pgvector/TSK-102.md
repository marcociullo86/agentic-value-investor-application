# TSK-102 — Implementa FilingRagService — persist chunks + embedding + similarity search pgvector

## Cosa fare

1. Creare `FilingRagService` in `./src/backend/src/main/kotlin/com/valueinvesting/service/FilingRagService.kt`.
2. Il servizio espone i metodi:
   - `indexFiling(filingBlobId: Long)`: chunking + embedding + persist in `filing_chunks` (idempotente via `upsert` su `(filing_blob_id, chunk_index)`).
   - `similaritySearch(queryText: String, ticker: String, topK: Int = 8): List<FilingChunkResult>`.
3. `indexFiling`:
   a. Recupera `chunkable_text` da `filing_blob` by `filingBlobId`.
   b. Chiama `FilingChunkingService.chunk(text)`.
   c. Chiama `EmbeddingService.embed(chunks.map { it.content })` → lista di vettori.
   d. Per ogni chunk: upsert in `filing_chunks` con `embedding = pgvector`.
4. `similaritySearch`:
   a. Chiama `EmbeddingService.embed(listOf(queryText))` → vettore query.
   b. Esegue query SQL: `SELECT *, (embedding <=> queryVector) AS distance FROM filing_chunks WHERE ticker = ? ORDER BY embedding <=> ? LIMIT ?`.
   c. Restituisce `List<FilingChunkResult(chunkIndex, content, distance, filingBlobId)>`.
5. Creare `FilingChunkEntity` (JPA) + `FilingChunkRepository`.
6. Dipendenze: TSK-098 (migration), TSK-100 (EmbeddingService), TSK-101 (ChunkingService).

## Acceptance Criteria

- [ ] `indexFiling(id)` su un blob di 60.000 caratteri produce ≈ 10 chunk persistiti in `filing_chunks`.
- [ ] Rieseguire `indexFiling` sullo stesso `filing_blob_id` non duplica chunk (idempotenza).
- [ ] `similaritySearch("rischi per il business", "AAPL", 5)` restituisce 5 chunk ordinati per distanza coseno.
- [ ] La query similarity risponde in < 200ms su corpus di 10 filing (≈ 300 chunk).

## Note implementative

- La query pgvector coseno usa l'operatore `<=>` (cosine distance, non inner product `<#>`). [^src: US-040 §Business Rules]
- Per il `upsert` Kotlin: usa `@Query` Spring Data JPA con `ON CONFLICT (filing_blob_id, chunk_index) DO UPDATE`.
- Stack: Kotlin 2.2 + Spring Boot 3.5 + Spring Data JPA + pgvector. [^src: raw/tech_stack.md]
