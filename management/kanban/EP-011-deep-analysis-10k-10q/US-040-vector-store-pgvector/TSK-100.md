# TSK-100 — Implementa EmbeddingService Kotlin — HTTP client verso sidecar Python

## Cosa fare

1. Creare `EmbeddingService` in `./src/backend/src/main/kotlin/com/valueinvesting/service/EmbeddingService.kt`.
2. Il servizio espone il metodo: `embed(texts: List<String>): List<FloatArray>` che:
   a. Divide `texts` in batch da 32 (batch size configurabile via `embeddings.batch-size`).
   b. Per ogni batch chiama `POST http://embeddings-sidecar:8001/embed` con body `{ "texts": [...] }`.
   c. Aggrega e restituisce la lista di vettori 1024-dim.
3. Gestire errori HTTP del sidecar: 503 → `EmbeddingServiceUnavailableException`; timeout > 30s → `EmbeddingTimeoutException`.
4. Esporre configurazione in `application.yaml`: `embeddings.sidecar.url`, `embeddings.sidecar.timeout-seconds`, `embeddings.batch-size`, `embeddings.model.name` (informativo, non usato per l'inferenza che avviene nel sidecar).
5. Log INFO per ogni batch: `Embedding batch {n}/{total}, model: {model.name}`.

## Acceptance Criteria

- [ ] `EmbeddingService.embed(listOf("hello"))` restituisce un vettore di 1024 floats.
- [ ] Con sidecar irraggiungibile → `EmbeddingServiceUnavailableException`.
- [ ] Batch size = 32: lista di 100 testi → 4 richieste HTTP al sidecar (3×32 + 1×4).
- [ ] Configurazione `embeddings.sidecar.url` e `embeddings.batch-size` in `application.yaml`.
