# TSK-101 — Implementa FilingChunkingService — split testo + RecursiveCharSplitter-equivalent

## Cosa fare

1. Creare `FilingChunkingService` in `./src/backend/src/main/kotlin/com/valueinvesting/service/FilingChunkingService.kt`.
2. Il servizio espone il metodo: `chunk(text: String): List<TextChunk>` dove `TextChunk(index: Int, content: String)`.
3. Algoritmo di split (Recursive Character Splitter-equivalent):
   - Separatori di priorità decrescente: `"\n\n\n"`, `"\n\n"`, `"\n"`, `" "`, `""`.
   - Chunk size: 6000 caratteri (configurabile via `chunking.chunk-size`).
   - Overlap: 400 caratteri (configurabile via `chunking.chunk-overlap`).
   - Se un singolo separatore produce chunk > chunk-size, ricorsivamente divide con il separatore di priorità inferiore.
4. Parametri esposti in `application.yaml`: `chunking.chunk-size = 6000`, `chunking.chunk-overlap = 400`.
5. Il metodo è puro (no side effect, no DB): riceve testo e restituisce lista di chunk.

## Acceptance Criteria

- [ ] `chunk("a".repeat(12000))` produce almeno 2 chunk di ≈ 6000 caratteri con overlap di 400.
- [ ] Chunk size e overlap sono configurabili via `application.yaml` senza ricompilare.
- [ ] Un testo di 100 caratteri produce 1 solo chunk (nessuna divisione inutile).
- [ ] I chunk contigui si sovrappongono degli ultimi 400 caratteri del chunk precedente.
