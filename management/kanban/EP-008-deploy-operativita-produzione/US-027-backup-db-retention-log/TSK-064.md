# TSK-064 — Scheduled purge fmp_api_event_log 90 giorni

## Context

Runbook US-027: retention tabella `fmp_api_event_log` 90 giorni, purge giornaliero. Tabella creata in V008 (Sprint 3).

## Technical Specs

- **BE:** `@Scheduled(cron = "0 0 3 * * *")` (o equivalente UTC) in servizio dedicato o `FmpEventLogMaintenanceJob`.
- **SQL:** `DELETE FROM fmp_api_event_log WHERE created_at < :cutoff` con cutoff `now() - 90 days`.
- **Config:** property opzionale `fmp.event-log.retention-days` default 90.
- **Test:** `@DataJpaTest` o integration con clock — inserire record vecchi → job → asserire cancellati.
[^src: src/backend/src/main/resources/db/migration/V008__create_fmp_event_log.sql]

4. Loggare count righe eliminate (INFO, no PII).
