# US-026 — Baseline target deploy e infrastruttura runtime

## Descrizione
Come operatore responsabile del go-live, voglio un target di deploy formalizzato (ambiente cloud o on-prem, modalità esecuzione container, requisiti minimi di risorse), affinché il team possa provisionare infrastruttura coerente con l'immagine Docker già prodotta.

## Business Rules
- La decisione copre almeno: provider/ambiente target, modalità deploy (servizio container gestito, orchestrator, VM singola), requisiti CPU/RAM minimi per backend + database + frontend statico.
- Il frontend statico e il backend API sono deployabili secondo il modello scelto in US-023 (export statico vs runtime).
- Segreti (API key provider, JWT secret) gestiti via meccanismo del target (env, secret manager) — non in repository.
- ADR deployment (ADR-009 appendice o v2) è la fonte canonica L4.
