# TSK-067 — Esecuzione checklist cutover con registro

## Context

US-028 AC: checklist ≥15 voci in L4/runbook eseguita in staging con esito tracciato. Runbook già contiene tabelle Gate/Infra/App/Smoke — task = esecuzione + registro.
[^src: design_&_architecture/operations/deploy-runbook-r11.md §Checklist cutover R1.1]
[^src: management/kanban/EP-008-deploy-operativita-produzione/US-028-checklist-cutover-r11/US-028.md §Acceptance Criteria]

## Technical Specs

- **Input:** checklist runbook (G1–G3, I1–I6, A1–A7, F1–F5).
- **Output:** `cutover-r11-staging-YYYY-MM-DD.md` sotto cartella US-028 con tabella | # | Voce | Owner | PASS/FAIL | Note |
- **Gate:** G1 richiede EP-007 TSK done; verificare prima di go-live.
- **Automazione parziale:** mappare voci F* a esito TSK-066; I/A miste manuali + curl script.

## Implementation Steps

1. Copiare template checklist da runbook.
2. Eseguire ogni voce su staging annotando evidenza (curl output, screenshot ref).
3. Segnare item critici non verificati come FAIL (blocco go-live).
4. Consegnare registro al release manager.

## Definition of Done

- [ ] ≥15 voci con PASS/FAIL esplicito.
- [ ] Data ed esecutore nel registro.
- [ ] Nessun item critico (G*, I1–I4, A1, F1–F2) in stato non verificato per go-live approvato.
