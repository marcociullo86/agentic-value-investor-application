# TSK-030 — Bootstrap frontend: Next.js App Router + Tailwind + Zustand + API client

## Obiettivo

Configurare il progetto frontend con tutti i prerequisiti infrastrutturali che gli altri
task FE presuppongono.

## Scope tecnico

- `src/frontend/package.json`: dipendenze `next`, `react`, `react-dom`, `zustand`,
  `recharts`, `ag-grid-community`, `@radix-ui/*`, `tailwindcss`, `openapi-typescript`
  (o `orval`), `axios`.
  [^src: design_&_architecture/decisions/ADR-001-frontend-stack.md §Decisione]
- `next.config.js`: modalità SPA (`output: 'export'`), proxy `/api/*` → `localhost:8080`
  per dev.
  [^src: design_&_architecture/decisions/ADR-009-deployment-target.md §Dev locale]
- `tailwind.config.ts`: configurazione base, `class` strategy per dark mode.
  [^src: design_&_architecture/components/frontend-components.md §Design system]
- `lib/api/client.ts`: axios instance con interceptor auth (Bearer) + interceptor 401
  (refresh + logout) + estrazione header `X-Data-Snapshot-At` / `X-Data-Stale`.
  [^src: design_&_architecture/components/frontend-components.md §API client]
- Script `generate:api` in `package.json`: genera `lib/api/generated/` da
  `design_&_architecture/api/openapi.yaml`.
- `app/layout.tsx`: root layout, `AuthProvider`, Toaster.
  [^src: design_&_architecture/components/frontend-components.md §app/layout.tsx]
- `components/ui/`: Button, Input, Card, Modal base (Tailwind + Radix).
- `lib/utils/formatters.ts` e `signal-color.ts`.

## Criteri di completamento (DoD)

- [ ] `npm run dev` avvia l'app su porta 3000 senza errori.
- [ ] `npm run generate:api` produce tipi TS da `openapi.yaml`.
- [ ] `npm run build` (static export) produce `out/` senza errori.
- [ ] Client API generato: interfacce TypeScript aderenti allo schema OpenAPI.
