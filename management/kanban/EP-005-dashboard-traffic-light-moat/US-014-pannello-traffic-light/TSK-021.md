# TSK-021 — TrafficLightPanel, RuleSignalCard, ValuationSummary

## Obiettivo

Implementare i componenti del pannello Traffic Light che visualizzano il risultato
del Rule Engine per un ticker.

## Scope tecnico

- `components/analysis/TrafficLightPanel.tsx`: riceve `RuleEngineResult`, renderizza
  tutti i segnali come `RuleSignalCard`.
  [^src: design_&_architecture/components/frontend-components.md §analysis/TrafficLightPanel]
- `RuleSignalCard.tsx`: semaforo cliccabile che espande valore osservato e soglia.
  - Codifica colore Tailwind: GREEN=`bg-green-500`, YELLOW=`bg-amber-500`,
    RED=`bg-red-500`, INDETERMINATE=`bg-slate-400`.
    [^src: design_&_architecture/components/frontend-components.md §Design system §Codifica colore Traffic Light]
  - Alternativa testuale accessibile: `aria-label` + label visibile ("OK" / "Attenzione" /
    "Non soddisfatta" / "Indeterminato").
    [^src: management/kanban/EP-005-dashboard-traffic-light-moat/US-014-pannello-traffic-light/US-014.md §AC]
  - ADR-001: React + Next.js SPA.
    [^src: design_&_architecture/decisions/ADR-001-frontend-stack.md]
- `ValuationSummary.tsx`: mostra Graham Number, DCF, MoS signal con valori e prezzo
  corrente di riferimento.
  [^src: design_&_architecture/components/frontend-components.md §analysis/ValuationSummary]
- `lib/store/useAnalysisStore.ts`: `fetchAnalysis(ticker)` → `GET /api/analysis/{ticker}`,
  popola `byTicker[ticker]`.
  [^src: design_&_architecture/components/frontend-components.md §useAnalysisStore]
- `app/analysis/[ticker]/page.tsx`: carica analisi all'mount, mostra `TrafficLightPanel` +
  `ValuationSummary`.
  [^src: design_&_architecture/components/frontend-components.md §Routing]

## Criteri di completamento (DoD)

- [ ] 6+ semafori visibili in dashboard per ticker con analisi completa.
- [ ] Click semaforo espande valore e soglia.
- [ ] Codifica: 4 stati visivamente distinti + label testuale alternativa.
- [ ] Stato WCAG AA: contrasto 4.5:1 verificato.
- [ ] Unit test Vitest + RTL: rendering con mock `RuleEngineResult`, click espansione,
  rendering INDETERMINATE.
