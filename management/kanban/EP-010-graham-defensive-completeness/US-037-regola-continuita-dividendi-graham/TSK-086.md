# TSK-086 — Test integrazione DividendContinuityRule + contratto adapter getDividendHistory

## Cosa fare

1. Creare `DividendContinuityRuleTest.kt` con test unitari:
   - **Verde**: fixture con 20 anni di pagamenti consecutivi → `GREEN`, `consecutiveYears = 20`.
   - **Giallo**: fixture con 17 anni consecutivi → `YELLOW`, `consecutiveYears = 17`.
   - **Rosso**: fixture con 12 anni → `RED`.
   - **Indeterminato**: lista vuota → `INDETERMINATE`.
2. Creare `FmpAdapterDividendHistoryTest.kt` con test di contratto adapter:
   - WireMock: `/stable/historical-price-full/stock_dividend?symbol=AAPL` restituisce fixture JSON con 20 anni → verifica lista DividendRecord mappata correttamente.
   - WireMock: risposta vuota (`[]`) → lista vuota senza eccezione.
   - WireMock: risposta 404 → lista vuota senza eccezione.
   - WireMock: seconda chiamata entro TTL → nessuna nuova HTTP call (cache hit).
3. Integration test: `GET /api/analysis/{ticker}` include `DIVIDEND_CONTINUITY_20Y` nel response.

## Acceptance Criteria

- [ ] Test Verde/Giallo/Rosso/Indeterminato tutti passano.
- [ ] Contratto adapter: serie completa mappata, lista vuota su 404, cache hit verificato.
- [ ] Integration test: `DIVIDEND_CONTINUITY_20Y` presente nel response API.
