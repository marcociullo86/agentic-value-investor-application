# TSK-083 — Estendi FmpAdapter con getDividendHistory (endpoint /stable/historical-price-full/stock_dividend)

## Cosa fare

1. Aggiungere il metodo `getDividendHistory(ticker: String, years: Int = 20): List<DividendRecord>` all'interfaccia `FmpAdapter`.
2. Aggiungere il DTO `DividendRecord` con almeno i campi: `date: LocalDate?`, `dividend: Double?`, `adjDividend: Double?`, `label: String?` (nullable-aware per regola US-004).
3. Implementare il metodo in `FmpAdapterRestClient` chiamando `GET /stable/historical-price-full/stock_dividend?symbol={ticker}&from={date-20y}&apikey={key}`.
4. Il metodo filtra i record con `date >= (today - years * 365)` restituendo solo gli ultimi `years` anni.
5. Rispettare il contratto additive: non breaking per i metodi FmpAdapter preesistenti.
6. La chiamata è cacheable: TTL 24h coerente con il pattern `FmpCacheService` (TSK-010).
7. Gestire `404` e lista vuota come risultato vuoto (non eccezione), coerente con regola "campi mancanti = assenti".

## Acceptance Criteria

- [ ] L'interfaccia `FmpAdapter` espone `getDividendHistory(ticker, years)`.
- [ ] Per AAPL (dividendi dal 2012) il metodo restituisce lista non vuota di `DividendRecord`.
- [ ] Per un ticker senza dividendi il metodo restituisce lista vuota senza eccezione.
- [ ] I campi `date`, `dividend` sono nullable: nessun NPE se l'API FMP omette un campo.
- [ ] La chiamata per lo stesso ticker entro TTL 24h viene servita dalla cache (no nuova HTTP call).
- [ ] Nessuna regressione sui metodi FmpAdapter preesistenti.
