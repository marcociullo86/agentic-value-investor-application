# TSK-285 — BE — Estendi FmpAdapter con getDividendHistory (endpoint /stable/dividends)

## Context

US-037 richiede l'aggiunta del metodo `getDividendHistory(ticker: String): List<DividendRecord>` all'interfaccia `FmpAdapter`, wrappando l'endpoint FMP `/stable/dividends?symbol={ticker}`. Il filtro temporale viene applicato lato consumer (`DividendContinuityRule`, TSK-287), non dall'adapter.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-037-regola-continuita-dividendi-graham/US-037.md §Business Rules]
[^src: wiki/concepts/seven-criteria-defensive-stock-selection.md §Criterio 4 — Regolarita' dei Dividendi]

## Technical Specs

**Endpoint FMP verificato:**
- Path: `GET https://financialmodelingprep.com/stable/dividends?symbol={ticker}&apikey={key}`
- URL doc: `https://site.financialmodelingprep.com/developer/docs/stable/dividends-company`

**DTO `DividendRecord`:**
```
date: LocalDate?          // ex-dividend date (primary key logica)
recordDate: LocalDate?
paymentDate: LocalDate?
declarationDate: LocalDate?
dividend: Double?         // importo dichiarato
adjDividend: Double?      // importo aggiustato per split
yield: Double?
frequency: String?        // es. "Quarterly", "Annual"
```
Tutti i campi nullable (regola US-004: campi mancanti = assenti, mai 0).

**Comportamenti:**
- Risposta ordinata per `date` decrescente (più recente prima)
- `404` e lista vuota → lista vuota, nessuna eccezione
- Cacheable: TTL 24h coerente con il pattern `FmpCacheService`
- Contratto additive: non breaking per i metodi `FmpAdapter` preesistenti

## Implementation Steps

1. Aggiungere `getDividendHistory(ticker: String): List<DividendRecord>` a `FmpAdapter.kt`
2. Creare `DividendRecord` DTO con tutti i campi nullable + Jackson deserialization
3. Implementare il metodo in `FmpAdapterRestClient`: `GET /stable/dividends?symbol={ticker}&apikey={key}`
4. Gestire 404 e lista vuota come risultato vuoto
5. Integrare con `FmpCacheService` (TTL 24h, chiave cache `dividends-{ticker}`)
6. Eseguire una verifica empirica con curl su AAPL per confermare i nomi field Jackson prima di finalizzare il mapper

## Definition of Done

- [ ] `FmpAdapter` espone `getDividendHistory(ticker): List<DividendRecord>`
- [ ] Per AAPL il metodo restituisce lista non vuota con campi popolati
- [ ] Per ticker senza dividendi (es. GOOGL pre-2024) restituisce lista vuota senza eccezione
- [ ] Tutti i campi `DividendRecord` sono nullable (nessun NPE su campo assente)
- [ ] Chiamata cache-hit entro TTL 24h (nessuna nuova HTTP call)
- [ ] Nessuna regressione sui metodi FmpAdapter preesistenti
