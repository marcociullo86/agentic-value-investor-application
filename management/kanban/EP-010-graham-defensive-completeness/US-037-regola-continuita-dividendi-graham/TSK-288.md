# TSK-288 — QA — Test DividendContinuityRule + contratto adapter getDividendHistory

## Context

Verifica la `DividendContinuityRule` (TSK-287) e il contratto del nuovo metodo `FmpAdapter.getDividendHistory` (TSK-285). Copre i 4 scenari canonici della US-037 (verde, giallo, rosso, indeterminato) più i casi boundary dell'adapter.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-037-regola-continuita-dividendi-graham/US-037.md §Acceptance Criteria]

## Technical Specs

**Test unitari DividendContinuityRule (JUnit 5 + Mockito):**
- Verde: 20 anni di `DividendRecord` senza gap → `GREEN`, `consecutiveYears = 20`
- Giallo: 17 anni consecutivi (ticker quotato da 17 anni) → `YELLOW`, `consecutiveYears = 17`
- Rosso: gap nell'anno 10 su una serie di 20 → `RED` (serie interrotta)
- Indeterminato: lista vuota → `INDETERMINATE`

**Test contratto adapter getDividendHistory (WireMock):**
- Serie completa 20 anni (AAPL-like): stub `/stable/dividends?symbol=AAPL` → risposta con 80+ record → lista non vuota
- Serie parziale 5 anni: lista con 20 record → correttamente deserializzata
- Lista vuota: risposta `[]` → lista vuota Kotlin, nessuna eccezione
- Ticker inesistente: risposta 404 → lista vuota, nessuna eccezione

**Integration test:** `GET /api/analysis/{ticker}` include `ruleId = DIVIDEND_CONTINUITY_20Y` con `consecutiveYears`

## Implementation Steps

1. Creare `DividendContinuityRuleTest.kt` con i 4 test unitari sulla regola
2. Creare (o estendere) `FmpAdapterRestClientIT` con i 4 test contratto sul metodo adapter
3. Aggiungere assertion `DIVIDEND_CONTINUITY_20Y` nell'IT di `AnalysisControllerIT`
4. `./gradlew test` verde

## Definition of Done

- [ ] Test Verde: 20 anni consecutivi → `GREEN`
- [ ] Test Giallo: 15-19 anni → `YELLOW`
- [ ] Test Rosso: anni interrotti → `RED`
- [ ] Test Indeterminato: lista vuota → `INDETERMINATE`
- [ ] Contratto adapter: 4 casi (serie completa, parziale, vuota, 404) passano
- [ ] Integration test: `ruleId = DIVIDEND_CONTINUITY_20Y` con `consecutiveYears` nel response
- [ ] Nessuna regressione
