# TSK-076 — Test integrazione EarningsStabilityRule (EARNINGS_STABILITY_10Y) — 4 scenari

## Cosa fare

1. Creare `EarningsStabilityRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`.
2. Scrivere test unitari con fixture per i quattro scenari:
   - **Verde**: lista 10 record con `netIncome > 0` → `GREEN`, `yearsPositive = 10`.
   - **Giallo**: lista 10 record con 1 record a `netIncome = -1_000_000` → `YELLOW`, `lossYears` non vuoto.
   - **Rosso**: lista 10 record con 2 record negativi → `RED`.
   - **Indeterminato**: lista con 8 record (< 10 anni) → `INDETERMINATE`.
3. Integration test: `GET /api/analysis/{ticker}` (WireMock FMP) include `EARNINGS_STABILITY_10Y` nel response.

## Acceptance Criteria

- [ ] Test Verde: serie 10/10 → `GREEN`.
- [ ] Test Giallo: serie 9/10 → `YELLOW` con anno di perdita in `lossYears`.
- [ ] Test Rosso: serie 8/10 (2 perdite) → `RED`.
- [ ] Test Indeterminato: serie < 10 anni → `INDETERMINATE`.
- [ ] Integration test: il ruleId `EARNINGS_STABILITY_10Y` compare nel response API.
