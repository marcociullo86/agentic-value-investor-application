# TSK-278 — QA — Test integrazione EarningsStabilityRule (EARNINGS_STABILITY_10Y) — 4 scenari

## Context

Verifica la `EarningsStabilityRule` (TSK-277) con i 4 scenari canonici della US-033: verde (10/10), giallo (9/10), rosso (2+ perdite), indeterminato (serie < 10 anni).
[^src: management/kanban/EP-010-graham-defensive-completeness/US-033-regola-stabilita-utili-graham/US-033.md §Acceptance Criteria]

## Technical Specs

**File:** `EarningsStabilityRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`

**Test unitari (JUnit 5 + Mockito):**
- Verde: 10 `IncomeStatementDto` con `netIncome > 0` → `GREEN`, `yearsPositive = 10`
- Giallo: 9 anni positivi + 1 anno con `netIncome = -1_000_000` → `YELLOW`, `lossYears` con l'anno in perdita
- Rosso: 2 anni con `netIncome < 0` su 10 → `RED`
- Indeterminato: lista con soli 5 record → `INDETERMINATE`

**Integration test:** `GET /api/analysis/{ticker}` (mock FMP) include `ruleId = EARNINGS_STABILITY_10Y` nel response

## Implementation Steps

1. Creare `EarningsStabilityRuleTest.kt` con i 4 test unitari
2. Aggiungere assertion `EARNINGS_STABILITY_10Y` nell'IT di `AnalysisControllerIT`
3. `./gradlew test` verde

## Definition of Done

- [ ] Test Verde: 10 anni positivi → `GREEN`, `yearsPositive = 10`
- [ ] Test Giallo: 9 positivi + 1 perdita → `YELLOW`, `lossYears` valorizzato
- [ ] Test Rosso: 2+ perdite → `RED`
- [ ] Test Indeterminato: serie < 10 anni → `INDETERMINATE`
- [ ] Integration test: `ruleId = EARNINGS_STABILITY_10Y` presente nel response
- [ ] Nessuna regressione sui test preesistenti
