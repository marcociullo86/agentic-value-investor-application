# TSK-080 — Test integrazione Pe3yAvgRule (PE_3Y_AVG) — 4 scenari

## Cosa fare

1. Creare `Pe3yAvgRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`.
2. Test unitari:
   - **Verde**: `price = 120, avgEps3y = 10.0` → `pe3yAvg = 12.0` → `GREEN`.
   - **Giallo**: `price = 180, avgEps3y = 10.0` → `pe3yAvg = 18.0` → `YELLOW`.
   - **Rosso**: `price = 250, avgEps3y = 10.0` → `pe3yAvg = 25.0` → `RED`.
   - **Indeterminato**: `avgEps3y = 0.0` → `INDETERMINATE`.
3. Test boundary: `pe3yAvg = 15.0` esatto → `GREEN` (≤ 15 incluso); `pe3yAvg = 20.0` esatto → `YELLOW` (≤ 20 incluso).
4. Integration test: `GET /api/analysis/{ticker}` include `PE_3Y_AVG` nel response.

## Acceptance Criteria

- [ ] I 4 scenari unitari passano con output atteso.
- [ ] Boundary a 15.0 → `GREEN`; boundary a 20.0 → `YELLOW`.
- [ ] Integration test: ruleId `PE_3Y_AVG` presente nel response.
