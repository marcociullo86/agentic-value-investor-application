# TSK-079 — Implementa Pe3yAvgRule (PE_3Y_AVG) nel RuleEngineService

## Cosa fare

1. Creare `Pe3yAvgRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/Pe3yAvgRule.kt`.
2. Recuperare:
   - `currentPrice` da `FmpAdapter.getQuote(ticker)` (già implementato, campo `price`).
   - `eps` dagli ultimi 3 Income Statement annuali via `FmpAdapter.getIncomeStatement(ticker, limit=3)`.
3. Calcolare `avgEps3y = avg(eps[anni 1,2,3])` (media triennale più recente).
4. Calcolare `pe3yAvg = currentPrice / avgEps3y`.
5. Applicare la logica di segnale:
   - `pe3yAvg <= 15` → `GREEN`
   - `pe3yAvg in (15, 20]` → `YELLOW`
   - `pe3yAvg > 20` → `RED`
   - `avgEps3y <= 0` O `currentPrice == null` O serie EPS < 3 anni → `INDETERMINATE`
6. Il `RuleResult` include: `currentPrice`, `priceTimestamp`, `avgEps3y`, `pe3yAvg`, `thresholdGreen = 15.0`, `thresholdYellow = 20.0`.
7. Registrare `Pe3yAvgRule` nel `RuleEngineService`. `ruleId = PE_3Y_AVG`.

## Acceptance Criteria

- [ ] `GET /api/analysis/{ticker}` include `ruleId = PE_3Y_AVG` con `currentPrice`, `avgEps3y`, `pe3yAvg`.
- [ ] Con `currentPrice = 150`, `avgEps3y = 12.0` → `pe3yAvg = 12.5` → `GREEN`.
- [ ] Con `currentPrice = 150`, `avgEps3y = 9.0` → `pe3yAvg = 16.7` → `YELLOW`.
- [ ] Con `currentPrice = 200`, `avgEps3y = 8.0` → `pe3yAvg = 25.0` → `RED`.
- [ ] Con `avgEps3y = -2.0` → `INDETERMINATE`.
