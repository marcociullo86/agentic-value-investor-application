# TSK-281 — BE — Implementa Pe3yAvgRule (PE_3Y_AVG) nel RuleEngineService

## Context

Implementa il Criterio 6 di Graham (P/E moderato su media triennale) come `Rule`. La formula usa il prezzo corrente diviso la media degli EPS degli ultimi 3 anni, attenuando la ciclicità annuale del rapporto P/E.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-035-regola-pe-moderato-graham/US-035.md §Business Rules]
[^src: wiki/concepts/seven-criteria-defensive-stock-selection.md §Criterio 6 — Rapporto P/E Moderato]

## Technical Specs

- Classe: `Pe3yAvgRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/Pe3yAvgRule.kt`
- Dati:
  - Prezzo corrente: da `FmpAdapter.getQuote(ticker)` (già implementato, campo `price`)
  - EPS triennale: `eps` dagli ultimi 3 `IncomeStatementDto` annuali via `FmpAdapter.getIncomeStatement(ticker, limit=3)`
- Formula: `PE_3Y_AVG = currentPrice / avg(EPS[ultimi 3 anni])`
- Logica segnale:
  - `PE_3Y_AVG <= 15` → `GREEN`
  - `15 < PE_3Y_AVG <= 20` → `YELLOW`
  - `PE_3Y_AVG > 20` → `RED`
  - Media triennale EPS <= 0 o serie EPS < 3 anni → `INDETERMINATE`
- Metadati `RuleResult`: `currentPrice: Double?`, `priceTimestamp: Instant?`, `avgEps3y: Double?`, `pe3yAvg: Double?`
- `ruleId = PE_3Y_AVG`
- Registrare nel `RuleEngineService`

## Implementation Steps

1. Creare `Pe3yAvgRule.kt`
2. Recuperare prezzo corrente da `getQuote` e EPS da `getIncomeStatement(limit=3)`
3. Se serie EPS < 3 record → `INDETERMINATE`
4. Calcolare `avgEps3y = avg(eps[0..2])` — se `avgEps3y <= 0.0` → `INDETERMINATE`
5. Calcolare `pe3yAvg = currentPrice / avgEps3y`; applicare soglie 15/20
6. Includere `priceTimestamp` dai metadati del quote
7. Registrare nel `RuleEngineService`

## Definition of Done

- [ ] `GET /api/analysis/{ticker}` include `ruleId = PE_3Y_AVG` con `currentPrice`, `avgEps3y`, `pe3yAvg`
- [ ] P/E 3y <= 15 → `GREEN`
- [ ] 15 < P/E 3y <= 20 → `YELLOW`
- [ ] P/E 3y > 20 → `RED`
- [ ] Media EPS 3y <= 0 o serie < 3 anni → `INDETERMINATE`
- [ ] Nessuna regressione sui ruleId preesistenti
