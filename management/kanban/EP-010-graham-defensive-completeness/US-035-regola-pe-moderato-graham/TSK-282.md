# TSK-282 — QA — Test integrazione Pe3yAvgRule (PE_3Y_AVG) — 4 scenari

## Context

Verifica la `Pe3yAvgRule` (TSK-281) con i 4 scenari della US-035: verde (<= 15), giallo (15-20), rosso (> 20), indeterminato (EPS media <= 0).
[^src: management/kanban/EP-010-graham-defensive-completeness/US-035-regola-pe-moderato-graham/US-035.md §Acceptance Criteria]

## Technical Specs

**File:** `Pe3yAvgRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`

**Test unitari (JUnit 5 + Mockito):**
- Verde: prezzo=150, avgEps3y=12.0 → PE=12.5 → `GREEN`
- Giallo: prezzo=150, avgEps3y=9.0 → PE=16.7 → `YELLOW`
- Rosso: prezzo=150, avgEps3y=6.0 → PE=25.0 → `RED`
- Indeterminato: avgEps3y = -1.0 → `INDETERMINATE`

**Integration test:** `GET /api/analysis/{ticker}` include `ruleId = PE_3Y_AVG` con `pe3yAvg` valorizzato

## Implementation Steps

1. Creare `Pe3yAvgRuleTest.kt` con i 4 test unitari
2. Aggiungere assertion `PE_3Y_AVG` nell'IT di `AnalysisControllerIT`
3. `./gradlew test` verde

## Definition of Done

- [ ] Test Verde: PE_3Y_AVG <= 15 → `GREEN`
- [ ] Test Giallo: 15 < PE_3Y_AVG <= 20 → `YELLOW`
- [ ] Test Rosso: PE_3Y_AVG > 20 → `RED`
- [ ] Test Indeterminato: EPS media <= 0 → `INDETERMINATE`
- [ ] Integration test: `ruleId = PE_3Y_AVG` con `pe3yAvg` e `currentPrice` nel response
- [ ] Nessuna regressione
