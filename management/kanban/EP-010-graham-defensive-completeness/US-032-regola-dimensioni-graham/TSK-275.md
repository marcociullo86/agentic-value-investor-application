# TSK-275 — BE — Implementa SizeRule (SIZE_LATEST) nel RuleEngineService

## Context

Implementa il Criterio 1 di Graham (dimensioni adeguate) come `Rule` nel RuleEngineService. La regola verifica che il fatturato annuo dell'azienda superi i $100M, escludendo automaticamente le aziende troppo piccole dal portafoglio difensivo.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-032-regola-dimensioni-graham/US-032.md §Business Rules]
[^src: wiki/concepts/seven-criteria-defensive-stock-selection.md §Criterio 1 — Dimensioni Adeguate dell'Azienda]

## Technical Specs

- Classe: `SizeRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/SizeRule.kt`
- Dato: `revenue` da `IncomeStatementDto` dell'esercizio annuale più recente via `FmpAdapter.getIncomeStatement(ticker)` (già implementato)
- Logica segnale:
  - `revenue >= 100_000_000` → `GREEN`
  - `revenue < 100_000_000` → `RED` (salvo settore utility — vedi note)
  - `revenue == null` o Income Statement assente → `INDETERMINATE`
- Metadati `RuleResult`: `revenueLatest: Long?`, `thresholdUsd: Long = 100_000_000`
- `ruleId = SIZE_LATEST`
- Registrare `SizeRule` nel registry del `RuleEngineService`

## Implementation Steps

1. Creare `SizeRule.kt` nella cartella delle regole
2. Iniettare `FmpAdapter` (o ricevere il dato precaricato) e leggere `revenue` dall'ultimo `IncomeStatementDto`
3. Applicare la logica di segnale con la costante `private const val SIZE_THRESHOLD_USD = 100_000_000L`
4. Per titoli utility (settore da `CompanyProfileDto.sector`): restituire `INDETERMINATE` se revenue < 100M (threshold alternativa $50M out-of-scope per questa US)
5. Produrre `RuleResult` con `revenueLatest` e `thresholdUsd` nei metadati
6. Aggiungere `SizeRule` al registry `RuleEngineService` senza toccare le regole Buffett preesistenti

## Definition of Done

- [ ] `GET /api/analysis/{ticker}` include `ruleId = SIZE_LATEST` nel payload accanto ai ruleId Buffett
- [ ] Revenue >= 100M → segnale `GREEN` con `revenueLatest` valorizzato e `thresholdUsd = 100000000`
- [ ] Revenue < 100M → segnale `RED`
- [ ] Income Statement assente → segnale `INDETERMINATE`
- [ ] Nessuna regressione sui ruleId Buffett preesistenti (suite test verde)
