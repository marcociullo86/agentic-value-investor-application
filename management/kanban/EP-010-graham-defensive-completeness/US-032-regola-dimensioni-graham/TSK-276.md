# TSK-276 — QA — Test integrazione SizeRule (SIZE_LATEST) — 3 scenari

## Context

Verifica la `SizeRule` (TSK-275) con test unitari per i 3 scenari canonici (verde, rosso, indeterminato) e un integration test che verifica la presenza del `ruleId` nel response di `GET /api/analysis/{ticker}`.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-032-regola-dimensioni-graham/US-032.md §Acceptance Criteria]

## Technical Specs

**File:** `SizeRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`

**Test unitari (JUnit 5 + Mockito):**
- Verde: `IncomeStatementDto(revenue = 500_000_000L)` → `RuleResult(signal = GREEN, revenueLatest = 500_000_000L, thresholdUsd = 100_000_000)`
- Rosso: `IncomeStatementDto(revenue = 50_000_000L)` → `RuleResult(signal = RED, revenueLatest = 50_000_000L)`
- Indeterminato: `getIncomeStatement()` restituisce lista vuota → `RuleResult(signal = INDETERMINATE)`

**Integration test (Testcontainers PostgreSQL + WireMock FMP):**
- `GET /api/analysis/{ticker}` (mock FMP) include `ruleId = SIZE_LATEST` nel campo `ruleResults`
- Riusa fixture WireMock già presente negli IT di `AnalysisControllerIT`

## Implementation Steps

1. Creare `SizeRuleTest.kt` con i 3 test unitari
2. Aggiungere integration test in `AnalysisControllerIT` (o classe dedicata) per verificare presenza `SIZE_LATEST`
3. Eseguire `./gradlew test` — verde su tutti i test inclusi quelli preesistenti

## Definition of Done

- [ ] Test Verde: `SizeRule.evaluate()` con revenue 500M ritorna `GREEN`
- [ ] Test Rosso: `SizeRule.evaluate()` con revenue 50M ritorna `RED`
- [ ] Test Indeterminato: lista Income Statement vuota → `INDETERMINATE`
- [ ] Integration test: `GET /api/analysis/AAPL` (mock FMP) include `ruleId = SIZE_LATEST`
- [ ] Nessuna regressione sui test dei ruleId Buffett preesistenti
