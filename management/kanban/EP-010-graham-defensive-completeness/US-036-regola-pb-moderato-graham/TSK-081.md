# TSK-081 — Implementa PbLatestRule (PB_LATEST) nel RuleEngineService

## Cosa fare

1. Creare `PbLatestRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/PbLatestRule.kt`.
2. Recuperare:
   - `currentPrice` da `FmpAdapter.getQuote(ticker)`.
   - `bookValuePerShare` da `FmpAdapter.getKeyMetrics(ticker, limit=1)` (già implementato in TSK-009).
3. Calcolare `pbLatest = currentPrice / bookValuePerShare`.
4. Applicare la logica di segnale:
   - `pbLatest <= 1.5` → `GREEN`
   - `pbLatest in (1.5, 3.0]` → `YELLOW`
   - `pbLatest > 3.0` → `RED`
   - `bookValuePerShare <= 0` O `bookValuePerShare == null` O `currentPrice == null` → `INDETERMINATE`
5. Il `RuleResult` include: `currentPrice`, `priceTimestamp`, `bookValuePerShare`, `pbLatest`, `thresholdGreen = 1.5`, `thresholdYellow = 3.0`.
6. Registrare `PbLatestRule` nel `RuleEngineService`. `ruleId = PB_LATEST`.

## Acceptance Criteria

- [ ] `GET /api/analysis/{ticker}` include `ruleId = PB_LATEST` con `currentPrice`, `bookValuePerShare`, `pbLatest`.
- [ ] Con `price = 15, bvps = 12.0` → `pbLatest = 1.25` → `GREEN`.
- [ ] Con `price = 30, bvps = 12.0` → `pbLatest = 2.5` → `YELLOW`.
- [ ] Con `price = 60, bvps = 12.0` → `pbLatest = 5.0` → `RED`.
- [ ] Con `bvps = -5.0` (patrimonio netto negativo) → `INDETERMINATE`.
