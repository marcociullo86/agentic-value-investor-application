# TSK-283 — BE — Implementa PbLatestRule (PB_LATEST) nel RuleEngineService

## Context

Implementa il Criterio 7 di Graham (P/Book moderato) come `Rule`. La regola usa il prezzo corrente diviso il `bookValuePerShare` più recente da Key Metrics FMP, con soglia standalone P/B <= 1.5.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-036-regola-pb-moderato-graham/US-036.md §Business Rules]
[^src: wiki/concepts/seven-criteria-defensive-stock-selection.md §Criterio 7 — Rapporto P/Book Moderato]

## Technical Specs

- Classe: `PbLatestRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/PbLatestRule.kt`
- Dati:
  - Prezzo corrente: da `FmpAdapter.getQuote(ticker)` (campo `price`)
  - `bookValuePerShare`: dal Key Metrics più recente via `FmpAdapter.getKeyMetrics(ticker, limit=1)`
- Formula: `PB_LATEST = currentPrice / bookValuePerShare`
- Logica segnale:
  - `PB_LATEST <= 1.5` → `GREEN`
  - `1.5 < PB_LATEST <= 3.0` → `YELLOW`
  - `PB_LATEST > 3.0` → `RED`
  - `bookValuePerShare <= 0` o nullo → `INDETERMINATE`
- Metadati `RuleResult`: `currentPrice: Double?`, `bookValuePerShare: Double?`, `pbLatest: Double?`
- `ruleId = PB_LATEST`
- Registrare nel `RuleEngineService`
- Nota: il vincolo combinato P/E x P/B <= 22.5 è gestito dal `ruleId` grahamNumber preesistente; questa US si limita alla soglia P/B standalone

## Implementation Steps

1. Creare `PbLatestRule.kt`
2. Recuperare `bookValuePerShare` dal primo record Key Metrics
3. Se `bookValuePerShare == null` o `<= 0.0` → `INDETERMINATE`
4. Calcolare `pbLatest = currentPrice / bookValuePerShare`; applicare soglie 1.5/3.0
5. Registrare nel `RuleEngineService`

## Definition of Done

- [ ] `GET /api/analysis/{ticker}` include `ruleId = PB_LATEST` con `currentPrice`, `bookValuePerShare`, `pbLatest`
- [ ] P/B <= 1.5 → `GREEN`
- [ ] 1.5 < P/B <= 3.0 → `YELLOW`
- [ ] P/B > 3.0 → `RED`
- [ ] `bookValuePerShare <= 0` o nullo → `INDETERMINATE`
- [ ] Nessuna regressione sui ruleId preesistenti
