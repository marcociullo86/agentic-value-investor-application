# TSK-284 — QA — Test integrazione PbLatestRule (PB_LATEST) — 4 scenari

## Context

Verifica la `PbLatestRule` (TSK-283) con i 4 scenari della US-036: verde (<= 1.5), giallo (1.5-3.0), rosso (> 3.0), indeterminato (BVPS <= 0).
[^src: management/kanban/EP-010-graham-defensive-completeness/US-036-regola-pb-moderato-graham/US-036.md §Acceptance Criteria]

## Technical Specs

**File:** `PbLatestRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`

**Test unitari (JUnit 5 + Mockito):**
- Verde: prezzo=15.0, BVPS=12.0 → PB=1.25 → `GREEN`
- Giallo: prezzo=30.0, BVPS=15.0 → PB=2.0 → `YELLOW`
- Rosso: prezzo=60.0, BVPS=12.0 → PB=5.0 → `RED`
- Indeterminato: BVPS=-2.0 → `INDETERMINATE`

**Integration test:** `GET /api/analysis/{ticker}` include `ruleId = PB_LATEST` con `pbLatest` e `bookValuePerShare`

## Implementation Steps

1. Creare `PbLatestRuleTest.kt` con i 4 test unitari
2. Aggiungere assertion `PB_LATEST` nell'IT di `AnalysisControllerIT`
3. `./gradlew test` verde

## Definition of Done

- [ ] Test Verde: PB_LATEST <= 1.5 → `GREEN`
- [ ] Test Giallo: 1.5 < PB_LATEST <= 3.0 → `YELLOW`
- [ ] Test Rosso: PB_LATEST > 3.0 → `RED`
- [ ] Test Indeterminato: BVPS <= 0 o nullo → `INDETERMINATE`
- [ ] Integration test: `ruleId = PB_LATEST` presente con metadati nel response
- [ ] Nessuna regressione
