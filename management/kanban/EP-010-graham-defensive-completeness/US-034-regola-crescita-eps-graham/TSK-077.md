# TSK-077 — Implementa EpsGrowthRule (EPS_GROWTH_10Y) nel RuleEngineService

## Cosa fare

1. Creare `EpsGrowthRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/EpsGrowthRule.kt`.
2. Recuperare la serie storica dei 10 Income Statement annuali via `FmpAdapter.getIncomeStatement(ticker, limit=10)`.
3. Estrarre il campo `eps` per ciascun anno (ordine cronologico ascendente: anno 1 = più vecchio).
4. Calcolare:
   - `avgEpsInitial = avg(eps[anni 1,2,3])` (media triennale iniziale)
   - `avgEpsFinal = avg(eps[anni 8,9,10])` (media triennale finale)
   - `growth = (avgEpsFinal - avgEpsInitial) / avgEpsInitial`
5. Applicare la logica di segnale:
   - `growth >= 0.33` → `GREEN`
   - `growth in [0.0, 0.33)` → `YELLOW`
   - `growth < 0.0` → `RED`
   - `avgEpsInitial <= 0` O serie < 10 anni O `eps == null` per 3+ record → `INDETERMINATE`
6. Il `RuleResult` include: `avgEpsInitial`, `avgEpsFinal`, `growthPct` (formattato come percentuale), `thresholdPct = 33.0`.
7. Registrare `EpsGrowthRule` nel `RuleEngineService`. `ruleId = EPS_GROWTH_10Y`.

## Acceptance Criteria

- [ ] `GET /api/analysis/{ticker}` include `ruleId = EPS_GROWTH_10Y` nel payload con `avgEpsInitial`, `avgEpsFinal`, `growthPct`.
- [ ] Con `avgEpsInitial = 1.0`, `avgEpsFinal = 1.40` → `GREEN` (growth = 40% > 33%).
- [ ] Con `avgEpsInitial = 1.0`, `avgEpsFinal = 1.20` → `YELLOW` (growth = 20%, in fascia 0-33%).
- [ ] Con `avgEpsInitial = 1.0`, `avgEpsFinal = 0.90` → `RED` (growth negativo).
- [ ] Con `avgEpsInitial = -0.5` → `INDETERMINATE` (denominatore non significativo).
- [ ] Con serie < 10 anni → `INDETERMINATE`.

## Note implementative

- La formula usa medie triennali per attenuare la ciclicità annuale: anni 1-2-3 per la baseline, anni 8-9-10 per il finale. [^src: US-034 §Business Rules]
- Se un singolo anno EPS è null nella triennale, escluderlo dalla media (non trattarlo come 0).
- Se la triennale è calcolabile su 2 soli anni (1 null), procedere ugualmente.
- Stack: Kotlin 2.2 + Spring Boot 3.5. [^src: raw/tech_stack.md]
