# TSK-280 — QA — Test integrazione EpsGrowthRule (EPS_GROWTH_10Y) — 5 scenari

## Context

Verifica la `EpsGrowthRule` (TSK-279) con i 5 scenari della US-034: verde (>= 33%), giallo (0%-33%), rosso (<= 0%), indeterminato per denominatore nullo, indeterminato per serie breve.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-034-regola-crescita-eps-graham/US-034.md §Acceptance Criteria]

## Technical Specs

**File:** `EpsGrowthRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`

**Test unitari (JUnit 5 + Mockito):**
- Verde: EPS da 0.50 (anno 1-3 avg=0.50) a 0.75 (anno 8-10 avg=0.75) → growth=50% → `GREEN`
- Giallo: EPS avg iniziale 1.00, avg finale 1.20 → growth=20% → `YELLOW`
- Rosso: EPS avg iniziale 2.00, avg finale 1.50 → growth=-25% → `RED`
- Indeterminato (denominatore nullo): avg iniziale EPS = -0.10 → `INDETERMINATE`
- Indeterminato (serie breve): solo 7 record su 10 → `INDETERMINATE`

**Integration test:** `GET /api/analysis/{ticker}` include `ruleId = EPS_GROWTH_10Y` con `growthPct` valorizzato

## Implementation Steps

1. Creare `EpsGrowthRuleTest.kt` con i 5 test unitari
2. Aggiungere assertion `EPS_GROWTH_10Y` nell'IT di `AnalysisControllerIT`
3. `./gradlew test` verde

## Definition of Done

- [ ] Test Verde: growth >= 33% → `GREEN`
- [ ] Test Giallo: growth 0%-33% → `YELLOW`
- [ ] Test Rosso: growth <= 0% → `RED`
- [ ] Test Indeterminato (denominatore ≤ 0): `INDETERMINATE`
- [ ] Test Indeterminato (serie < 10): `INDETERMINATE`
- [ ] Integration test: `ruleId = EPS_GROWTH_10Y` con metadati nel response
- [ ] Nessuna regressione
