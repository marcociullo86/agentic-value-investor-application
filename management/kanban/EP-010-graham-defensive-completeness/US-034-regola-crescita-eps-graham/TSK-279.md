# TSK-279 — BE — Implementa EpsGrowthRule (EPS_GROWTH_10Y) nel RuleEngineService

## Context

Implementa il Criterio 5 di Graham (crescita EPS decennale) come `Rule`. La regola calcola la crescita degli utili per azione su medie triennali (prima triennale vs ultima triennale della finestra decennale), con soglia minima +33%.
[^src: management/kanban/EP-010-graham-defensive-completeness/US-034-regola-crescita-eps-graham/US-034.md §Business Rules]
[^src: wiki/concepts/seven-criteria-defensive-stock-selection.md §Criterio 5 — Crescita degli Utili]

## Technical Specs

- Classe: `EpsGrowthRule : Rule` in `./src/backend/src/main/kotlin/com/valueinvesting/rules/EpsGrowthRule.kt`
- Dato: campo `eps` da `IncomeStatementDto` degli ultimi 10 esercizi annuali (FMP, già wrappato)
- Formula: `growth = (avg(EPS[anni 8-9-10]) - avg(EPS[anni 1-2-3])) / avg(EPS[anni 1-2-3])`
  - Anno 1 = esercizio più vecchio della finestra; anno 10 = più recente
- Logica segnale:
  - `growth >= 0.33` → `GREEN`
  - `0.0 <= growth < 0.33` → `YELLOW`
  - `growth < 0.0` → `RED`
  - Serie < 10 anni o media triennale iniziale <= 0 → `INDETERMINATE`
- Metadati `RuleResult`: `avgEpsInitial: Double?`, `avgEpsFinal: Double?`, `growthPct: Double?`, `thresholdPct: Double = 0.33`
- `ruleId = EPS_GROWTH_10Y`
- Registrare nel `RuleEngineService`

## Implementation Steps

1. Creare `EpsGrowthRule.kt`
2. Recuperare serie EPS da 10 esercizi annuali ordinati per anno crescente (dal più vecchio al più recente)
3. Se record < 10 → `INDETERMINATE`
4. Calcolare `avgInitial = avg(eps[0..2])` e `avgFinal = avg(eps[7..9])`
5. Se `avgInitial <= 0.0` → `INDETERMINATE` (denominatore non definito)
6. Calcolare `growth = (avgFinal - avgInitial) / avgInitial`; applicare soglie
7. Registrare nel `RuleEngineService`

## Definition of Done

- [ ] `GET /api/analysis/{ticker}` include `ruleId = EPS_GROWTH_10Y` con `avgEpsInitial`, `avgEpsFinal`, `growthPct`
- [ ] Growth >= 33% → `GREEN`
- [ ] Growth 0%-33% → `YELLOW`
- [ ] Growth <= 0% → `RED`
- [ ] Media triennale iniziale <= 0 o serie < 10 anni → `INDETERMINATE`
- [ ] Nessuna regressione sui ruleId preesistenti
