# TSK-078 — Test integrazione EpsGrowthRule (EPS_GROWTH_10Y) — 5 scenari

## Cosa fare

1. Creare `EpsGrowthRuleTest.kt` in `./src/backend/src/test/kotlin/com/valueinvesting/rules/`.
2. Test unitari con fixture EPS:
   - **Verde**: `[1.0, 1.1, 0.9, *, *, *, *, 1.4, 1.5, 1.3]` → `GREEN` (avg iniziale ~1.0, avg finale ~1.4, growth 40%).
   - **Giallo**: `[1.0, 1.0, 1.0, *, *, *, *, 1.1, 1.2, 1.1]` → `YELLOW` (growth ~13%).
   - **Rosso**: `[1.0, 1.0, 1.0, *, *, *, *, 0.8, 0.9, 0.7]` → `RED`.
   - **Indeterminato denominatore negativo**: `avgEpsInitial = -0.5` → `INDETERMINATE`.
   - **Indeterminato serie insufficiente**: lista di 8 record → `INDETERMINATE`.
3. Integration test: `GET /api/analysis/{ticker}` include `EPS_GROWTH_10Y` con `growthPct` nel response.

## Acceptance Criteria

- [ ] Verde growth ≥ 33% → `GREEN`.
- [ ] Giallo growth 0-33% → `YELLOW`.
- [ ] Rosso growth < 0% → `RED`.
- [ ] Indeterminato su denominatore ≤ 0 → `INDETERMINATE`.
- [ ] Indeterminato su serie < 10 anni → `INDETERMINATE`.
