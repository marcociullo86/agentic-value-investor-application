# TSK-177 — Infra Gradle task piiLeakDetection post-test CI

## Context
US-061 richiede una batteria di leak detection automatica nella pipeline CI che scansiona i log dei test con regex per PII non redatti, fallendo il build al primo match.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-061-leak-detection-ci/US-061.md §AC]
[^src: design_&_architecture/decisions/ADR-021-structured-logging-pii-redaction.md §5]

## Technical Specs
- **Infra:** Gradle task `piiLeakDetection` in `build.gradle.kts`, eseguito post-test
- **Input:** `test-output.log` generato dai test di integrazione (`@SpringBootTest`)
- **Regex 6+ categorie:** PAN (Luhn-valid 13-19 digit), CVV pattern, IBAN completo, JWT (`eyJ...`), API key pattern, password pattern
- **Output:** al primo match → build failure con report (pattern matchato + log line)
- **Integrazione CI:** task dipende da `test` task Gradle

## Implementation Steps
1. Configurare test per scrivere log in `test-output.log`
2. Creare Gradle task `piiLeakDetection` con regex per 6+ categorie
3. Implementare scansione file con report dettagliato al primo match
4. Integrare nel pipeline CI come task post-test
5. Verificare che con PiiRedactionEncoder attivo → zero match

## Definition of Done
- [ ] Task Gradle `piiLeakDetection` eseguibile
- [ ] Copre 6+ categorie PII
- [ ] Report indica pattern matchato e log line
- [ ] Build fallisce al primo match
- [ ] Code review approvata

## Dependencies
- TSK-175 (PiiRedactionEncoder deve essere configurato per i test di integrazione)
