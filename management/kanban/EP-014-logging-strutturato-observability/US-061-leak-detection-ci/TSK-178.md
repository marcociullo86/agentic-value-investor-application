# TSK-178 — QA Test scenari leak detection CI

## Context
US-061 richiede test che verifichino: (a) un PAN non redatto nel log causa build failure; (b) con PiiRedactionEncoder attivo, zero match.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-061-leak-detection-ci/US-061.md §AC]

## Technical Specs
- **QA:** Test di integrazione che generano log con PII di test intenzionali
- **Scenari:**
  - Test con PAN non redatto nel log → task `piiLeakDetection` fallisce con report
  - Test con JWT completo nel log → task fallisce
  - Batteria copre 6 categorie: PAN, CVV, IBAN, JWT, API key, password
  - Con PiiRedactionEncoder attivo: tutti i test di leak detection passano (zero match)
  - Report indica quale pattern è matchato e quale log line

## Implementation Steps
1. Creare scenari di test che loggano PII intenzionalmente (bypass encoder per test)
2. Verificare che `piiLeakDetection` rileva ogni categoria
3. Eseguire con PiiRedactionEncoder attivo → zero match
4. Verificare formato report (pattern + log line)

## Definition of Done
- [ ] PAN non redatto → build fail con report
- [ ] JWT completo → build fail
- [ ] 6 categorie coperte
- [ ] Con redazione attiva → zero match
- [ ] Code review approvata
