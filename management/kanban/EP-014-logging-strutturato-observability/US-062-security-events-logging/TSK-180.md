# TSK-180 — QA Test SecurityEventLogger: 6 categorie + formato + correlationId

## Context
US-062 richiede verifica che almeno 6 categorie di eventi di sicurezza generano log con formato strutturato corretto.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-062-security-events-logging/US-062.md §AC]

## Technical Specs
- **QA:** JUnit 5 + Spring Boot Test
- **Scenari:**
  - Login fallito → log WARN con userId, motivo, Correlation ID
  - Login riuscito → log INFO con userId, Correlation ID
  - Accesso 403 → log WARN con userId, risorsa, Correlation ID
  - Cambio password → log INFO con userId, senza password
  - Almeno 6 categorie verificate con formato strutturato
  - Tutti gli eventi contengono marker `SECURITY_EVENT`

## Implementation Steps
1. Test login fallito: cattura log, verifica WARN + userId + motivo + correlationId
2. Test login riuscito: verifica INFO + userId + correlationId
3. Test 403: verifica WARN + userId + risorsa
4. Test password change: verifica INFO + userId, assenza password
5. Verifica marker `SECURITY_EVENT` su tutti gli eventi
6. Verifica almeno 6 categorie coperte

## Definition of Done
- [ ] 6 categorie eventi testate
- [ ] Formato strutturato verificato
- [ ] Correlation ID presente in tutti
- [ ] Nessuna password nei log
- [ ] Code review approvata
