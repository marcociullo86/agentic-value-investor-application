# TSK-171 — QA Test formato log JSON/pretty + switch env var + benchmark p99

## Context
US-058 richiede verifica del formato log, switch env var senza rebuild, 7 campi obbligatori e benchmark p99 < 2ms.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-058-logging-strutturato-formato/US-058.md §AC]

## Technical Specs
- **QA:** JUnit 5 + Spring Boot Test
- **Test format prod:** log entry JSON parsabile con Jackson, verifica 7 campi obbligatori presenti
- **Test format dev:** log entry non JSON, contiene colori ANSI
- **Test switch:** cambio `LOG_FORMAT`/`LOG_LEVEL` via property senza rebuild
- **Benchmark:** 1000 richieste sotto carico simulato, p99 logging overhead < 2ms
- **Message style:** verifica messaggi log endpoint principali iniziano con verbo inglese
- **Security:** nessun path filesystem server nelle risposte HTTP di errore

## Implementation Steps
1. Test integrazione: genera log in profilo prod, parsa JSON, asserisci 7 campi
2. Test integrazione: genera log in profilo dev, verifica non è JSON raw
3. Test property switch: LOG_FORMAT=json → LOG_FORMAT=pretty senza rebuild
4. Test property switch: LOG_LEVEL=INFO → LOG_LEVEL=DEBUG
5. Benchmark test: 1000 richieste, misura p99 overhead logging
6. Test message style: verifica verbo iniziale su almeno 3 endpoint
7. Test security: verifica nessun path filesystem in risposte errore

## Definition of Done
- [ ] Test formato JSON prod passa (7 campi obbligatori)
- [ ] Test formato pretty dev passa
- [ ] Test switch env var passa
- [ ] Benchmark p99 < 2ms
- [ ] Code review approvata
