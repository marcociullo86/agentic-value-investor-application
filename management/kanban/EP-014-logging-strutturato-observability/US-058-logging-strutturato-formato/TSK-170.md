# TSK-170 — Logback profili prod/dev + logstash-logback-encoder + AsyncAppender

## Context
US-058 richiede logging strutturato con formato differenziato per ambiente (JSON in prod, pretty-print in dev) e switchabile via env var senza rebuild. Questo task è il fondamento infrastrutturale per tutto EP-014.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-058-logging-strutturato-formato/US-058.md §AC]
[^src: design_&_architecture/decisions/ADR-021-structured-logging-pii-redaction.md §1]

## Technical Specs
- **BE:** `logback-spring.xml` con due profili Spring:
  - `prod`: `logstash-logback-encoder` (net.logstash.logback) con JSON strutturato
  - `dev` (default): `PatternLayoutEncoder` standard con colori ANSI
- **Env vars:** `LOG_FORMAT` (json|pretty), `LOG_LEVEL` (default INFO) — senza rebuild/redeploy
- **Campi obbligatori JSON:** timestamp (ISO 8601 TZ), level, service, traceId, spanId, correlationId, userId, message, context
- **Performance:** `AsyncAppender` wrapping tutti gli appender (buffer 256, neverBlock=true)
- **Dipendenza Gradle:** `net.logstash.logback:logstash-logback-encoder` in `build.gradle.kts`
- **Message style:** verbo inglese all'inizio ("Failed to process..." non "PaymentService.process error")

## Implementation Steps
1. Aggiungere dipendenza `logstash-logback-encoder` in `build.gradle.kts`
2. Creare `logback-spring.xml` in `src/main/resources` con profili `prod` e `dev`
3. Configurare `AsyncAppender` wrapping entrambi gli appender
4. Aggiungere MDC fields per `service` (da `spring.application.name`), `userId`, `correlationId`
5. Configurare variabili d'ambiente `LOG_FORMAT` e `LOG_LEVEL` in `application.yml`
6. Verificare output JSON valido in profilo prod e pretty-print in profilo dev

## Definition of Done
- [ ] Log entry in profilo prod è JSON valido con 7+ campi obbligatori
- [ ] Log entry in profilo dev è pretty-print con colori ANSI
- [ ] Switch `LOG_FORMAT` e `LOG_LEVEL` funziona senza rebuild
- [ ] `AsyncAppender` configurato (neverBlock=true, buffer 256)
- [ ] Test unitario passa
- [ ] Code review approvata
