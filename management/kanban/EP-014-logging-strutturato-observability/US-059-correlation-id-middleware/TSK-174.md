# TSK-174 — QA Test integrazione CorrelationIdFilter

## Context
US-059 richiede verifica completa della propagazione Correlation ID: generazione, propagazione, concorrenza, e inclusione in ProblemDetail.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-059-correlation-id-middleware/US-059.md §AC]

## Technical Specs
- **QA:** JUnit 5 + Spring Boot Test + REST Assured
- **Scenari:**
  - Request senza header → UUID v4 generato, presente in response header
  - Request con header → stesso valore propagato in response header
  - 100% dei log della richiesta contengono correlationId (cattura log output)
  - Due richieste concorrenti → correlationId distinti
  - Risposta errore ProblemDetail → contiene `correlationId` come campo strutturato

## Implementation Steps
1. Test senza header: verifica generazione UUID v4 e presence in response
2. Test con header: verifica propagazione stessa stringa
3. Test log: cattura log output, verifica correlationId nel 100%
4. Test concorrenza: 2 richieste parallele, correlationId distinti
5. Test ProblemDetail: provoca errore, verifica campo correlationId nel body

## Definition of Done
- [ ] 5 scenari di test coperti
- [ ] Test concorrenza dimostra isolamento
- [ ] ProblemDetail include correlationId
- [ ] Code review approvata

- TSK-173 (correlationId in ProblemDetail)
