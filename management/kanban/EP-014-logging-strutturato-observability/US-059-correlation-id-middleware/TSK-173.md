# TSK-173 — BE Estendi GlobalExceptionHandler con correlationId in ProblemDetail

## Context
US-059 AC richiede che il Correlation ID appaia nelle risposte di errore RFC 9457. Il `GlobalExceptionHandler` (ADR-012) va esteso per includere `correlationId` come extension member.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-059-correlation-id-middleware/US-059.md §AC]
[^src: design_&_architecture/decisions/ADR-021-structured-logging-pii-redaction.md §3]

## Technical Specs
- **BE:** Estendere `GlobalExceptionHandler` per aggiungere `correlationId` (da MDC) in tutte le risposte `ProblemDetail`
- **Campo:** `correlationId` come extension member top-level (coerente con ADR-012 flatten)
- **Sorgente:** `MDC.get("correlationId")` iniettato da `CorrelationIdFilter`

## Implementation Steps
1. Nel `GlobalExceptionHandler`, leggere `MDC.get("correlationId")`
2. Aggiungere `correlationId` come proprietà nelle risposte `ProblemDetail`
3. Verificare che tutte le risposte di errore (400, 401, 403, 404, 409, 422, 500) includano il campo

## Definition of Done
- [ ] Tutte le risposte ProblemDetail includono `correlationId`
- [ ] Il valore corrisponde all'header `X-Correlation-Id` della response
- [ ] Test unitario passa
- [ ] Code review approvata

## Dependencies
- TSK-172 (CorrelationIdFilter che popola MDC)
