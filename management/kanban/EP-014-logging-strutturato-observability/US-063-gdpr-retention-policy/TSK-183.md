# TSK-183 — QA Test retention rotazione + pseudonimizzazione

## Context
US-063 richiede verifica del meccanismo di cancellazione automatica (rotazione) e della pseudonimizzazione per diritto all'oblio.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-063-gdpr-retention-policy/US-063.md §AC]

## Technical Specs
- **QA:** JUnit 5 / script test
- **Scenari:**
  - Log operativi più vecchi di 30d vengono rimossi dalla rotazione
  - Security events più vecchi di 1 anno vengono rimossi
  - Script pseudonimizzazione: userId target → sostituito, altri userId intatti
  - Verifica documentazione retention policy nell'ADR

## Implementation Steps
1. Test rotazione: creare file log con date simulate, eseguire rollover, verificare cleanup
2. Test retention security: verificare che file con marker SECURITY_EVENT hanno maxHistory diverso
3. Test pseudonimizzazione: log con 2+ userId, pseudonimizzare uno, verificare l'altro intatto
4. Validare documentazione retention policy

## Definition of Done
- [ ] Rotazione 30d verificata
- [ ] Rotazione 365d security events verificata
- [ ] Pseudonimizzazione funzionante e selettiva
- [ ] Policy documentata e auditabile
- [ ] Code review approvata

## Dependencies
- TSK-181 (retention config Logback)
- TSK-182 (script pseudonimizzazione)
