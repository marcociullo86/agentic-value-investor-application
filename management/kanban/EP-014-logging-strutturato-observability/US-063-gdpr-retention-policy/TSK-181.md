# TSK-181 — BE Logback retention operativi 30d + security events 365d

## Context
US-063 richiede retention differenziata GDPR: log operativi max 30 giorni, security events 1 anno, con cancellazione automatica.
[^src: management/kanban/EP-014-logging-strutturato-observability/US-063-gdpr-retention-policy/US-063.md §AC]
[^src: design_&_architecture/decisions/ADR-021-structured-logging-pii-redaction.md §7]

## Technical Specs
- **BE:** Configurazione in `logback-spring.xml`
- **Operativi:** `RollingFileAppender` con `TimeBasedRollingPolicy` `maxHistory=30`
- **Security events:** `SiftingAppender` dedicato filtrato su marker `SECURITY_EVENT`, `maxHistory=365`
- **Config:** valori in `application.yml` sotto `app.logging.retention`

## Implementation Steps
1. Configurare `RollingFileAppender` con `TimeBasedRollingPolicy` maxHistory=30
2. Configurare `SiftingAppender` per marker `SECURITY_EVENT` con maxHistory=365
3. Integrare con `AsyncAppender` wrapping
4. Esternalizzare valori retention in application.yml

## Definition of Done
- [ ] Log operativi ruotati con maxHistory 30d
- [ ] Security events ruotati con maxHistory 365d
- [ ] Marker `SECURITY_EVENT` filtra correttamente
- [ ] Retention configurabile da yaml
- [ ] Code review approvata
