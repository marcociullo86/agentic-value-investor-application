# TSK-182 — BE Script pseudonimizzazione log per userId (diritto all'oblio)

## Context
US-063 richiede capacità di rimozione o pseudonimizzazione dei log riconducibili a uno specifico utente su richiesta GDPR (diritto all'oblio).
[^src: management/kanban/EP-014-logging-strutturato-observability/US-063-gdpr-retention-policy/US-063.md §AC]
[^src: design_&_architecture/decisions/ADR-021-structured-logging-pii-redaction.md §7]

## Technical Specs
- **BE:** Script shell/Kotlin documentato per pseudonimizzare log di un utente specifico
- **Strategia:** grep per userId nei file log + sed per sostituzione con pseudonimo (`USER_DELETED_<hash>`)
- **Documentazione:** procedura passo-passo per l'operatore (runbook)
- **Scope:** file log locali; per aggregatore centralizzato: documentare API equivalente

## Implementation Steps
1. Creare script `pseudonymize-user-logs.sh` con parametro userId
2. Implementare grep + sed su directory log configurabile
3. Documentare procedura nell'ADR-021 come appendice
4. Testare su log di esempio con userId specifico
