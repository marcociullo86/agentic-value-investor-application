# TSK-237 — QA Verifica codebase no flusso dati carta + validazione ADR PCI-DSS

## Context
US-082 richiede verifica che nessun flusso di dati di carta di pagamento sia implementato e che l'ADR-025 §8 dichiari formalmente PCI-DSS non applicabile.
`pending_clarification: [Q_005]` — ADR-025 (status: proposed) risolve Q_005 ma non ancora accepted.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-082-scope-pci-dss-adr/US-082.md §AC]
[^src: design_&_architecture/decisions/ADR-025-security-hardening-pci-dss.md §8]

## Technical Specs
- **QA:** Verifica documentale + grep/search codebase
- **Scenari:**
  - grep/search codebase: nessun campo PAN, CVV, expiry, card number
  - Nessun provider di pagamento (Stripe, Adyen, etc.) integrato
  - ADR-025 §8 esiste con dichiarazione "PCI-DSS: Non Applicabile" e motivazioni
  - ADR documenta storage token e threat model baseline
  - ADR ha deciders documentati

## Implementation Steps
1. grep/rg nel codebase per pattern PAN/CVV/card/payment/stripe/adyen
2. Verificare che nessun flusso pagamento è implementato
3. Verificare ADR-025 §8 contenuto e dichiarazione formale
4. Verificare che ADR documenta storage token e threat model
5. Report risultati

## Definition of Done
- [ ] Zero match pattern pagamento nel codebase
- [ ] ADR PCI-DSS dichiarazione presente
- [ ] Storage token documentato
- [ ] Threat model baseline documentato
- [ ] Code review approvata

## Dependencies
Nessuna — verifica documentale.
