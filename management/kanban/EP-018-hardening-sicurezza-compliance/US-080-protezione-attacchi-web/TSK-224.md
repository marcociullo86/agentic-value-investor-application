# TSK-224 — QA Test CSP + CSRF: header, XSS, CSRF 403, SameSite, E2E

## Context
US-080 AC richiede verifica CSP, XSS bloccato, CSRF protection, SameSite e nessuna regressione E2E.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-080-protezione-attacchi-web/US-080.md §AC]

## Technical Specs
- **QA:** JUnit 5 + Playwright
- **Scenari:**
  - Header Content-Security-Policy presente su tutte le response con script-src senza unsafe-inline
  - XSS reflected (`<script>alert(1)</script>` in query param) bloccato dalla CSP
  - POST /api/auth/refresh senza CSRF token → 403
  - Cookie SameSite=Strict verificato
  - Tutti i test E2E esistenti passano con CSP attiva (no regressione)
  - CSP configurata come header HTTP (non meta tag)

## Implementation Steps
1. Test header: verifica CSP presente su response BE e FE
2. Test XSS: inject payload riflesso, verifica bloccato
3. Test CSRF: POST refresh senza X-CSRF-Token → 403
4. Test SameSite: verifica attributo cookie
5. Test E2E: suite completa con CSP attiva

## Definition of Done
- [ ] CSP header verificato
- [ ] XSS reflected bloccato
- [ ] CSRF 403 senza token
- [ ] SameSite=Strict confermato
- [ ] E2E passano con CSP
- [ ] Code review approvata

## Dependencies
- TSK-221 (BE CSP)
- TSK-222 (FE CSP nonce)
- TSK-223 (CSRF config)
