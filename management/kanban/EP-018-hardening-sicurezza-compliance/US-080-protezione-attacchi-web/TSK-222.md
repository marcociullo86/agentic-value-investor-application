# TSK-222 — FE Next.js middleware CSP nonce per inline script

## Context
US-080 richiede CSP con nonce per gli script inline generati da Next.js, evitando unsafe-inline su script-src.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-080-protezione-attacchi-web/US-080.md §AC]
[^src: design_&_architecture/decisions/ADR-025-security-hardening-pci-dss.md §2]

## Technical Specs
- **FE:** Estensione `middleware.ts` (o dedicato) per aggiungere CSP header con nonce
- **Nonce:** `crypto.randomUUID()` generato per ogni richiesta
- **CSP FE:**
  ```
  script-src 'self' 'nonce-{nonce}'; style-src 'self' 'unsafe-inline';
  img-src 'self' data: https:; connect-src 'self'; font-src 'self';
  frame-src 'none'; object-src 'none'
  ```
- **Next.js 16:** supporta nonce nativo per inline scripts
- **Propagazione nonce:** tramite headers Next.js per script inline

## Implementation Steps
1. Generare nonce in middleware.ts
2. Aggiungere CSP header con nonce nella response
3. Propagare nonce ai componenti Next.js per inline scripts
4. Verificare che l'applicazione FE funziona con CSP + nonce

## Definition of Done
- [ ] CSP con nonce su tutte le response FE
- [ ] script-src senza unsafe-inline
- [ ] Nonce generato per ogni richiesta
- [ ] Applicazione funzionante
- [ ] Code review approvata

Nessuna.
