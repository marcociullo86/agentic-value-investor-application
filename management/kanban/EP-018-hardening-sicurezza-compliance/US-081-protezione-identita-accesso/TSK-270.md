# TSK-270 — BE CSP allow-list Cloudflare Turnstile in SecurityHeadersConfig

## Context

`SecurityHeadersConfig` (TSK-221) emette una CSP statica con `frame-src 'none'`, `script-src 'self'`, `connect-src 'self'`. Cloudflare Turnstile richiede `https://challenges.cloudflare.com` su tutti e tre questi header per poter rendersi e comunicare con i propri server.

Con `output: 'export'` (ADR-009), il middleware Next.js è attivo solo in `next dev`; in produzione la CSP applicata è quella del BE (Spring Boot `SecurityHeadersConfig`). La CSP del FE Edge middleware (`lib/security/csp.ts`) è già stata aggiornata in TSK-238, ma questo non ha effetto su build statiche servite dal backend.

Senza questo fix, il widget Turnstile è bloccato in produzione dalla CSP BE, rendendo l'AC US-081 "CAPTCHA dopo soglia" di fatto non eseguibile in produzione.

## Technical Specs

- **File target:** `SecurityHeadersConfig.csp()` (backend Spring Boot)
- **Entrambe le varianti** (strict e non-strict) devono essere aggiornate
- **Aggiunte CSP richieste:**
  - `script-src`: aggiungere `https://challenges.cloudflare.com`
  - `frame-src`: sostituire `'none'` con `https://challenges.cloudflare.com`
  - `connect-src`: aggiungere `https://challenges.cloudflare.com`
- L'origine Cloudflare è l'unica eccezione a frame-src; in assenza di CAPTCHA, frame-src rimane 'none'

## Implementation Steps

1. Localizzare `SecurityHeadersConfig` e il metodo `csp()` (o equivalente) che costruisce il valore dell'header `Content-Security-Policy`
2. Aggiornare la variante non-strict: aggiungere `https://challenges.cloudflare.com` a `script-src`, `frame-src`, `connect-src`
3. Aggiornare la variante strict (se presente): stessa aggiunta alle tre direttive
4. Aggiungere unit/integration test che asserti la presenza dell'origine Turnstile in tutte e tre le direttive per entrambe le varianti
5. Verificare che le altre direttive CSP (default-src, img-src, style-src, etc.) restino invariate

## Definition of Done

- [ ] `SecurityHeadersConfig.csp()` variante non-strict include `https://challenges.cloudflare.com` in `script-src`, `frame-src` e `connect-src`
- [ ] `SecurityHeadersConfig.csp()` variante strict include `https://challenges.cloudflare.com` in `script-src`, `frame-src` e `connect-src`
- [ ] Test che verifica la presenza dell'origine Turnstile nelle tre direttive (entrambe le varianti)
- [ ] Widget Turnstile non più bloccato da CSP in build statica servita dal backend
- [ ] Code review approvata
