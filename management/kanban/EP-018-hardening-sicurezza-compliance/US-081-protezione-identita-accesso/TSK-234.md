# TSK-234 — QA Test MFA: enrollment, login TOTP, recovery, disabilitazione

## Context
US-081 AC richiede verifica completa del flusso MFA.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-081-protezione-identita-accesso/US-081.md §AC]

## Technical Specs
- **QA:** JUnit 5 Integration + Playwright E2E
- **Scenari:**
  - Enrollment: POST enroll → secret + QR + recovery codes → verify → MFA enabled
  - Login con MFA: email/password → mfaRequired → challenge con TOTP → access token
  - Recovery code: challenge con recovery code → access token + codice revocato
  - Disabilitazione: DELETE MFA con conferma password → MFA disabled
  - Session ID cambia dopo login riuscito (session fixation protection)
  - Login da IP/device non riconosciuto → evento di sicurezza flaggato

## Implementation Steps
1. Test enrollment completo: enroll → verify → enabled
2. Test login MFA: email/password → challenge → token emesso
3. Test recovery: recovery code funzionante + revocato dopo uso
4. Test disabilitazione: password confirm → MFA off
5. Test session fixation: session ID diverso pre/post login
6. Test new device flag

## Definition of Done
- [ ] Enrollment testato end-to-end
- [ ] Login MFA funzionante
- [ ] Recovery code monouso verificato
- [ ] Disabilitazione verificata
- [ ] Session fixation protection confermata
- [ ] Code review approvata
