# TSK-235 — QA Test rate limiting + brute force: delay, CAPTCHA, lockout

## Context
US-081 AC richiede verifica progressive lockout, CAPTCHA threshold e lockout temporaneo.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-081-protezione-identita-accesso/US-081.md §AC]

## Technical Specs
- **QA:** JUnit 5 Integration
- **Scenari:**
  - 5 tentativi falliti sullo stesso account in 5 min → ritardo progressivo
  - 10 tentativi falliti dallo stesso IP in 5 min → captchaRequired flag
  - 20 tentativi falliti in 15 min → lockout 30 min
  - Post lockout: auto-unlock dopo 30 min
  - Rate limiting: 10 req/5 min login per IP → 429 con Retry-After
  - Login riuscito dopo lockout scaduto → accesso consentito

## Implementation Steps
1. Test delay progressivo: 5 fail → verifica delay nella response
2. Test CAPTCHA threshold: 10 fail IP → verifica flag
3. Test lockout: 20 fail → verifica blocco
4. Test auto-unlock: avanza timer → verifica sblocco
5. Test rate limiting 429: supera limite → verifica Retry-After

## Definition of Done
- [ ] Progressive lockout verificato
- [ ] CAPTCHA threshold flag
- [ ] Lockout 30 min
- [ ] Auto-unlock confermato
- [ ] 429 con Retry-After
- [ ] Code review approvata
