# TSK-228 — BE MfaController: endpoint enroll, verify, challenge, recovery, delete

## Context
US-081 richiede endpoint per enrollment MFA, verifica, challenge durante login, recovery e disabilitazione.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-081-protezione-identita-accesso/US-081.md §AC]
[^src: design_&_architecture/decisions/ADR-025-security-hardening-pci-dss.md §4]

## Technical Specs
- **BE:** `MfaController` in package `controller`
- **Endpoint:**

| Method | Path | Auth | Descrizione |
|---|---|---|---|
| POST | /api/auth/mfa/enroll | Bearer | Genera secret + QR + recovery codes |
| POST | /api/auth/mfa/verify | Bearer | Verifica TOTP per attivare MFA |
| POST | /api/auth/mfa/challenge | mfaToken | Verifica TOTP durante login |
| POST | /api/auth/mfa/recovery | mfaToken | Recovery code per login MFA |
| DELETE | /api/auth/mfa | Bearer | Disabilita MFA (conferma password) |

- **Login flow con MFA:** login con email/password → se MFA enabled: `{ mfaRequired: true, mfaToken: "temp-jwt-5min" }` → challenge con TOTP → access token + Set-Cookie
- **Risposte errore:** RFC 9457 ProblemDetail

## Implementation Steps
1. Creare MfaController con 5 endpoint
2. Implementare flusso enrollment (secret + QR + recovery)
3. Implementare flusso verify (attiva MFA)
4. Implementare flusso challenge (login con TOTP)
5. Implementare recovery code flow
6. Implementare delete MFA (con conferma password)
7. Aggiornare login flow: se MFA enabled → mfaRequired response
8. Aggiornare OpenAPI
