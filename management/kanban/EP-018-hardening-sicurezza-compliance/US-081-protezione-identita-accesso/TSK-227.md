# TSK-227 — BE TotpService: generazione secret, verifica codice, recovery codes

## Context
US-081 richiede MFA TOTP. TotpService gestisce generazione secret, verifica codice e recovery codes.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-081-protezione-identita-accesso/US-081.md §AC]
[^src: design_&_architecture/decisions/ADR-025-security-hardening-pci-dss.md §4]

## Technical Specs
- **BE:** `TotpService` in package `service`
- **Dipendenza:** `dev.samstevens.totp` (libreria TOTP RFC 6238)
- **Funzionalità:**
  - Generazione secret TOTP + QR code URI (otpauth://)
  - Verifica codice TOTP a 6 cifre con finestra temporale ±1
  - Generazione 8 recovery codes random
  - Hash BCrypt dei recovery codes per storage
  - Verifica recovery code one-time (revocato dopo uso)
- **Config:** `app.security.mfa.issuer`, `app.security.mfa.totp-period-seconds`

## Implementation Steps
1. Aggiungere dipendenza `dev.samstevens.totp` in build.gradle.kts
2. Implementare generazione secret + QR URI
3. Implementare verifica TOTP con finestra ±1
4. Implementare generazione + hash BCrypt recovery codes
5. Implementare verifica + revoca recovery code

## Definition of Done
- [ ] Secret TOTP generato correttamente
- [ ] QR code URI valido (otpauth://)
- [ ] Verifica codice TOTP funzionante
- [ ] 8 recovery codes generati e hashati
- [ ] Recovery code monouso (revocato dopo uso)
- [ ] Code review approvata
