# TSK-233 — FE MfaChallengeForm: form TOTP durante login MFA

## Context
US-081 richiede un form per inserimento codice TOTP durante il login quando MFA è abilitato.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-081-protezione-identita-accesso/US-081.md §AC]
[^src: design_&_architecture/decisions/ADR-025-security-hardening-pci-dss.md §4]

## Technical Specs
- **FE:** `components/auth/mfa-challenge-form.tsx`
- **Flusso login MFA:**
  1. Login con email/password → response `{ mfaRequired: true, mfaToken }`
  2. Mostra MfaChallengeForm con input codice TOTP a 6 cifre
  3. Submit → POST /api/auth/mfa/challenge con mfaToken + totpCode
  4. Se valido: riceve access token + Set-Cookie → redirect
  5. Link "Usa codice di recupero" → POST /api/auth/mfa/recovery
- **UX:** input autofocus, 6 cifre, submit automatico al 6° digit (opzionale)
- **Accessibilità:** label, aria-describedby per errori

## Implementation Steps
1. Creare MfaChallengeForm component
2. Implementare rilevamento mfaRequired nella login page
3. Implementare challenge flow con mfaToken
4. Implementare fallback recovery code
5. Integrare con auth store per ricevere access token

## Definition of Done
- [ ] Form TOTP funzionante
- [ ] Login MFA: email/password → challenge → token
- [ ] Recovery code fallback
- [ ] Accessibile (label, errori)
- [ ] Code review approvata
