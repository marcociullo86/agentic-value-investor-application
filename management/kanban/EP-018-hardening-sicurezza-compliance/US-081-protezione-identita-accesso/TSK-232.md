# TSK-232 — FE MfaEnrollmentPage: QR code + verifica + recovery codes

## Context
US-081 richiede una pagina per enrollment MFA con QR code, verifica codice TOTP e display recovery codes.
[^src: management/kanban/EP-018-hardening-sicurezza-compliance/US-081-protezione-identita-accesso/US-081.md §AC]
[^src: design_&_architecture/decisions/ADR-025-security-hardening-pci-dss.md §4]

## Technical Specs
- **FE:** `app/profile/mfa/page.tsx`
- **Flusso enrollment:**
  1. Utente clicca "Attiva MFA" → POST /api/auth/mfa/enroll
  2. Display QR code (otpauth:// URI → QR image) + secret manuale
  3. Input codice TOTP a 6 cifre → POST /api/auth/mfa/verify
  4. Se valido: display 8 recovery codes con istruzione "salva in luogo sicuro"
  5. Conferma "Ho salvato i codici" → redirect profilo
- **Disabilitazione:** conferma password → DELETE /api/auth/mfa
- **Accessibilità:** form accessibile, QR con alt text

## Implementation Steps
1. Creare pagina /profile/mfa
2. Implementare chiamata enroll + display QR code
3. Implementare form verifica TOTP
4. Implementare display recovery codes
5. Implementare disabilitazione MFA

## Definition of Done
- [ ] QR code visibile e scansionabile
- [ ] Verifica TOTP funzionante
- [ ] Recovery codes visualizzati
- [ ] Disabilitazione MFA funzionante
- [ ] Code review approvata
