# TSK-165 — RsiContextEvaluator + contextFlags nel RuleEngineResultResponse

## Cosa fare

1. Creare nuovo package `src/backend/src/main/kotlin/com/valueinvesting/webapp/contextflags/`.
2. Creare il data class `MrMarketRsiFlag`:
   - `flag: MrMarketRsiSignal` (enum: `OVERSOLD`, `NEUTRAL`, `OVERBOUGHT`, `INDETERMINATE`)
   - `rsiLatest: Double?`
   - `rsiTimestamp: Instant?`
   - `periodLength: Int = 14`
   - `timeframe: String = "1day"`
3. Creare `RsiContextEvaluator` (`@Component`):
   - Costruttore inietta `FmpAdapter` (TSK-164).
   - Metodo: `fun evaluate(ticker: String): MrMarketRsiFlag`
   - Chiama `fmpAdapter.getTechnicalIndicator(ticker, "rsi", 14, "1day")`.
   - Prende il record latest (max date), legge `value`.
   - Logica:
     - `value == null` o lista vuota → `INDETERMINATE`
     - `value < 30.0` → `OVERSOLD`
     - `value > 70.0` → `OVERBOUGHT`
     - else → `NEUTRAL`
4. Estendere `RuleEngineResultResponse` (in `src/backend/src/main/kotlin/com/valueinvesting/webapp/api/model/`) con un nuovo campo opzionale:
   ```kotlin
   val contextFlags: ContextFlags? = null,
   ```
   dove `ContextFlags(val mrMarketRsi: MrMarketRsiFlag?, val longTermTrend: LongTermTrendFlag? = null)` — il secondo flag arriva da US-057/TSK-168.
5. Aggiornare `AnalyzeTickerService.analyze()` per chiamare `rsiContextEvaluator.evaluate(ticker)` e popolare `contextFlags.mrMarketRsi` nella response.
6. Estendere OpenAPI `design_&_architecture/api/openapi.yaml` con il nuovo schema `ContextFlags` + `MrMarketRsiFlag` + enum `MrMarketRsiSignal`. NON breaking: campo opzionale.

## Acceptance Criteria

- [ ] `GET /api/analysis/{ticker}` per AAPL include `contextFlags.mrMarketRsi` con `flag, rsiLatest, rsiTimestamp` valorizzati.
- [ ] Per un ticker senza dati RSI il flag è `INDETERMINATE` con `rsiLatest=null`.
- [ ] Il `mosSignal`, `dcfMethod`, i 13 `ruleSignals` NON sono toccati.
- [ ] OpenAPI valida 3.x con il nuovo schema.
- [ ] Test di integrazione (con WireMock `/stable/technical-indicators/rsi` stubbed) coprono 4 scenari: OVERSOLD, NEUTRAL, OVERBOUGHT, INDETERMINATE.
