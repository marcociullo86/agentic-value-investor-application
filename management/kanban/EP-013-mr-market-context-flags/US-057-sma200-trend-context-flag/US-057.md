# US-057 — SMA200 come trend lungo periodo flag

## Descrizione
Come investitore retail value-oriented, voglio vedere un advisory flag basato sulla posizione del prezzo corrente rispetto alla media mobile a 200 giorni (SMA200), affinché possa contestualizzare se sto comprando un titolo in fase di deep value pessimismo (prezzo < SMA200) o di esuberanza (prezzo molto sopra SMA200). Il valore di un titolo VI-positivo è massimo quando coincide con un mercato pessimista sul ticker. [^src: wiki/syntheses/graham-investing-philosophy.md §Mr. Market]

## Business Rules
- Sorgente dato: `GET https://financialmodelingprep.com/stable/technical-indicators/sma?symbol={ticker}&periodLength=200&timeframe=1day&apikey={key}` [^src: raw/fmp_docs.md §Technical Indicators — Simple Moving Average]
- Periodo: 200 giorni (standard de-facto industriale per long-term trend).
- Timeframe: `1day`.
- Valore latest (record più recente della serie).
- Confronto con `currentPrice` da `ProfileDto.price` (già disponibile via `dataset.currentPrice`, EP-010).
- Calcolo: `priceVsSmaPct = (currentPrice - sma200) / sma200`
- Codifica flag:
  - `priceVsSmaPct < -0.05` (prezzo > 5% sotto SMA200) → `BELOW_TREND` (deep value / Mr. Market pessimista).
  - `priceVsSmaPct in [-0.05, +0.20]` → `NEAR_TREND` (allineato alla media lungo periodo).
  - `priceVsSmaPct > +0.20` (prezzo > 20% sopra SMA200) → `ABOVE_TREND` (euforia, rischio "comprare in cima").
  - `sma200 == null` O `currentPrice == null` O sma200 ≤ 0 → `INDETERMINATE`.
- **Il flag NON altera `mosSignal`, `dcfMethod`, né i 13 `ruleSignals`**. È esclusivamente advisory.
- L'output include `sma200Latest`, `currentPrice`, `priceVsSmaPct`, `smaTimestamp`.

## UI Reference
- Badge separato sopra/sotto il TrafficLight, distinto dal flag RSI (US-056).
- Suggerimento: icona freccia (↓ BELOW_TREND, → NEAR_TREND, ↑ ABOVE_TREND) + label numerica % vs SMA200.
- Tooltip: "Prezzo $X / SMA200 $Y = Z.Z% — trend lungo periodo: [bearish/neutral/bullish]. Advisory."

## Acceptance Criteria
- [ ] Per un ticker con `currentPrice=$80`, `sma200=$100` → `priceVsSmaPct = -0.20` → flag `BELOW_TREND`.
- [ ] Per un ticker con `currentPrice=$100`, `sma200=$98` → `priceVsSmaPct ≈ +0.02` → flag `NEAR_TREND`.
- [ ] Per un ticker con `currentPrice=$150`, `sma200=$100` → `priceVsSmaPct = +0.50` → flag `ABOVE_TREND`.
- [ ] Per un ticker senza dati SMA200 → flag `INDETERMINATE`.
- [ ] Per un ticker IPO recente con < 200 giorni di storico (SMA200 ritorna null/vuoto) → flag `INDETERMINATE`.
- [ ] Il response `GET /api/analysis/{ticker}` include `contextFlags.longTermTrend` con `flag, sma200Latest, currentPrice, priceVsSmaPct, smaTimestamp, periodLength=200, timeframe="1day"`.
- [ ] UI: badge separato dal RSI, distinto dal TrafficLight, accessibile (icone con alternativa testuale).
