# TSK-166 — LongTermTrendEvaluator (SMA200) + estensione contextFlags

## Cosa fare

1. Nel package `contextflags` (creato in TSK-165) aggiungere il data class `LongTermTrendFlag`:
   - `flag: LongTermTrendSignal` (enum: `BELOW_TREND`, `NEAR_TREND`, `ABOVE_TREND`, `INDETERMINATE`)
   - `sma200Latest: Double?`
   - `currentPrice: Double?`
   - `priceVsSmaPct: Double?` (es. -0.20 per -20%)
   - `smaTimestamp: Instant?`
   - `periodLength: Int = 200`
   - `timeframe: String = "1day"`
2. Creare `LongTermTrendEvaluator` (`@Component`):
   - Costruttore inietta `FmpAdapter` (TSK-164).
   - Metodo: `fun evaluate(ticker: String, currentPrice: Double?): LongTermTrendFlag`
   - Chiama `fmpAdapter.getTechnicalIndicator(ticker, "sma", 200, "1day")`.
   - Prende il record latest, legge `value` come `sma200`.
   - Logica:
     - `currentPrice == null` O `sma200 == null` O `sma200 <= 0.0` → `INDETERMINATE`
     - `priceVsSmaPct = (currentPrice - sma200) / sma200`
     - `priceVsSmaPct < -0.05` → `BELOW_TREND`
     - `priceVsSmaPct > +0.20` → `ABOVE_TREND`
     - else → `NEAR_TREND`
3. Estendere `ContextFlags` (definito in TSK-165) con il campo `longTermTrend: LongTermTrendFlag?`.
4. Aggiornare `AnalyzeTickerService.analyze()` per chiamare `longTermTrendEvaluator.evaluate(ticker, profile.value.price)` e popolare `contextFlags.longTermTrend`.
5. Estendere OpenAPI con `LongTermTrendFlag` + enum `LongTermTrendSignal`. Non breaking.

## Acceptance Criteria

- [ ] Per `currentPrice=$80`, `sma200=$100` → `priceVsSmaPct=-0.20`, flag `BELOW_TREND`.
- [ ] Per `currentPrice=$100`, `sma200=$98` → flag `NEAR_TREND`.
- [ ] Per `currentPrice=$150`, `sma200=$100` → flag `ABOVE_TREND`.
- [ ] Per IPO recente (< 200 giorni storico, SMA ritorna lista vuota) → `INDETERMINATE`.
- [ ] Per `currentPrice=null` → `INDETERMINATE`.
- [ ] `GET /api/analysis/{ticker}` include `contextFlags.longTermTrend`.
- [ ] OpenAPI valida 3.x.
