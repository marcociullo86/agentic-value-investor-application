# TSK-160 — FE badge "Long-Term Trend" (SMA200 flag)

## Cosa fare

1. Creare il componente `LongTermTrendBadge.tsx` in `src/frontend/components/analysis/`:
   - Props: `flag: "BELOW_TREND" | "NEAR_TREND" | "ABOVE_TREND" | "INDETERMINATE"`, `sma200Latest: number | null`, `currentPrice: number | null`, `priceVsSmaPct: number | null`.
   - Rendering:
     - `BELOW_TREND` → badge con icona `↓` + label "Sotto SMA200 ({pct}%)" + tooltip "Mr. Market depresso sul titolo — deep value potential"
     - `NEAR_TREND` → badge con icona `→` + label "In linea con SMA200 ({pct}%)"
     - `ABOVE_TREND` → badge con icona `↑` + label "Sopra SMA200 (+{pct}%)" + tooltip "Cautela: rischio di acquisto in cima"
     - `INDETERMINATE` → "Trend lungo periodo non disponibile" (es. IPO < 200gg)
   - Color palette distinta da RSI badge e da TrafficLight (suggerimento: monocromatico con icona + percentuale).
   - Tooltip accessibilità: "SMA200 = media mobile a 200 giorni. Advisory tecnico, non sostituisce il giudizio fondamentale."
2. Posizionare il badge nella section "Context Flags" di `AnalysisPageClient.tsx`, accanto a `MrMarketSentimentBadge` (TSK-159).
3. Estendere `RuleEngineResultResponse` TS type per `contextFlags.longTermTrend`.
4. Snapshot test + accessibility check (alt text per icone, contrast).

## Acceptance Criteria

- [ ] Pagina `/analysis/AAPL` mostra badge "Long-Term Trend" accanto a "Mr. Market Sentiment".
- [ ] Icona ↓/→/↑ visibile + alternative testuale per screen reader.
- [ ] Tooltip explicit "advisory, non sostituisce…".
- [ ] Per IPO recente (`INDETERMINATE`) badge visibile in stato muted.
- [ ] Snapshot test verifica i 4 stati.
- [ ] No regression sul TrafficLightPanel né su `MrMarketSentimentBadge` (TSK-159).
