# TSK-014 — Regole solidità finanziaria: CurrentRatioRule e DebtToIncomeRule

## Obiettivo

Implementare le due regole di solidità finanziaria del Rule Engine.

## Scope tecnico

- `CurrentRatioRule`:
  - Current Ratio = Current Assets / Current Liabilities.
  - Verde > 2, Giallo 1.5-2 (con annotazione "stabile-friendly"), Rosso < 1.5.
  [^src: management/kanban/EP-003-rule-engine-quantitativo/US-009-regola-solidita-finanziaria/US-009.md §Business Rules]
- `DebtToIncomeRule`:
  - Debito LT / Utile Netto (anno più recente disponibile).
  - Verde < 4, Rosso > 5.
  - Se Utile Netto nullo o negativo → `INDETERMINATE` (non `RED`).
  [^src: management/kanban/EP-003-rule-engine-quantitativo/US-009-regola-solidita-finanziaria/US-009.md §AC]
- Integrazione in `RuleEngineService.evaluateAll()`.
- `RuleSignal` con `observedValue` (il ratio calcolato) e `threshold` (soglia applicata).

## Criteri di completamento (DoD)

- [ ] Current Ratio 2.5 → `GREEN`.
- [ ] Current Ratio 1.7 → `YELLOW` con rationale "stabile-friendly".
- [ ] Utile Netto negativo → DebtToIncomeRule → `INDETERMINATE`.
- [ ] Unit test: `CurrentRatioRuleTest`, `DebtToIncomeRuleTest` con edge case null.
