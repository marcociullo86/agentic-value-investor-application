# TSK-015 — Regola intensità di capitale: CapexIntensityRule

## Obiettivo

Implementare la regola CapEx/Utile Netto e completare il set di 7 regole in
`RuleEngineService`.

## Scope tecnico

- `CapexIntensityRule`:
  - CapEx / Utile Netto (media 10 anni se disponibile, fallback anno più recente).
  - Verde < 25%, Giallo 25-30%, Rosso > 30%.
  - Se Utile Netto nullo/negativo → `INDETERMINATE`.
  [^src: management/kanban/EP-003-rule-engine-quantitativo/US-010-regola-capitale-intensivo/US-010.md §Business Rules]
- `RuleEngineService.evaluateAll()` completa ora tutte e 7 le strategie:
  ROE, ROIC, GrossMargin, NetMargin, CurrentRatio, DebtToIncome, CapexIntensity.
  [^src: design_&_architecture/components/backend-components.md §RuleEngine §ValuationRule[] (7 strategies)]
- Integrazione in `RuleEngineResult.signals: JSONB` → array con 7+ entry.
  [^src: design_&_architecture/data/er-diagram.md §rule_engine_result §signals]

## Criteri di completamento (DoD)

- [ ] CapEx/Utile < 25% → `GREEN`.
- [ ] CapEx/Utile 27% → `YELLOW`.
- [ ] CapEx/Utile 35% → `RED`.
- [ ] Utile Netto negativo → `INDETERMINATE`.
- [ ] `RuleEngineService.evaluateAll()` produce lista di esattamente 7 segnali su dataset
  completo.
