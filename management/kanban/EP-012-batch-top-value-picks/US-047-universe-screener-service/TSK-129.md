# TSK-129 — Aggiungi costanti SectorBlacklist + SETTORI_BUFFETT_OK e FmpAdapter.companyScreener()

## Cosa fare

1. Creare `SectorConstants.kt` in `./src/backend/src/main/kotlin/com/valueinvesting/service/`:
   ```kotlin
   val SETTORI_BUFFETT_OK = setOf(
     "Consumer Staples", "Consumer Discretionary", "Healthcare",
     "Financials", "Industrials", "Technology", "Communication Services",
     "Energy", "Materials", "Real Estate", "Utilities"
   )
   val SECTOR_BLACKLIST = setOf(
     "Financial Services", // troppo complesse per modello Graham semplificato
     "Biotechnology"       // P&L troppo volatile pre-approvazione farmaci
   )
   ```
   (affinare la lista sulla base di `wiki/runbooks/defensive-investor-checklist.md`).
2. Aggiungere il metodo `companyScreener(exchange: String, marketCapMoreThan: Long, country: String): List<ScreenerResultItem>` all'interfaccia `FmpAdapter`.
3. Creare DTO `ScreenerResultItem`: `ticker`, `companyName`, `marketCap`, `sector`, `exchange` (nullable-aware).
4. Implementare in `FmpAdapterRestClient` chiamando `GET /stable/company-screener?exchange={e}&marketCapMoreThan={m}&country={c}&apikey={key}`.
5. TTL cache: 6h (screener non cambia frequentemente).

## Acceptance Criteria

- [ ] `SETTORI_BUFFETT_OK` e `SECTOR_BLACKLIST` sono costanti documentate e usate da `UniverseScreenerService`.
- [ ] `FmpAdapter.companyScreener("NASDAQ,NYSE", 3_000_000_000, "US")` restituisce lista di `ScreenerResultItem`.
- [ ] Cache hit entro TTL 6h.
- [ ] Nessuna regressione sui metodi FmpAdapter preesistenti.
