# TSK-128 — Implementa NewsScoutService — Claude Opus news scout su top-200 candidati

## Cosa fare

1. Creare `NewsScoutService` in `./src/backend/src/main/kotlin/com/valueinvesting/service/NewsScoutService.kt`.
2. Il servizio espone: `scoutPanicBuyCandidates(candidates: List<UniverseCandidate>): List<String>` (lista di ticker in possibile panic-buy zone).
3. Prende i primi 200 candidati dalla lista pre-filtrata dello screener base.
4. Per ogni candidato: recupera news degli ultimi 30 giorni via `FmpAdapter.getStockNews(ticker, 30)`.
5. Invia a Claude Opus 4.7 un prompt aggregato: "Tra questi 200 ticker, quali mostrano segnali di panic sell temporaneo (calo ≥ 20% nelle ultime 4 settimane con fondamentali invariati)? Rispondi con lista di ticker e motivazione breve."
6. Parser output → lista di ticker.
7. Capped a 50 ticker output per costi LLM (configurabile via `news-scout.max-results`).
8. Se LLM non disponibile: restituisce lista vuota + log WARNING (il news scout è opzionale, non blocca il batch).

## Acceptance Criteria

- [ ] `scoutPanicBuyCandidates(top200)` restituisce lista ≤ 50 ticker.
- [ ] Se LLM non disponibile → lista vuota senza eccezione.
- [ ] Cap `news-scout.max-results` rispettato.
- [ ] Nessuna eccezione non gestita.
