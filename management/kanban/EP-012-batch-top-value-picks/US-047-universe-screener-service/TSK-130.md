# TSK-130 — Test integrazione UniverseScreenerService — mock FMP + mock SEC, deduplicazione, cap 500

## Cosa fare

1. Creare `UniverseScreenerServiceTest.kt` con WireMock FMP + WireMock SEC + mock `NewsScoutService` + mock `AnthropicClient`.
2. Test da implementare:
   - **Happy path**: mock FMP screener restituisce 100 ticker; mock SEC 13-F restituisce 20 ticker (di cui 10 già in screener) → lista finale ≤ 120 candidati deduplicati per ticker.
   - **Cap 500**: mock screener restituisce 600 ticker → lista finale cap a 500.
   - **Cache 6h**: seconda chiamata entro 6h → nessuna nuova HTTP call FMP.
   - **RateLimiter fmp-batch**: verificare che le chiamate usino il RateLimiter `fmp-batch` (non `fmp-online`).
   - **Log finale**: verificare che il log `(runDate, totalCandidates, breakdownBySource, durationMs)` venga emesso.
3. Verificare la deduplicazione cross-source (ticker presente in SCREENER e 13F → source = `THIRTEEN_F` vince).

## Acceptance Criteria

- [ ] Happy path: lista deduplicata con source corretti.
- [ ] Cap 500 rispettato.
- [ ] Cache 6h: nessuna nuova HTTP call.
- [ ] Log finale emesso.
- [ ] Deduplicazione: THIRTEEN_F ha priorità su SCREENER.
