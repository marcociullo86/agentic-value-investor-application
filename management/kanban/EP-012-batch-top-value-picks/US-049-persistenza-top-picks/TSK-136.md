# TSK-136 — Implementa TopValuePickEntity + TopValuePickRepository (Spring Data JPA)

## Cosa fare

1. Creare `TopValuePickEntity` in `./src/backend/src/main/kotlin/com/valueinvesting/repository/TopValuePickEntity.kt`:
   - `@EmbeddedId` con `TopValuePickId(runDate: LocalDate, rank: Int)`.
   - Campi: `ticker`, `verdictClass`, `scoreMos`, `positionSizePct`, `marketCapUsd`, `sector`, `sourcesJson` (String, JSONB), `verdictPayload` (String, JSONB), `createdAt`.
2. Creare `TopValuePickRepository : JpaRepository<TopValuePickEntity, TopValuePickId>`:
   - `findByRunDate(runDate: LocalDate): List<TopValuePickEntity>`
   - `findLatestRunDate(): LocalDate?` (query derivata max)
   - `deleteByRunDateBefore(cutoffDate: LocalDate)` (per retention rolling 365gg)
3. Validazione pre-insert: `rank in 1..30`, `runDate` non null.

## Acceptance Criteria

- [ ] `TopValuePickRepository.save()` persiste un record in `top_value_picks`.
- [ ] `findByRunDate(today)` restituisce i record della run di oggi.
- [ ] `findLatestRunDate()` restituisce la data più recente presente in DB.
- [ ] `deleteByRunDateBefore(cutoff)` rimuove i record fuori dalla finestra 365gg.
- [ ] Insert con `rank = 0` o `rank = 31` → eccezione di validazione.
