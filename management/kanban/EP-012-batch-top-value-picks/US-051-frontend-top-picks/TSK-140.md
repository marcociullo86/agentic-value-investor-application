# TSK-140 — Route /top-picks page + tabella ordinabile (Next.js App Router)

## Cosa fare

1. Creare la route `./src/frontend/app/top-picks/page.tsx` (App Router, Next.js 16.x).
2. Struttura della pagina (ordine fisso):
   - Header: "Classifica del {run_date}" + datepicker (shadcn/ui `<Calendar>` o `<DatePicker>`).
   - Banner: "Aggiornata ogni notte alle 02:00 UTC — ultima run: {run_date}".
   - Tabella principale con colonne: `Rank`, `Ticker` (link a `/analysis/{ticker}/deep`), `Verdict` (badge), `MoS %`, `Position Size`, `Market Cap`, `Sector`, `Sources` (icone).
   - Ordinamento colonne: click sull'header della colonna → ordina ASC/DESC.
   - Paginazione: bottoni Pagina precedente / successiva.
3. Stato vuoto: se `total = 0` → messaggio "Nessuna classifica disponibile per questa data".
4. Stato errore: 400 → "Data non valida"; 503 → "Servizio non disponibile, riprova più tardi".
5. Badge verdict riusato da US-046 (`DeepVerdictBadge`).
6. URL deep-linkable: i filtri attivi sono nei query params della URL (paginazione e data inclusi).
7. Aggiungere link "/top-picks" alla navbar principale.

## Acceptance Criteria

- [ ] La route `/top-picks` carica la classifica dell'ultima `run_date`.
- [ ] Il datepicker permette di selezionare una data storica.
- [ ] La tabella è ordinabile per colonna.
- [ ] Cliccando il ticker → naviga a `/analysis/{ticker}/deep`.
- [ ] Stato vuoto mostrato per data senza run.
- [ ] Stato errore 503 mostrato correttamente.
- [ ] URL deep-linkable: filtri persistono nei query params.
- [ ] Link "/top-picks" nella navbar.
