# TSK-141 — Filtri sidebar/top-bar verdict + sector + marketCap + MoS + useTopPicks SWR hook

## Cosa fare

1. Creare il hook `useTopPicks(params: TopPicksQueryParams)` in `./src/frontend/lib/hooks/useTopPicks.ts`:
   - Chiama `GET /api/top-picks` con i query params mappati.
   - Usa SWR con `revalidateOnFocus: false`.
   - Gestisce stati `isLoading`, `error`, `data`.
2. Creare `TopPicksFilters.tsx` con:
   - Multi-select verdict (checkboxes: APPROVATO, APPROVATO_PANIC_BUY, WATCHLIST).
   - Multi-select sector (derivato dai valori presenti nella classifica).
   - Market cap range slider (min/max da classifica).
   - MoS minimo slider (0-100%).
3. I filtri aggiornano i query params URL (deep-linkable): usare `next/navigation useRouter` + `useSearchParams`.
4. Ogni modifica filtro → il hook `useTopPicks` richiama l'API con i nuovi params.
5. I badge verdict usano la codifica colore di `DeepVerdictBadge` + alternativa testuale.

## Acceptance Criteria

- [ ] Filtro verdict selezionando "APPROVATO" → tabella mostra solo APPROVATO.
- [ ] Filtro sector "Technology" → tabella mostra solo Technology.
- [ ] Slider MoS 20% → solo items con `score_mos >= 20`.
- [ ] I filtri sono riflessi nei query params URL.
- [ ] Incollando l'URL in finestra nuova ripristina gli stessi filtri.
- [ ] Badge verdict hanno `aria-label`.
