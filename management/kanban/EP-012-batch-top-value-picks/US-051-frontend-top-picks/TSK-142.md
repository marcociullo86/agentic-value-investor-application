# TSK-142 — Test E2E Playwright /top-picks — caricamento default, filtro verdict, datepicker, navigazione /deep

## Cosa fare

1. Creare `top-picks.spec.ts` in `./src/frontend/e2e/`.
2. Test da implementare:
   - **Caricamento default**: navigare a `/top-picks` → tabella con ≥ 1 row visibile (mock backend).
   - **Filtro verdict**: selezionare "APPROVATO_PANIC_BUY" nel multi-select → la tabella mostra solo rows con badge "Approvato - Panic Buy".
   - **Datepicker storico**: cliccare il datepicker, selezionare una data di 7 giorni fa → tabella si aggiorna.
   - **Navigazione a /deep**: cliccare il ticker nella prima riga → navigare a `/analysis/{ticker}/deep`.
   - **Stato vuoto**: mock API restituisce `total = 0` → messaggio "Nessuna classifica disponibile".
   - **URL deep-link**: applicare filtro verdict → verificare che il query param `?verdict=APPROVATO_PANIC_BUY` compaia nell'URL.
3. Accessibilità: i badge verdict hanno `aria-label` verificato.

## Acceptance Criteria

- [ ] Caricamento default: tabella visibile.
- [ ] Filtro verdict: solo righe con il verdict selezionato.
- [ ] Datepicker: tabella aggiornata.
- [ ] Navigazione: link a `/deep` funzionante.
- [ ] Stato vuoto: messaggio corretto.
- [ ] Deep-link: filtro nei query params.
