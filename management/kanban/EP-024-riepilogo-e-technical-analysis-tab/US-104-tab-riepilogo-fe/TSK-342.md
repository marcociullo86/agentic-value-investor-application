# TSK-342 — Tab Riepilogo: primo tab, routing, hero, banner anti-COPART

## Obiettivo
Aggiungere il tab "Riepilogo" come PRIMO tab e default attivo del dettaglio ticker, con routing default-redirect, hero verdetto a 4 stati e banner anti-COPART, riusando il pattern di `AnalysisPageClient`.

## Scope

### Posizionamento + routing
- Ordine tab finale: `Riepilogo | Analisi Base | Deep Analysis | Technical Analysis`; "Riepilogo" primo e attivo al landing su `/analysis?ticker=XXX`.
- Routing: default-redirect a `/analysis/{ticker}/summary`; deep-link `/analysis/{ticker}/deep` e `/analysis/{ticker}/technical` preservati (aprono il rispettivo tab).
- Fetch `/api/analysis/{ticker}/summary` al mount del tab (default attivo); skeleton EP-016; errore via `NotificationProvider` EP-015.

### Hero verdetto (4 stati)
- `ENTER_NOW` → "ENTRA ORA" verde + icona check + sub-headline.
- `WAIT_FOR_SETUP` → "ASPETTA" giallo/blu + icona timer + sub-headline con `reentryCondition.description`.
- `AVOID` → "EVITA" rosso + icona stop + sub-headline che spiega quale gate ha bocciato (VI o Munger).
- `INSUFFICIENT_DATA` → "DATI INSUFFICIENTI" grigio + icona info + sub-headline.
- Colore non unico canale: testo + icona (WCAG 2.2 AA).

### Banner anti-COPART
- Visibile solo se `warningAntiCopart` non vuoto; colore alert non-rosso; ruolo ARIA `alert`; link "Approfondisci →" a [[ta-vs-vi-decision-layer]].

## Acceptance Criteria
- [ ] Tab "Riepilogo" primo e attivo al landing su `/analysis?ticker=XXX`; ordine `Riepilogo | Analisi Base | Deep | Technical`.
- [ ] Routing default-redirect a `/summary`; deep-link `/deep` e `/technical` preservati.
- [ ] Hero verdetto copre i 4 stati con colore + icona + testo + sub-headline; ASPETTA mostra `reentryCondition.description`.
- [ ] Banner anti-COPART solo se `warningAntiCopart` non vuoto, ruolo ARIA `alert`, link "Approfondisci →".
