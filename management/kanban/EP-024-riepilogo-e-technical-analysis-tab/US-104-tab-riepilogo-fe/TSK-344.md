# TSK-344 — QA Tab Riepilogo

## Obiettivo
Coprire il tab Riepilogo con Vitest sui 4 stati del verdetto e sul banner anti-COPART, E2E Playwright sui 3 scenari chiave, compatibilità deep-link, a11y e snapshot di non-regressione sugli altri 3 tab.

## Scope

### Vitest
- 4 stati verdetto (ENTRA ORA / ASPETTA / EVITA / DATI INSUFFICIENTI) + presenza/assenza del banner anti-COPART.

### E2E Playwright
- CPRT → Riepilogo attivo + hero "ASPETTA" + banner anti-COPART + decision path coerente.
- AAPL → hero "ENTRA ORA" senza banner anti-COPART.
- VI-negativo → hero "EVITA" con decision path "VI gate failed".
- Deep-link compat: `/analysis/AAPL/deep` apre tab Deep (non Riepilogo); `/analysis?ticker=AAPL` apre Riepilogo.

### A11y + non-regressione
- Lighthouse a11y ≥ 95 + axe-core zero serious/critical sul tab Riepilogo.
- Snapshot di non-regressione sugli altri 3 tab (Analisi Base, Deep, Technical Analysis).

## Acceptance Criteria
- [ ] Vitest coprono i 4 stati verdetto + presenza/assenza banner anti-COPART.
- [ ] E2E CPRT → Riepilogo attivo + "ASPETTA" + banner + decision path.
- [ ] E2E AAPL → "ENTRA ORA" senza banner.
- [ ] E2E VI-negativo → "EVITA" con "VI gate failed".
- [ ] Deep-link compat: `/analysis/AAPL/deep` apre Deep; `/analysis?ticker=AAPL` apre Riepilogo.
- [ ] Lighthouse a11y ≥ 95 + axe-core zero serious/critical.
- [ ] Snapshot non-regressione sugli altri 3 tab `passed`.
