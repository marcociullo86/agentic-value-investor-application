# TSK-343 — Riepilogo: card fattori, decision path, citazioni

## Obiettivo
Completare il tab Riepilogo con le 3 card fattori chiave (VI/Deep/TA), il decision path accessibile, la sezione citazioni wiki raggruppate per dominio e il footer disclaimer.

## Scope

### 3 card fattori chiave
- Card "Verdetto VI" → `rationale.viSummary` + chip MoS% + link "Vedi Analisi Base →".
- Card "Deep Analysis" → `rationale.deepSummary` + chip Munger verdict + link "Vedi Deep →"; CTA "Indicizza filing →" se `deepAnalysisStatus = NOT_INDEXED` (linka all'azione del tab Deep, EP-011).
- Card "Technical Analysis" → `rationale.taSummary` + chip TA verdict + link "Vedi Technical Analysis →".
- I link "Vedi →" navigano al rispettivo tab.

### Decision path
- Chip orizzontale con `rationale.decisionPath` + alternativa accessibile (tabella per screen reader).

### Sezione "Perché questo verdetto"
- `wikiCitations` raggruppate per `domain` (value-investing vs technical-analysis-trading), cliccabili (pagina wiki o modal con estratto).

### Footer
- Disclaimer: "Decision-support tool. Nessuna esecuzione automatica di ordini. Il verdetto VI resta gate primario; la TA è layer advisory di timing."

## Acceptance Criteria
- [ ] 3 card fattori chiave mostrano summary + chip verdetto + link funzionante al rispettivo tab.
- [ ] Card Deep mostra CTA "Indicizza filing →" se `deepAnalysisStatus = NOT_INDEXED`.
- [ ] Decision path in chip orizzontale + alternativa accessibile (tabella screen reader).
- [ ] Sezione citazioni raggruppate per dominio, cliccabili.
- [ ] Footer disclaimer presente.
