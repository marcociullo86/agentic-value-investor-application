# US-104 — Tab "Riepilogo" come primo tab (FE)

## Descrizione

Come investitore value che apre `/analysis?ticker=XXX`, voglio che il **primo tab che vedo** sia "Riepilogo" — un tab capstone che mi risponde direttamente alla domanda "Devo entrare ORA su questo ticker?" mostrando il verdetto tipato `ENTRA ORA / ASPETTA / EVITA`, i fattori chiave estratti dagli altri 3 tab (Analisi Base + Deep Analysis + Technical Analysis), le citazioni wiki che giustificano il verdetto, e un **warning esplicito anti-COPART** quando il verdetto fondamentale e' positivo ma il timing tecnico e' sfavorevole, affinche io non debba aggregare mentalmente 3 tab di dati per decidere. [^src: wiki/syntheses/ta-vs-vi-decision-layer.md §"Sintesi: la regola delle due domande"]

## Business Rules

### Posizionamento del tab

L'ordine finale dei tab sul dettaglio ticker diventa:

```
[ Riepilogo ] | [ Analisi Base ] | [ Deep Analysis ] | [ Technical Analysis ]
   ^ primo, default attivo all'apertura della pagina
```

- Il tab "Riepilogo" e' **il primo tab visibile** e quello attivo al landing su `/analysis?ticker=XXX`.
- Gli altri 3 tab restano accessibili e invariati.
- Modifica route default: il deep-link `/analysis?ticker=XXX` apre Riepilogo; i deep-link esistenti `/analysis/XXX/deep` (e l'eventuale `/analysis/XXX/technical` di US-101) continuano a funzionare aprendo il rispettivo tab.

### Layout del tab Riepilogo

Dall'alto verso il basso:

1. **Hero verdetto**: badge prominente con il `summaryVerdict` di US-103:
   - `ENTER_NOW` → "ENTRA ORA" verde, icona check, sub-headline "Verdetto fondamentale e timing tecnico favorevoli".
   - `WAIT_FOR_SETUP` → "ASPETTA" giallo/blu, icona timer, sub-headline che mostra `reentryCondition.description` (es. "Re-valuta quando RSI 14d rientra sotto 50").
   - `AVOID` → "EVITA" rosso, icona stop, sub-headline che spiega quale gate ha bocciato (VI o Munger).
   - `INSUFFICIENT_DATA` → "DATI INSUFFICIENTI" grigio, icona info, sub-headline che invita ad attendere indicizzazione/dati.
2. **Banner warning anti-COPART** (solo se `warningAntiCopart` non vuoto): banner grande, colore di alert ma non rosso (per distinguerlo da AVOID), contiene il testo:
   > "Verdetto fondamentale positivo ma timing tecnico sfavorevole. Acquistare ora rischia uno stop loss prematuro su una tesi VI corretta — situazione COPART. Attendere il setup tecnico migliore."
   Link "Approfondisci →" che apre [[ta-vs-vi-decision-layer]] §"La domanda che ha motivato questa sintesi".
3. **3 card "Fattori chiave"** (riga, layout responsive):
   - Card "Verdetto VI" → `rationale.viSummary` + chip con MoS% + link "Vedi Analisi Base →"
   - Card "Deep Analysis" → `rationale.deepSummary` + chip Munger verdict + link "Vedi Deep →" (oppure messaggio "Non ancora indicizzata" se `deepAnalysisStatus = NOT_INDEXED`).
   - Card "Technical Analysis" → `rationale.taSummary` + chip TA verdict + link "Vedi Technical Analysis →"
4. **Decision path** (riga): chip orizzontale che mostra `rationale.decisionPath` (es. "VI gate passed → TA gate: WAIT → WAIT_FOR_SETUP"), utile per la trasparenza.
5. **Sezione "Perche questo verdetto"** (citazioni wiki): lista delle `wikiCitations` raggruppate per `domain` (value-investing vs technical-analysis-trading), cliccabili (apre pagina wiki o modal con estratto — decisione fe-dev).
6. **Footer disclaimer**: "Decision-support tool. Nessuna esecuzione automatica di ordini. Il verdetto VI resta gate primario; la TA e' layer advisory di timing."

### Comportamento

- Fetch di `/api/analysis/{ticker}/summary` al mount del tab Riepilogo (default attivo).
- Stato di caricamento: skeleton coerente con design system EP-016.
- Errore: `NotificationProvider` di EP-015 con messaggio specifico se il backend e' down.
- Se `deepAnalysisStatus = NOT_INDEXED`: la card "Deep Analysis" mostra CTA "Indicizza filing →" che linka all'azione gia esistente nel tab Deep Analysis (EP-011).
- Se l'utente clicca un link "Vedi →" su una card, naviga al rispettivo tab dell'analisi.

### Accessibilita

- Hero verdetto: colore + icona + testo (non solo colore), conforme WCAG 2.2 AA.
- Banner anti-COPART: ruolo `alert` ARIA, screen reader lo legge in priorita.
- Decision path: tabella alternativa accessibile per chi non puo leggere il flusso orizzontale.
- Lighthouse a11y >= 95, axe-core zero serious/critical (EP-016).

### Componente

- Nuovo route segment `/analysis/{ticker}` default-redirect a `/analysis/{ticker}/summary`, oppure tab interno (decisione fe-dev coerente con il pattern usato per Technical Analysis in US-101).
- Riusa pattern card/badge del design system EP-016.

## Acceptance Criteria

- [ ] Il tab "Riepilogo" e' il **primo tab** visibile sulla pagina di dettaglio e quello attivo al landing su `/analysis?ticker=XXX`.
- [ ] L'ordine dei tab e' `Riepilogo | Analisi Base | Deep Analysis | Technical Analysis`.
- [ ] Hero verdetto mostra `summaryVerdict` con colore + icona + testo + sub-headline coerente; copre i 4 stati (`ENTER_NOW`, `WAIT_FOR_SETUP`, `AVOID`, `INSUFFICIENT_DATA`).
- [ ] Banner anti-COPART appare **solo** quando `warningAntiCopart` non e' vuoto, con ruolo ARIA `alert` e link "Approfondisci →".
- [ ] Le 3 card "Fattori chiave" mostrano il summary testuale e i chip di verdetto per VI, Deep, TA, con link funzionante al rispettivo tab.
- [ ] Card Deep mostra CTA "Indicizza filing →" se `deepAnalysisStatus = NOT_INDEXED`.
- [ ] Decision path mostra `rationale.decisionPath` in chip orizzontale e ha alternativa accessibile (tabella per screen reader).
- [ ] Sezione "Perche questo verdetto" mostra `wikiCitations` raggruppate per dominio, cliccabili.
- [ ] Footer disclaimer presente in tutte le viste.
- [ ] Deep-link compatibility: `/analysis/AAPL/deep` apre tab Deep (non Riepilogo); `/analysis?ticker=AAPL` apre Riepilogo.
- [ ] Test Vitest coprono i 4 stati del verdetto + presenza/assenza del banner anti-COPART.
- [ ] Test E2E Playwright:
  - Scenario stile-COPART (CPRT fixture): apertura `/analysis?ticker=CPRT` → tab Riepilogo attivo → hero "ASPETTA" + banner anti-COPART visibile + decision path coerente.
  - Scenario happy path uptrend (AAPL fixture): tab Riepilogo → hero "ENTRA ORA" + nessun banner anti-COPART.
  - Scenario VI negativo: tab Riepilogo → hero "EVITA" + decision path mostra "VI gate failed".
- [ ] Lighthouse a11y >= 95 e axe-core zero serious/critical sul tab Riepilogo.
- [ ] Snapshot test di non-regressione sugli altri 3 tab (Analisi Base, Deep, Technical Analysis) `passed`.
