# TSK-335 — Pannelli momentum/stop/sizing + citazioni

## Obiettivo
Completare il tab Technical Analysis con i pannelli momentum, stop-placement e position-sizing, il footer di citazioni wiki e il banner "Dati limitati" su `confidenceReduced`.

## Scope

### Pannello momentum
- Riga RSI 14d (valore + zona Oversold/Neutral/Overbought), riga MACD daily (valore + direzione), riga MACD weekly (valore + direzione).

### Pannello stop-placement
- `type` (`SUPPORT_BASED/SMA200_BASED/ATR_BASED`) + `anchorReference` + `stopPrice` + `stopDistancePct` + rationale citato.
- Gestione `NOT_CALCULABLE` con messaggio dedicato.

### Pannello position-sizing
- Input `equity` (number, default 50000, persistito in `localStorage`) → ricalcolo.
- Output 2% Rule (shares, positionValue, %equity, warning `POSITION_EXCEEDS_EQUITY`), 6% Rule (budget mensile + disclaimer), badge reward/risk (`EXCELLENT/ACCEPTABLE/MARGINAL/UNFAVORABLE/NOT_APPLICABLE`).

### Footer citazioni + banner
- Footer con link cliccabili alle pagine wiki TA ([[ta-entry-timing-stock-detail]], [[ta-stop-placement-position-sizing]], [[elder-triple-screen-impulse-system]], [[elder-risk-management-2pct-6pct]]) — link a pagina wiki o modal con estratto.
- Banner giallo "Dati limitati: analisi tecnica con confidenza ridotta" quando `confidenceReduced = true`.
- A11y EP-016 su pannelli e badge.

## Acceptance Criteria
- [ ] Pannello momentum mostra RSI14 (zona) + MACD daily + MACD weekly (direzione).
- [ ] Pannello stop-placement mostra type/anchor/stopPrice/dist% + rationale; gestisce `NOT_CALCULABLE`.
- [ ] Pannello position-sizing: input equity (default 50000, localStorage), 2% Rule + 6% Rule + badge reward/risk.
- [ ] Footer citazioni con link cliccabili alle pagine wiki TA.
- [ ] Banner "Dati limitati" appare su `confidenceReduced = true`.
