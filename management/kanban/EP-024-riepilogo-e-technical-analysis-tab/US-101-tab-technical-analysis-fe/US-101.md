# US-101 — Tab "Technical Analysis" sul dettaglio ticker (FE)

## Descrizione

Come investitore value che apre `/analysis?ticker=XXX`, voglio un terzo tab **"Technical Analysis"** (accanto a "Analisi Base" e "Deep Analysis") che mostri visualmente trend, indicatori, livelli di support/resistance, verdetto di entry-timing, stop suggerito e position sizing, **chiaramente etichettato come layer advisory di timing che non sostituisce il verdetto fondamentale**, affinche io possa rispondere alla domanda "Quando comprare?" senza interpretare manualmente JSON o uscire dall'app. [^src: wiki/syntheses/ta-entry-timing-stock-detail.md §"Sintesi operativa: checklist di timing"] [^src: wiki/syntheses/ta-vs-vi-decision-layer.md §"Architettura a due layer nell'app"]

## Business Rules

### Layout del tab

Tab "Technical Analysis" aggiunto come terzo tab nella navigazione del dettaglio ticker (ordine post-EP-024 Fase 1: `Analisi Base | Deep Analysis | Technical Analysis`; il tab "Riepilogo" diventera primo solo dopo US-104 in Fase 2).

Sezioni dall'alto verso il basso:

1. **Disclaimer banner** (prominente, dismissable per sessione): "Layer advisory di timing. Il verdetto fondamentale resta primario. [Approfondisci →]" con link a una sezione info che riassume [[ta-vs-vi-decision-layer]] in 3 bullet.
2. **Verdetto entry-timing** (card grande): badge colorato con il verdetto di US-099 (`ENTRY_FAVORABLE` verde, `ENTRY_NEUTRAL` giallo, `ENTRY_UNFAVORABLE` rosso, `WAIT` blu, `INDETERMINATE` grigio). Sotto, le tre righe Screen 1/2/3 dal `rationale` strutturato.
3. **Condizione di re-entry** (solo se `WAIT`): banner che mostra `reentryCondition.description` in modo evidente (es. "Re-valuta quando RSI 14d rientra sotto 50").
4. **Price chart con overlay** (Recharts):
   - Linea prezzo daily ultimi 12 mesi (riuso pattern `HistoricalChart` con dataset EOD se disponibile, altrimenti dataset esistente).
   - Overlay SMA50 e SMA200 (linee tratteggiate).
   - Marker orizzontali per i top 3 livelli support (sotto il prezzo) e top 3 resistance (sopra il prezzo) da US-098 `levels`.
   - Marker dello `stopSuggestion.stopPrice` se calcolato.
5. **Pannello indicatori momentum**:
   - Riga RSI 14d (valore corrente + zona Oversold/Neutral/Overbought).
   - Riga MACD daily (valore + direzione).
   - Riga MACD weekly (valore + direzione).
6. **Pannello stop-placement** (da US-100 `stopSuggestion`):
   - Tipo stop (`SUPPORT_BASED`/`SMA200_BASED`/`ATR_BASED`) + ancoraggio + stopPrice + distanza %.
   - Rationale testuale citato.
   - Se `NOT_CALCULABLE`: messaggio esplicito.
7. **Pannello position-sizing** (da US-100 `positionSizing`):
   - Input `equity` (number, default 50000 USD, persistito in `localStorage` per UX — coerente con principio "BE non persiste equity").
   - Output 2% Rule: shares raccomandate, valore posizione, % equity, warning `POSITION_EXCEEDS_EQUITY` se applicabile.
   - Output 6% Rule: budget mensile aggregato + disclaimer.
   - Reward/Risk ratio vs DCF intrinsic value (badge `EXCELLENT/ACCEPTABLE/MARGINAL/UNFAVORABLE/NOT_APPLICABLE`).
8. **Footer di citazioni**: lista di pagine wiki TA collegate ([[ta-entry-timing-stock-detail]], [[ta-stop-placement-position-sizing]], [[elder-triple-screen-impulse-system]], [[elder-risk-management-2pct-6pct]]) cliccabili (link a pagine wiki o modal con estratto, decisione fe-dev).

### Comportamento

- Lazy load: il fetch di `/api/analysis/{ticker}/technical` avviene solo quando l'utente clicca sul tab "Technical Analysis" (non al mount della pagina), per non penalizzare il tab Analisi Base.
- Stato di caricamento: skeleton coerente con design system EP-016.
- Errore di rete: `NotificationProvider` di EP-015 con ProblemDetail decodato.
- `confidenceReduced=true` (storico corto): banner giallo "Dati limitati: analisi tecnica con confidenza ridotta".

### Accessibilita

- WCAG 2.2 AA: contrasto, focus visibile, label aria-* sui badge, screen reader leggibili (EP-016).
- Chart Recharts: tabella dati alternativa accessibile per screen reader (pattern gia in uso in `HistoricalChart`).
- Il colore del badge verdetto non e' l'unico canale (testo + icona).

### Componente

- Nuovo route segment se segue il pattern `/analysis/{ticker}/technical` analogo a `/analysis/{ticker}/deep`, **oppure** tab interno al componente `AnalysisPageClient` (decisione fe-dev coerente con UX di EP-011 deep). La spec preferisce coerenza: se Deep e' una route separata, anche Technical e' una route separata; altrimenti tab interno.
- Riuso `MrMarketSentimentBadge` e `LongTermTrendBadge` esistenti **non e'** previsto qui (restano nel tab Analisi Base). Niente duplicazione visiva.

## Acceptance Criteria

- [ ] Esiste un terzo tab "Technical Analysis" sul dettaglio ticker, visibile con il pattern di navigazione tab usato dagli altri tab.
- [ ] Disclaimer banner "Layer advisory di timing — verdetto fondamentale primario" e' presente in testa al tab, accessibile e dismissable per sessione.
- [ ] Card "Verdetto entry-timing" mostra il verdetto di US-099 con colore + icona + testo (5 stati supportati: ENTRY_FAVORABLE/NEUTRAL/UNFAVORABLE/WAIT/INDETERMINATE).
- [ ] Banner "Condizione di re-entry" appare solo se verdetto = WAIT, mostrando `reentryCondition.description`.
- [ ] Price chart Recharts con overlay SMA50, SMA200, marker support/resistance, marker stopPrice (se presente).
- [ ] Pannello momentum mostra RSI 14d + MACD daily + MACD weekly con zona/direzione.
- [ ] Pannello stop-placement mostra type, stopPrice, distanza %, rationale; gestisce `NOT_CALCULABLE` con messaggio dedicato.
- [ ] Pannello position-sizing accetta input `equity` (default 50000, persistito in `localStorage`), mostra output 2% Rule + 6% Rule + Reward/Risk ratio.
- [ ] Lazy load: l'endpoint `/technical` e' chiamato solo al click sul tab, non al mount della pagina (verificato con network test).
- [ ] Banner "Dati limitati" appare quando il payload ha `confidenceReduced = true`.
- [ ] Footer citazioni mostra link cliccabili alle pagine wiki TA principali.
- [ ] Accessibilita: lighthouse a11y >= 95, axe-core zero serious/critical (coerente con EP-016).
- [ ] Test Vitest coprono almeno i 5 stati del verdetto entry-timing.
- [ ] Test E2E Playwright smoke: navigazione `/analysis?ticker=AAPL` → click tab Technical Analysis → render delle 7 sezioni senza errori.
