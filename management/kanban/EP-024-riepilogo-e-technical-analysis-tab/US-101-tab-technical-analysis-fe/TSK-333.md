# TSK-333 — Client TS + hook useTechnicalAnalysis (lazy)

## Obiettivo
Rigenerare il client TypeScript dal nuovo OpenAPI (`TechnicalAnalysisResponse` + advisor) e fornire un hook SWR `useTechnicalAnalysis` che effettua il fetch solo al click sul tab Technical Analysis (lazy load), non al mount della pagina.

## Scope

### Client TS
- Rigenerazione del client TS dal `design_&_architecture/api/openapi.yaml` aggiornato (TSK-326 + TSK-332), tipi per i 6 blocchi + advisor + enum tipati.

### Hook SWR
- `useTechnicalAnalysis(ticker, { equity })` basato su SWR.
- LAZY: il fetch di `/api/analysis/{ticker}/technical` parte solo quando il tab Technical Analysis viene attivato (gating SWR via key condizionale), non al mount di `/analysis?ticker=XXX`.
- Gestione stati loading/error coerente con design system EP-016 e `NotificationProvider` EP-015 (consumati dai componenti delle TSK-334/335).

## Acceptance Criteria
- [ ] Client TS rigenerato dal nuovo OpenAPI con tipi per blocchi indicatori + advisor + enum tipati.
- [ ] Hook `useTechnicalAnalysis` con SWR.
- [ ] Lazy load: nessuna chiamata a `/technical` finché il tab non è attivato (key SWR condizionale).
- [ ] Hook espone stati loading/error consumabili dai pannelli.
