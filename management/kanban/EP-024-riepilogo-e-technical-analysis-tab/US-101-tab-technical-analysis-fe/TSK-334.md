# TSK-334 — Tab Technical Analysis: scaffold, verdetto, chart

## Obiettivo
Creare il terzo tab "Technical Analysis" sul dettaglio ticker con disclaimer banner, card del verdetto entry-timing, banner condizione di re-entry e price chart Recharts con overlay, riusando i pattern di `AnalysisPageClient` e `HistoricalChart`.

## Scope

### Scaffold tab + disclaimer
- Terzo tab "Technical Analysis" (ordine Fase 1: `Analisi Base | Deep Analysis | Technical Analysis`), coerente con il pattern di navigazione di `AnalysisPageClient.tsx`. Route separata `/analysis/{ticker}/technical` se Deep è route separata, altrimenti tab interno.
- Disclaimer banner advisory dismissable per sessione: "Layer advisory di timing. Il verdetto fondamentale resta primario. [Approfondisci →]" con sezione info che riassume [[ta-vs-vi-decision-layer]] in 3 bullet.

### Card verdetto entry-timing
- Badge colorato per i 5 stati: `ENTRY_FAVORABLE` verde, `ENTRY_NEUTRAL` giallo, `ENTRY_UNFAVORABLE` rosso, `WAIT` blu, `INDETERMINATE` grigio. Colore non unico canale: testo + icona.
- Tre righe Screen 1/2/3 dal `rationale` strutturato.

### Banner re-entry
- Visibile solo se verdetto = `WAIT`: mostra `reentryCondition.description`.

### Price chart (Recharts)
- Linea prezzo daily 12 mesi (riuso pattern `HistoricalChart`), overlay SMA50/SMA200 (tratteggiate), marker orizzontali top 3 support + top 3 resistance, marker `stopSuggestion.stopPrice` se presente.

### Vincoli
- Riuso pattern `AnalysisPageClient.tsx` / `HistoricalChart.tsx`. Niente duplicazione dei badge EP-013 (`MrMarketSentimentBadge`, `LongTermTrendBadge` restano nel tab Analisi Base).
- A11y EP-016: contrasto, focus, aria-* sui badge, tabella dati alternativa accessibile per il chart.

## Acceptance Criteria
- [ ] Terzo tab "Technical Analysis" presente con il pattern di navigazione degli altri tab.
- [ ] Disclaimer banner advisory presente in testa, accessibile e dismissable per sessione.
- [ ] Card verdetto entry-timing con colore + icona + testo per i 5 stati.
- [ ] Banner re-entry appare solo se verdetto = WAIT con `reentryCondition.description`.
- [ ] Price chart con overlay SMA50/200 + marker support/resistance + marker stopPrice (se presente) + tabella dati accessibile.
- [ ] Nessuna duplicazione dei badge advisory EP-013.
