# TSK-339 — Rationale LLM + citazioni RAG + warningAntiCopart

## Obiettivo
Generare il rationale narrativo del Riepilogo con UNA sola call LLM, recuperare le citazioni wiki via RAG sul corpus WIKI e popolare il campo `warningAntiCopart` nelle condizioni esatte, senza che l'LLM tocchi il verdetto.

## Scope

### Rationale narrativo (1 call LLM)
- 1 sola call `AnthropicClient` (EP-011) che genera `rationale.viSummary`, `rationale.deepSummary`, `rationale.taSummary` partendo dai dati strutturati prodotti da TSK-338. Il `summaryVerdict` NON è mai prodotto dall'LLM.
- `decisionPath` testuale (es. "VI gate passed → TA gate: WAIT → WAIT_FOR_SETUP").
- Logging gated (EP-020 US-088) + `LlmBudgetGuard`/`LlmCostCounterService` (EP-011 TSK-156); call contabilizzata in `llm_cost_tracking`.

### wikiCitations (RAG)
- Similarity search sul corpus `corpus_kind = WIKI` (TSK-337), top-K = 4 (configurabile), filtro per dominio coerente con il rationale; query strutturate sui 3 verdetti VI/Deep/TA.
- Almeno una citazione per dominio quando entrambi i layer hanno contribuito.

### warningAntiCopart
- Presente SOLO quando `viVerdict = GREEN_DOMINANT` AND `taVerdict ∈ {WAIT, ENTRY_UNFAVORABLE}` AND `summaryVerdict = WAIT_FOR_SETUP`. In ogni altro caso assente.

## Acceptance Criteria
- [ ] Una sola call LLM genera i 3 campi `rationale.*Summary`; il verdetto non è mai prodotto dall'LLM.
- [ ] `decisionPath` testuale presente.
- [ ] `wikiCitations` da similarity search su corpus WIKI (top-K=4 configurabile, filtro dominio), almeno una per dominio quando entrambi i layer contribuiscono.
- [ ] `warningAntiCopart` presente solo nelle condizioni esatte specificate.
- [ ] Logging gated EP-020 attivo; `LlmBudgetGuard` rispettato; costo contabilizzato.
