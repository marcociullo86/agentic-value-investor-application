# TSK-338 — SummaryService: gate VI deterministico

## Obiettivo
Implementare il core deterministico del Riepilogo: la tabella di mapping hardcoded gate VI che produce `SummaryVerdict`, con soglia VI proporzionale (ADR-030 §3) e orchestrazione dei tre layer senza ricalcolo. Nessun LLM nel verdetto.

## Scope

### Tabella di mapping deterministica
- `SummaryService` con tabella DETERMINISTICA hardcoded (data class + match function): VI verdict × MoS × Deep verdict × TA entryTiming → `SummaryVerdict` ∈ `ENTER_NOW | WAIT_FOR_SETUP | AVOID | INSUFFICIENT_DATA`. Implementare tutte le righe US-103 §"Tabella di mapping".
- Regole assolute: VI verdict RED → mai `ENTER_NOW`; Munger `RISCHIO_ESTREMO` → mai `ENTER_NOW` (override).

### Soglia VI proporzionale (ADR-030 §3)
- Conteggio sui **ruleId decisionali disponibili** (esclusi `NCAV_LATEST` informativo ed esclusi `INDETERMINATE`/`NOT_CALCULABLE`).
- `GREEN_DOMINANT` = GREEN ≥ 60% dei decisionali disponibili; `RED_DOMINANT` = GREEN < 33%; `YELLOW_DOMINANT` intermedio; `INDETERMINATE_DOMINANT` (≥ 1/3 INDETERMINATE/NOT_CALCULABLE) → `INSUFFICIENT_DATA`.

### Orchestrazione
- Legge VI (`/api/analysis/{ticker}` + contextFlags), Deep latest (`/deep/runs/latest`), TA (`/technical`). Non ricalcola: orchestra.
- `deepAnalysisStatus = NOT_INDEXED` non blocca (verdetto su VI + TA, `deepVerdict = null`).
- Verdetto è funzione pura Kotlin; nessuna call LLM in questo TSK. Kdoc cita [[ta-vs-vi-decision-layer]] §"La regola sequenziale" e [[munger-inversion-rag]] §Cascade Logica.

## Acceptance Criteria
- [ ] `summaryVerdict` calcolato in pure-function dalla tabella di mapping; tutte le righe implementate.
- [ ] VI RED → mai `ENTER_NOW`; Munger RISCHIO_ESTREMO → mai `ENTER_NOW`.
- [ ] Soglia proporzionale: GREEN_DOMINANT ≥ 60%, RED_DOMINANT < 33% dei decisionali disponibili (NCAV_LATEST escluso, INDETERMINATE esclusi).
- [ ] `INDETERMINATE_DOMINANT` (≥ 1/3 indeterminati) → `INSUFFICIENT_DATA`.
- [ ] Orchestrazione legge VI + deep latest + /technical senza ricalcolo.
- [ ] `deepAnalysisStatus = NOT_INDEXED` non blocca il verdetto.
- [ ] Nessuna chiamata LLM nel verdetto.
