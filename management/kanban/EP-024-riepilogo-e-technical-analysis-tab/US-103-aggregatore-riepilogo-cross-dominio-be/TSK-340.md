# TSK-340 — SummaryController + DTO + OpenAPI + caching

## Obiettivo
Esporre l'endpoint `GET /api/analysis/{ticker}/summary` auth-aware con il DTO `SummaryVerdictResponse`, lo schema OpenAPI con enum tipati e il caching per-snapshot.

## Scope

### Controller + DTO
- `SummaryController` con `GET /api/analysis/{ticker}/summary`, auth-aware (Vary, cache per-user) coerente con `/api/analysis/{ticker}`.
- DTO `SummaryVerdictResponse`: `ticker`, `summaryVerdict`, `viVerdict`, `deepAnalysisStatus`, `deepVerdict`, `taVerdict`, `rationale {viSummary, deepSummary, taSummary, decisionPath}`, `reentryCondition`, `wikiCitations[]`, `warningAntiCopart`.

### OpenAPI
- Schema `SummaryVerdictResponse` con enum tipati `SummaryVerdict`, `ViVerdict`, `DeepVerdict`, `TaVerdict`, `ReentryConditionCode`.

### Caching
- Cache per `(userId, ticker, viSnapshot, taSnapshot, deepSnapshot)`, TTL 24h o invalidazione su nuova run di Deep / nuova analisi VI. Seconda chiamata con stessi snapshot servita da cache.

## Acceptance Criteria
- [ ] `GET /api/analysis/{ticker}/summary` ritorna `SummaryVerdictResponse` documentato; auth-aware (Vary, cache per-user).
- [ ] DTO include tutti i campi (verdetti, rationale, reentryCondition, wikiCitations, warningAntiCopart).
- [ ] OpenAPI con enum tipati `SummaryVerdict`, `ViVerdict`, `DeepVerdict`, `TaVerdict`, `ReentryConditionCode`.
- [ ] Caching per `(userId, ticker, viSnapshot, taSnapshot, deepSnapshot)` TTL 24h o invalidazione su nuova run.
- [ ] `deepAnalysisStatus = NOT_INDEXED` → `deepVerdict = null` esplicito nella response.
