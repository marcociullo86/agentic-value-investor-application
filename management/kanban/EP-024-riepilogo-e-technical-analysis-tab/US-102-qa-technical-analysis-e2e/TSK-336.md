# TSK-336 — QA E2E + contract Fase 1 TA

## Obiettivo
Coprire l'intera pipeline TA Fase 1 (US-098..US-101) con contract drift completo, integration BE su 5 fixture, E2E Playwright su 5 scenari e a11y, garantendo non-regressione e determinismo.

## Scope

### Contract + integration BE
- Contract drift completo su `TechnicalAnalysisResponse` + advisor + enum tipati (`EntryTimingVerdict`, `ReentryConditionCode`, `StopType`, `RewardRiskLabel`, `TrendClassification`, `SupportType`).
- Integration BE su 5 fixture: AAPL uptrend (favorable/neutral + stop SUPPORT_BASED + R/R ≥ 2), CPRT stile-COPART (`WAIT` + `RSI_BELOW_50` + citazioni wiki), downtrend (`ENTRY_UNFAVORABLE`), storico corto (`INDETERMINATE` + `confidenceReduced`), stop `NOT_CALCULABLE`.

### E2E Playwright (5 scenari, mocked-tier EP-016/EP-018)
1. Happy path uptrend (AAPL): tab → verdetto + chart + pannelli, no errori console.
2. CPRT stile-COPART: verdetto `WAIT` evidenziato + banner re-entry + disclaimer advisory presente.
3. Input equity → ricalcolo shares + warning `POSITION_EXCEEDS_EQUITY`.
4. Lazy load via network interception (nessuna chiamata a `/technical` finché il tab non è cliccato).
5. A11y smoke: keyboard navigation + chart accessibile via tabella alternativa.

### A11y + non-regressione
- Lighthouse a11y ≥ 95 + axe-core zero serious/critical sul tab Technical Analysis.
- Non-regressione tab Analisi Base + Deep Analysis (snapshot Vitest + Playwright).
- Tutti i test deterministici (no flake, pattern hotfix Sprint 15.5 EP-016).

## Acceptance Criteria
- [ ] Contract drift su `TechnicalAnalysisResponse` + sub-schema `passed`.
- [ ] Integration BE 5 fixture con asserzioni esplicite sul verdetto atteso.
- [ ] Test CPRT verifica `WAIT` + `RSI_BELOW_50` + citazioni wiki nel rationale.
- [ ] E2E Playwright 5 scenari `passed`.
- [ ] Lazy load verificato via network interception.
- [ ] Lighthouse a11y ≥ 95 + axe-core zero serious/critical.
- [ ] Non-regressione tab Analisi Base + Deep `passed` (snapshot).
- [ ] Test deterministici (no flake).
