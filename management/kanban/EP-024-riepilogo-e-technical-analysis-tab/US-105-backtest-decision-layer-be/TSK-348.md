# TSK-348 — BacktestController: endpoint GET /backtest + DTO + OpenAPI + caching

## Obiettivo

Esporre il motore di backtest (TSK-346/TSK-347) via `GET /api/analysis/{ticker}/backtest`, definire il DTO completo con enum tipati, arricchire lo schema OpenAPI e configurare il caching per-chiave `(ticker, years, horizonMonths)`.

## Scope

### Controller + DTO
- `BacktestController` con `GET /api/analysis/{ticker}/backtest?years={N}&horizonMonths={h}&equity={e}`.
- Parametri: `years` (default 5, max configurabile via property), `horizonMonths` (default 6, valori ammessi 1/3/6/12), `equity` opzionale (mai persistita, solo per esposizione valori assoluti nel DTO).
- `BacktestResultDto` con:
  - `ticker`, `window` (`fromDate`, `toDate`, `years`, `horizonMonths`).
  - `strategies`: lista di `BacktestStrategyDto` (`strategy`, `trades`, `winRate`, `avgReturnPct`, `medianReturnPct`, `avgHoldingDays`, `avgRealizedRewardRisk`, `totalReturnPct`, `maxTradeDrawdownPct`, `exitBreakdown`, `noSignalsInPeriod`).
  - `timingEdge`: `BacktestTimingEdgeDto` (`timingEdgePct`, `label: POSITIVE_EDGE | NEUTRAL | NEGATIVE_EDGE`).
  - `trades`: lista di `BacktestTradeDto` per `EP024_ENTER_NOW` e `VI_ONLY` (`entryDate`, `entryPrice`, `exitDate`, `exitPrice`, `exitReason: VI_TARGET | STOP_HIT | HORIZON`, `returnPct`, `holdingDays`, `maxIntraTradeDrawdownPct`).
  - `status`: `OK | INSUFFICIENT_HISTORY` — se `INSUFFICIENT_HISTORY`, campo `insufficientHistoryReason` presente, resto omesso.
  - `caveats`: `BacktestCaveatsDto` (`lookAheadResidual: true`, `singleTicker: true`, `notPortfolioPerformance: true`).

### OpenAPI
- Schema `BacktestResultDto` + enum `BacktestStrategy`, `ExitReason`, `TimingEdgeLabel`, `BacktestStatus` con description.
- Aggiornamento `openapi.yaml` generato da Kotlin source; client TS si rigenera da questo schema (TSK-350).

### Caching
- Cache-aside per chiave `(ticker, years, horizonMonths)` con TTL allineato alla policy ADR-030 (24h, stessa policy TA/summary). `equity` escluso dalla chiave di cache (mai persistita, valore locale).
- Cache invalidation: allineata alla policy esistente di `/technical` e `/summary`.

## Acceptance Criteria
- [ ] `GET /api/analysis/{ticker}/backtest` risponde con `BacktestResultDto` completo per ticker con storico sufficiente.
- [ ] `status: INSUFFICIENT_HISTORY` restituito con `insufficientHistoryReason`, senza dati parziali.
- [ ] Enum `ExitReason`, `TimingEdgeLabel`, `BacktestStrategy`, `BacktestStatus` presenti nello schema OpenAPI con description.
- [ ] `equity` mai persistita: test che verifica assenza di scritture DB per questo campo.
- [ ] Cache hit: seconda chiamata con stessa chiave `(ticker, years, horizonMonths)` servita da cache (test con spy sul motore).
- [ ] `caveats` sempre presente nel payload (anche per `OK`).
