# TSK-328 — EntryTimingAdvisor: verdetto Triple-Screen deterministico

## Obiettivo
Implementare l'advisor di entry-timing come funzione pura Kotlin che, dato il payload TA (trend, RSI zone, MACD, distanza dal support più vicino), produce un `EntryTimingVerdict` tipato tramite tabella di mapping dichiarativa, incluso `reentryCondition` e `rationale` strutturato.

## Scope

### Tabella di mapping dichiarativa
- `EntryTimingAdvisor` con tabella DICHIARATIVA (data class delle condizioni + match function, niente if/else annidati > 1 livello).
- Verdetti `EntryTimingVerdict`: `ENTRY_FAVORABLE | ENTRY_NEUTRAL | ENTRY_UNFAVORABLE | WAIT | INDETERMINATE`.
- Input dimensioni: `trend.classification` × zona RSI14 (`Oversold<30 | Neutral 30..70 | Overbought>70`) × `macdDaily` (rialzista/forte/flat/ribassista) × distanza % dal support più vicino (`<5% | 5..15% | qualsiasi`).
- Implementare tutte le righe della tabella US-099 §"Tabella di mapping", incl.:
  - UPTREND + Overbought + flat/ribassista → `WAIT (re-entry RSI < 50)`.
  - UPTREND + Overbought + rialzista forte → `ENTRY_NEUTRAL` (Murphy §Page 239).
  - DOWNTREND + Oversold + rialzista forte + <5% → `WAIT (re-entry prezzo > SMA200 con volume)`.
  - DOWNTREND altro → `ENTRY_UNFAVORABLE`.
  - INDETERMINATE → `INDETERMINATE`.

### reentryCondition (per WAIT)
- Campo `reentryCondition { code, description }`, enum `RSI_BELOW_50 | PRICE_ABOVE_SMA200_WITH_VOLUME | PULLBACK_TO_SUPPORT_50PCT`, valutato in pure-function coerente con la riga che ha prodotto il `WAIT`.

### rationale + gate
- `rationale { screen1, screen2, screen3, wikiCitations[] }` non vuoti per ogni verdetto ≠ INDETERMINATE.
- `vi_gate: "this_advisor_assumes_vi_verdict_positive"` (disclaimer machine-readable).
- Verdetto incluso nel `TechnicalAnalysisResponse` sotto chiave `entryTimingAdvisor` (ADR-030 §4).
- Nessuna chiamata LLM. Kdoc cita [[ta-entry-timing-stock-detail]] e [[elder-triple-screen-impulse-system]].

## Acceptance Criteria
- [ ] Per ogni combinazione della tabella di mapping il servizio restituisce il verdetto atteso.
- [ ] Verdetto `WAIT` espone `reentryCondition.code` + `description` coerenti con la riga.
- [ ] `rationale` strutturato (`screen1/2/3`, `wikiCitations`) non vuoto per verdetti ≠ INDETERMINATE.
- [ ] Tabella implementata in modo dichiarativo (data class + match function, no if/else annidati > 1 livello).
- [ ] Payload include `vi_gate: "this_advisor_assumes_vi_verdict_positive"`.
- [ ] `entryTimingAdvisor` incluso nel `TechnicalAnalysisResponse`.
- [ ] Nessuna chiamata LLM; logica deterministica Kotlin pure.
