# TSK-350 — FE: client TS backtest + hook useBacktest (on-demand) + selettori

## Obiettivo

Rigenerare il client TypeScript dallo schema OpenAPI aggiornato (TSK-348) per includere i tipi del backtest, implementare il hook `useBacktest` con semantica on-demand (non si attiva al mount della pagina), e aggiungere i selettori `years`/`horizonMonths` con gestione dello stato locale.

## Scope

### Client TS regen
- Rigenera il client TS da `openapi.yaml` (stesso processo di TSK-333 per la pipeline TA).
- Nuovi tipi esposti: `BacktestResultDto`, `BacktestStrategyDto`, `BacktestTradeDto`, `BacktestTimingEdgeDto`, `BacktestCaveatsDto`, enum `ExitReason`, `TimingEdgeLabel`, `BacktestStrategy`, `BacktestStatus`.

### Hook `useBacktest`
- Semantica **on-demand (lazy)**: il backtest NON parte al mount; parte solo al click del bottone "BACKTEST".
- Stato interno: `idle | loading | result | empty | error`.
  - `idle` → nessuna fetch attiva, bottone "BACKTEST" abilitato.
  - `loading` → spinner; bottone disabilitato.
  - `result` → `BacktestResultDto` disponibile (incluso `INSUFFICIENT_HISTORY`).
  - `empty` → caso 0 segnali (`noSignalsInPeriod: true` su `EP024_ENTER_NOW`).
  - `error` → errore di rete; esposizione via `NotificationProvider` (EP-015).
- Al cambio di `years` o `horizonMonths`, se un risultato è già presente, ri-eseguire il backtest automaticamente.

### Selettori years / horizonMonths
- `years`: 3 / 5 / max — default 5.
- `horizonMonths`: 1 / 3 / 6 / 12 — default 6.
- `equity` opzionale: input numerico; stato localStorage (chiave `backtest_equity_{ticker}`); mai inviato a persistenza server-side.
- Selettori implementati come componente controllato riusabile; cambio ri-esegue il backtest se già attivato.

## Acceptance Criteria
- [ ] Tipi TS generati correttamente da OpenAPI: `BacktestResultDto`, `BacktestStrategyDto`, `BacktestTradeDto`, enum tipati presenti.
- [ ] `useBacktest` in stato `idle` al mount — nessuna chiamata API al page load.
- [ ] Click sul trigger → transizione `idle → loading → result | empty | error`.
- [ ] Errore di rete → `NotificationProvider` riceve la notifica.
- [ ] Cambio `years` o `horizonMonths` con risultato già presente → ri-fetch automatico.
- [ ] `equity` da localStorage, mai nel body della request POST né in query param persistente.
- [ ] Vitest sul hook: stati `idle/loading/result/empty/error` coperti.
