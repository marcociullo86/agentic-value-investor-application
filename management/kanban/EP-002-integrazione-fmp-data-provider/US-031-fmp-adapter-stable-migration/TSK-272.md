# TSK-272 — BE — Migra FmpAdapterRestClient: endpoint routing + DTO /stable

## Context

FMP ha dismesso gli endpoint v3 (EOL 2025-08-31). `FmpAdapterRestClient` deve puntare esclusivamente a `https://financialmodelingprep.com/stable`. Questa è una migrazione tecnica del singolo punto di contatto con il provider esterno: l'interfaccia pubblica `FmpAdapter.kt` e tutta la pipeline a valle (cache, resilienza, rule engine) restano invariate.
[^src: management/kanban/EP-002-integrazione-fmp-data-provider/US-031-fmp-adapter-stable-migration/US-031.md §Business Rules]
[^src: design_&_architecture/decisions/ADR-004-fmp-integration.md §Endpoint base URL]

## Technical Specs

**Base URL**
- `src/main/resources/application.yml`: property `fmp.base-url` → `https://financialmodelingprep.com/stable`
- `.env.example` (se presente): variabile `FMP_BASE_URL` aggiornata di conseguenza

**Routing in `FmpAdapterRestClient.kt`**
- `fetchList(endpoint, ticker, limit)`: path `/{endpoint}/{ticker}` → `/{endpoint}?symbol={ticker}&limit={limit}&apikey={key}`. Endpoint coinvolti: `income-statement`, `balance-sheet-statement`, `cash-flow-statement`, `key-metrics`, `profile`.
- `searchSymbol(query)`: path `/search?query=` → `/search-symbol?query=`
- `screen(criteria)`: path `/stock-screener` → `/company-screener`

**DTO in `fmp/dto/`** — verifica campo per campo vs payload `/stable`:
- `ProfileDto`, `IncomeStatementDto`, `BalanceSheetDto`, `CashFlowDto`, `KeyMetricsDto`, `ScreenedStockDto`, `SearchHitDto`
- Mantenere tutti i campi come `val ...: Type?` (null-safety invariante da US-004)

**Fixture di test**
- Rigenerare i JSON in `src/backend/src/test/resources/fmp-fixtures/` con shape documentati `/stable`
- Aggiornare `FmpFixtureFactory` / `FmpFixtureLoader` di conseguenza

## Implementation Steps

1. Aggiornare `application.yml` con `fmp.base-url: https://financialmodelingprep.com/stable`
2. Modificare routing `FmpAdapterRestClient`: `fetchList` (symbol come query param), `searchSymbol` → `/search-symbol`, `screen` → `/company-screener`
3. Confrontare ogni DTO con il payload FMP `/stable`; applicare rename/aggiunta campi mantenendo null-safety
4. Rigenerare fixture JSON in `fmp-fixtures/`; aggiornare `FmpFixtureFactory` e `FmpFixtureLoader`
5. Eseguire `./gradlew build` fino a compilation verde prima di passare a TSK-273

**Vincoli:**
- Non modificare `FmpAdapter.kt` (signature metodi invariata)
- Non modificare `FmpResilienceConfig`, `ResilientFmpAdapter`, `FmpCacheService`, `FmpEventLogger`, `FmpHealthIndicator`, `FmpExceptions`
- Non modificare le entità DB né le migration Flyway esistenti
- Nessun path `api/v3` residuo in `application.yml`, `.env.example`, `FmpAdapterRestClient.kt`

## Definition of Done

- [ ] `application.yml` ha `fmp.base-url: https://financialmodelingprep.com/stable`; nessun path `v3` residuo
- [ ] `FmpAdapterRestClient.kt`: routing aggiornato per tutti e 3 i metodi (fetchList, searchSymbol, screen)
- [ ] Tutti i DTO aggiornati con null-safety invariante rispetto ai payload `/stable`
- [ ] Fixture JSON rigenerate e `FmpFixtureFactory`/`FmpFixtureLoader` aggiornati
- [ ] `./gradlew build` verde (compilation + unit test DTO)
- [ ] Nessuna regressione sull'interfaccia `FmpAdapter` pubblica
