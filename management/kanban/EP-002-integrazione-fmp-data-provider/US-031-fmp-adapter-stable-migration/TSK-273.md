# TSK-273 — QA — Aggiorna WireMock stub e integration test FMP /stable

## Context

Con TSK-272 il routing di `FmpAdapterRestClient` è migrato a `/stable`. Tutti i test che usano WireMock devono essere aggiornati per intercettare i nuovi path e query-param `/stable` invece dei vecchi `/v3`. Il pattern di riferimento è `Fmp429RetryWireMockIT` già presente nel progetto.
[^src: management/kanban/EP-002-integrazione-fmp-data-provider/US-031-fmp-adapter-stable-migration/US-031.md §Acceptance Criteria]

## Technical Specs

**Test di integrazione da aggiornare (WireMock / Testcontainers):**
- `FmpAdapterRestClientTest` (o `FmpAdapterRestClientIT`): aggiornare stub per nuovi path `?symbol=` e query-param
- `Fmp429RetryWireMockIT` (o equivalente): verificare che il pattern retry funzioni sui nuovi path `/stable`
- `SearchControllerIT`, `AnalysisControllerIT`: allineare mock/response-stub ai nuovi fixture e path
- `SearchControllerWebMvcTest`, `HistoricalControllerWebMvcTest`: aggiornare shape response se cambiati

**Controlli specifici:**
- Per `searchSymbol`: WireMock deve aspettarsi `GET /search-symbol?query=TTD` (non più `/search?query=TTD`)
- Per `fetchList income-statement`: `GET /income-statement?symbol=AAPL&limit=10` (non più `/income-statement/AAPL`)
- Per `screen`: `GET /company-screener` (non più `/stock-screener`)
- Tutti i response body devono riflettere i fixture rigenerati da TSK-272

## Implementation Steps

1. Identificare tutti i test che hanno stub WireMock con path `/v3` o path-variable ticker-based
2. Aggiornare gli stub con i nuovi path `/stable` e query-param `symbol=`
3. Allineare i response body ai fixture aggiornati da TSK-272
4. Eseguire `./gradlew test` e correggere fino a verde completo
5. Verificare che `Fmp429RetryWireMockIT` passi con i nuovi path (retry su 429 invariato)

## Definition of Done

- [ ] `./gradlew test` verde: tutti i test unit + integration BE passano
- [ ] Nessun stub WireMock residuo con path `/v3` o path-variable ticker-based
- [ ] `SearchControllerIT`, `AnalysisControllerIT`, `Fmp429RetryWireMockIT` (o equivalenti) passano
- [ ] `GET /api/search?query=TTD` (tramite IT) restituisce risultato con "The Trade Desk Inc."
- [ ] `GET /api/analysis/AAPL` (tramite IT) restituisce dati financials senza errori FMP
- [ ] `GET /api/screener?marketCap=LARGE,MEGA` (tramite IT) restituisce pagina risultati
