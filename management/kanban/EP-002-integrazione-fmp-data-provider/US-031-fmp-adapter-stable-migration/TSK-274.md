# TSK-274 — QA — Smoke test container: rebuild image + spot-check endpoint /stable

## Context

Dopo la migrazione BE (TSK-272) e il verde IT (TSK-273), verificare che l'immagine container si ricostruisca correttamente e che il container `vi-app` sia healthy ed esponga gli endpoint attesi verso FMP `/stable`.
[^src: management/kanban/EP-002-integrazione-fmp-data-provider/US-031-fmp-adapter-stable-migration/US-031.md §Acceptance Criteria]

## Technical Specs

- `docker compose build` (o `docker buildx build`) deve completare senza errori
- Container `vi-app` deve raggiungere lo stato `healthy` entro il timeout di healthcheck configurato
- Smoke test manuale (curl o Playwright headless) sui 3 endpoint critici

## Implementation Steps

1. `docker compose build vi-app` — verificare zero errori di build
2. `docker compose up -d` — avviare stack completo
3. Attendere `healthy` su `vi-app` (max 60s)
4. Eseguire spot-check:
   - `curl http://localhost:8080/api/search?query=TTD` → risposta non vuota con "The Trade Desk"
   - `curl http://localhost:8080/api/screener?marketCap=LARGE,MEGA` → pagina risultati (no 503)
   - `curl http://localhost:8080/api/analysis/AAPL` → dati financials (no 403/503)
5. Verificare che nei log del container non compaia nessun path `api/v3` nelle chiamate FMP

## Definition of Done

- [ ] `docker compose build vi-app` completa senza errori
- [ ] Container `vi-app` è `healthy`
- [ ] `GET /api/search?query=TTD` restituisce risultato con "The Trade Desk Inc."
- [ ] `GET /api/screener?marketCap=LARGE,MEGA` restituisce pagina risultati (no 503)
- [ ] `GET /api/analysis/AAPL` restituisce dati financials (no 403/503)
- [ ] Nessun path `api/v3` nei log FMP del container
