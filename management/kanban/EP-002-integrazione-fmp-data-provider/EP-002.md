# EP-002 — Integrazione FMP Data Provider
> Costruire il layer di accesso ai dati finanziari su FMP API con caching 24h, throttling e resilienza, base di ogni analisi value investing.

## Obiettivo
Fornire un'integrazione affidabile con Financial Modeling Prep capace di alimentare il Rule Engine (EP-003) e i moduli di valutazione (EP-004) senza esaurire la quota API, senza propagare errori transitori e con tipizzazione sicura dei dati finanziari. [^src: wiki/sources/vi-06-webapp-value-investing-fsd.md §RF2: Integrazione API (Financial Modeling Prep)]

## Valore di business
- Riduzione del costo per analisi grazie al caching (24h TTL) sulle chiamate FMP.
- Continuità di servizio in presenza di errori transitori del provider esterno (fallback cache).
- Affidabilità dei dati: tipizzazione stretta evita risultati di analisi falsati da campi null.
