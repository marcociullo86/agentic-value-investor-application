# TSK-031 — Bootstrap infrastruttura: Spring Boot Gradle + Docker Compose + profili

## Obiettivo

Configurare l'infrastruttura di base del monorepo per lo sviluppo locale e CI.

## Scope tecnico

- `src/backend/build.gradle.kts`: dipendenze Spring Boot 3.x, Kotlin 1.9, JPA, Security,
  Flyway, PostgreSQL driver, Resilience4j, JJWT 0.12+, springdoc-openapi, Micrometer,
  Testcontainers, JUnit5.
  [^src: design_&_architecture/decisions/ADR-002-backend-stack.md]
- `src/backend/src/main/resources/application.yml`:
  - Profilo `dev`: Logback human-readable, CORS `localhost:3000`, Flyway on.
  - Profilo `test`: Testcontainers PostgreSQL, `fmp.mock=true`.
  - Profilo `prod`: Logback JSON, JWT secret required, Actuator protetto.
    [^src: design_&_architecture/decisions/ADR-009-deployment-target.md §Profili Spring]
- `src/docker/docker-compose.yml`: servizi `app`, `postgres:16`, `adminer`.
  [^src: design_&_architecture/decisions/ADR-009-deployment-target.md §Dev locale]
- `src/docker/.env.example`: variabili `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`,
  `FMP_API_KEY`, `FMP_BASE_URL`, `JWT_SIGNING_SECRET`, `CORS_ALLOWED_ORIGINS`.
  [^src: design_&_architecture/decisions/ADR-009-deployment-target.md §Variabili d'ambiente]
- `ValueInvestingWebappApplication.kt`: `@SpringBootApplication`.
- `config/`: `CorsConfig`, `JacksonConfig`, `RestClientConfig`, `OpenApiConfig`.
  [^src: design_&_architecture/components/backend-components.md §config]
- `api/error/GlobalExceptionHandler.kt` + `ProblemDetailsMapper.kt`: mapper RFC 9457.
  [^src: design_&_architecture/decisions/ADR-007-api-contract.md]
- `RequestIdFilter.kt`: `X-Request-Id` MDC.

## Criteri di completamento (DoD)

- [ ] `gradle bootRun --args='--spring.profiles.active=dev'` avvia senza errori.
- [ ] `docker-compose up` porta app + postgres su.
- [ ] Flyway esegue migrations all'avvio.
- [ ] `/actuator/health` → 200 UP.
- [ ] `GET /api/openapi.json` → schema OpenAPI valido in profilo dev.
