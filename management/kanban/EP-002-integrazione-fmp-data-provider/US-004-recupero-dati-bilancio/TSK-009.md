# TSK-009 — FmpAdapter: recupero strutturato dei 4 set di dati di bilancio

## Obiettivo

Implementare i metodi dell'`FmpAdapterRestClient` che recuperano i quattro dataset di
bilancio decennali da FMP, mappandoli in DTO Kotlin nullable-aware.

## Scope tecnico

- Interfaccia `FmpAdapter` — metodi:
  - `getIncomeStatement(ticker: String, limit: Int = 10): List<IncomeStatementDto>`
  - `getBalanceSheet(ticker: String, limit: Int = 10): List<BalanceSheetDto>`
  - `getCashFlow(ticker: String, limit: Int = 10): List<CashFlowDto>`
  - `getKeyMetrics(ticker: String, limit: Int = 10): List<KeyMetricsDto>`
  [^src: design_&_architecture/components/backend-components.md §FmpAdapter]
- DTO Kotlin con tutti i campi finanziari come `val ...: Double?` (null safety).
  [^src: design_&_architecture/decisions/ADR-004-fmp-integration.md §Adapter pattern]
- `FmpAdapterRestClient`: usa Spring `RestClient` con base URL da property
  `fmp.base-url` + `?apikey=${fmp.api-key}&limit={limit}`.
  [^src: design_&_architecture/decisions/ADR-004-fmp-integration.md §endpoint base URL]
- Ticker inesistente (lista vuota da FMP) → throw `FmpTickerNotFoundException`.
- `FinancialDataService`: facade che coordina le 4 chiamate e assembla `FinancialDataset`.
  [^src: design_&_architecture/components/backend-components.md §FinancialDataService]
- `GET /api/financials/{ticker}` in `FinancialsController` (endpoint diagnostico).
  [^src: design_&_architecture/api/openapi.yaml §/api/financials/{ticker}]

## Vincoli e note

- Campi mancanti = `null`, mai `0.0` (US-004 AC "campi mancanti = assenti, mai 0").
- Le 4 chiamate FMP in `AnalyzeTickerService` saranno parallelizzate con
  `CompletableFuture` (TSK-018 le orchesta; questo task espone solo i metodi adapter).
  [^src: design_&_architecture/components/backend-components.md §Decisioni di concorrenza]

## Criteri di completamento (DoD)

- [ ] Chiamata per AAPL restituisce ≤ 10 oggetti ordinati dalla più recente.
- [ ] Campo opzionale mancante nella source = `null` nel DTO, non `0.0`.
- [ ] Ticker non esistente → `FmpTickerNotFoundException`.
- [ ] Unit test con fixture JSON da `fmp-fixtures/`.
