# TSK-032 — Dockerfile multi-stage + CI pipeline

## Obiettivo

Configurare il Dockerfile multi-stage per la build artefatto finale e una pipeline CI
minimale (build + test).

## Scope tecnico

- `src/docker/Dockerfile` multi-stage:
  - Stage 1 `fe-build`: `node:20-alpine`, `npm ci && npm run build && npm run export`.
  - Stage 2 `be-build`: `gradle:8-jdk21`, `gradle bootJar --no-daemon`.
  - Stage 3 runtime: `eclipse-temurin:21-jre-alpine`, copia JAR + `out/` static in
    `/app/public`.
    [^src: design_&_architecture/decisions/ADR-009-deployment-target.md §Build artifact]
- Pipeline CI (GitHub Actions o equivalente):
  - Job `be-test`: `gradle test` con profilo `test` (Testcontainers).
  - Job `fe-test`: `npm run test` (Vitest).
  - Job `fe-e2e`: `npx playwright test` headless (dipende da `be-test`).
  - Job `docker-build`: `docker build .` (smoke test immagine).
- `EXPOSE 8080`, `ENTRYPOINT ["java","-jar","/app/app.jar"]`.

## Criteri di completamento (DoD)

- [ ] `docker build -t vi-webapp .` completa senza errori.
- [ ] Container avviato espone `/actuator/health` su porta 8080.
- [ ] Pipeline CI green su branch `master`.
- [ ] Immagine finale serve asset statici FE da `/app/public`.
