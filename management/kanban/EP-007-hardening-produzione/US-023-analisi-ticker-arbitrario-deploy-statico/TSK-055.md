# TSK-055 — Route /analysis?ticker= (static export)

## Context

ADR-013 sceglie opzione B: pagina statica `app/analysis/page.tsx` con query param; eliminare `app/analysis/[ticker]/` e `generateStaticParams()`. REST `GET /api/analysis/{ticker}` invariato.
[^src: design_&_architecture/decisions/ADR-013-fe-analysis-routing-static-export.md §Decisione]
[^src: management/kanban/EP-007-hardening-produzione/US-023-analisi-ticker-arbitrario-deploy-statico/US-023.md §Acceptance Criteria]

## Technical Specs

- **FE:** Creare `src/frontend/app/analysis/page.tsx` (Server/Client wrapper).
- **Client:** `AnalysisPageClient` legge `searchParams.ticker` (Next.js 16 App Router), normalizza uppercase, redirect o messaggio se assente.
- **Rimozione:** directory `src/frontend/app/analysis/[ticker]/` incluso `generateStaticParams()` whitelist 8 ticker.
- **Coerenza:** stesso pattern di `app/moat/page.tsx` (`?ticker=`).
- **Export:** mantenere `output: 'export'` in `next.config`.

## Implementation Steps

1. Spostare/adattare logica da `[ticker]/page.tsx` a `page.tsx` + `useSearchParams`.
2. Eliminare route dinamica e static params.
3. Aggiornare commenti in `AnalysisPageClient.tsx`, `historical.ts`.
4. `npm run build` — verificare che `out/analysis/index.html` (o equivalente) sia generato senza 8 path ticker.

## Definition of Done

- [ ] Navigazione diretta a `/analysis?ticker=AAPL` renderizza dashboard.
- [ ] Nessuna directory `app/analysis/[ticker]` residua.
- [ ] Build static export verde.

## Dependencies

- Nessuna (prerequisito TSK-056, TSK-057)
