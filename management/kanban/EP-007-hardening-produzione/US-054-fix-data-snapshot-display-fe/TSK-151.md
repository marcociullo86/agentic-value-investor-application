# TSK-151 — lib/format-date.ts: helper formatSnapshotDate

## Context

US-054 documenta una regressione in produzione (2026-05-23): il pannello "Dati al" mostra `"1.779.484.360,919"` (timestamp epoch ms formattato con separatori italiani) invece della data leggibile "22 mag 2026, 11:12 UTC". Il backend può serializzare `dataSnapshotAt` come epoch ms long (Jackson default legacy) o come ISO-8601 string a seconda della configurazione `spring.jackson.serialization.write_dates_as_timestamps`. Questo task crea il helper riusabile che gestisce entrambi i formati.

## Technical Specs

- **File da creare:** `src/frontend/lib/format-date.ts`
- **Funzione esportata:** `export function formatSnapshotDate(value: number | string | null | undefined): string`
- **Logica:**
  1. Se `value == null || value === undefined` → restituire `"—"` (stringa trattino em, indica dato assente).
  2. Se `typeof value === "number"` → interpretare come millisecondi epoch: `new Date(value)`.
  3. Se `typeof value === "string"`:
     - Se la stringa è un numero puro (es. `"1779484360919"`) → parsare come `parseInt(value, 10)` → `new Date(intValue)`.
     - Altrimenti → interpretare come ISO-8601: `new Date(value)`.
  4. Se il `Date` risultante è `Invalid Date` (NaN) → restituire `"data non disponibile"`.
  5. Formattare con `Intl.DateTimeFormat` con le opzioni: `{ locale: "it-IT", day: "numeric", month: "short", year: "numeric", hour: "2-digit", minute: "2-digit", timeZone: "UTC" }`.
  6. Appende il suffisso `" UTC"` al risultato formattato (es. `"22 mag 2026, 11:12 UTC"`).
- **Nota implementativa:** verificare che il separatore tra data e ora sia `, ` (virgola + spazio) come nel formato target. `Intl.DateTimeFormat` con `it-IT` potrebbe usare ` alle ` o `, ` — usare `formatToParts` se necessario per un controllo esatto del separatore.
- **Export:** la funzione è l'unico export del file; aggiungere anche il tipo `export type SnapshotDateValue = number | string | null | undefined` per uso esterno.

## Implementation Steps

1. Creare il file `src/frontend/lib/format-date.ts`.
2. Implementare `formatSnapshotDate` con la logica sopra descritta.
3. Verificare manualmente con `console.log(formatSnapshotDate(1779484360919))` → atteso `"22 mag 2026, 11:12 UTC"`.
4. Verificare `formatSnapshotDate("2026-05-22T11:12:40.919Z")` → stessa stringa.
5. Verificare `formatSnapshotDate(null)` → `"—"`.
6. Verificare `formatSnapshotDate(NaN)` → `"data non disponibile"`.
