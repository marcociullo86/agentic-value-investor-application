# US-022 — Dipendenze UI allineate allo stack senza override peer

## Descrizione
Come team responsabile della pipeline di build frontend, voglio installare le dipendenze UI senza flag che rilassano la risoluzione peer, affinché CI, container e ambienti locali usino una dependency tree verificata e allineata alle versioni approvate dello stack.

## Business Rules
- Nessun passo di installazione in CI, Dockerfile o workflow contract-check usa override sulla risoluzione peer delle dipendenze.
- La libreria di data-fetching client-side deve dichiarare compatibilità con la major React approvata dallo stack, oppure essere sostituita con alternativa compatibile documentata in ADR.
- In assenza di release upstream compatibile, la decisione (pin versione alternativa, fork, sostituzione libreria) è documentata in L4 prima dell'implementazione.

## UI Reference
N/A — storia infrastrutturale build.

## Acceptance Criteria
- [ ] `npm install` (o equivalente) in CI frontend completa senza `--legacy-peer-deps` né flag analoghi.
- [ ] Stage build container frontend completa senza override peer.
- [ ] Workflow contract-check frontend completa senza override peer.
- [ ] Suite test unitari e E2E frontend restano verdi dopo la rimozione degli override.
