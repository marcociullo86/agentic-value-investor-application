# TSK-053 — Bump swr peer-compatible React 19

## Context

US-022 elimina `--legacy-peer-deps` da CI/Docker. ADR-001 appendice ordina upgrade `swr` alla prima release con peer widened a React 19, prima di sostituire la libreria.
[^src: management/kanban/EP-007-hardening-produzione/US-022-dipendenze-ui-senza-override/US-022.md §Acceptance Criteria]
[^src: design_&_architecture/decisions/ADR-001-frontend-stack.md §Allineamento stack v2026]

## Technical Specs

- **FE:** `src/frontend/package.json` — aggiornare `swr` da `2.2.5` a release ≥2.3 con peer `react@19` (verificare su npm prima del bump).
- **Lockfile:** rigenerare `package-lock.json` con `npm install` **senza** `--legacy-peer-deps`.
- **Call-site:** nessun cambio API atteso; verificare `useSWR` in stores/hooks esistenti.
- **Test:** `npm run test` (Vitest) + build `npm run build` localmente.

## Implementation Steps

1. Verificare peerDependencies della release target su npm.
2. Bump versione + `npm install` in `src/frontend/`.
3. Eseguire Vitest e `next build` (export static).
4. Documentare versione scelta in handoff dev (per gap `fe-swr-peer-r19`).

## Definition of Done

- [ ] `npm install` completa senza ERESOLVE su peer react.
- [ ] Vitest e build FE verdi.
- [ ] Prerequisito soddisfatto per TSK-054 (rimozione flag CI/Docker).

## Dependencies

- Nessuna
