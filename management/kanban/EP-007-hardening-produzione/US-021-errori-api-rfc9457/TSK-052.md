# TSK-052 — OpenAPI ProblemDetail extension al top-level

## Context

ADR-012 §4 richiede allineamento schema ed esempi errore in OpenAPI: extension come proprietà aggiuntive dello schema, non oggetto `properties` annidato.
[^src: design_&_architecture/decisions/ADR-012-problemdetail-rfc9457-flatten.md §4. Contratto OpenAPI]
[^src: management/kanban/EP-007-hardening-produzione/US-021-errori-api-rfc9457/US-021.md §Acceptance Criteria]

## Technical Specs

- **BE/Docs L4:** `design_&_architecture/api/openapi.yaml` — component `ProblemDetails` / esempi 404 ticker.
- **Esempio canonico:** body con `ticker` sibling di `status` (come ADR-012 appendice ADR-007).
- **endpoints-overview.md:** allineare nota error format se diverge (solo se richiesto da contract-check drift).

## Implementation Steps

1. Aggiornare schema `ProblemDetails` rimuovendo nesting `properties` per extension business.
2. Aggiornare esempi su `GET /api/search/{ticker}`, `GET /api/analysis/{ticker}` (404).
3. Rigenerare tipi FE se pipeline contract-check lo richiede (verifica job `contract-check.yml`).

## Definition of Done

- [ ] OpenAPI validato (lint/spectral se presente in CI).
- [ ] Esempio 404 ticker coerente con output runtime post TSK-050.
- [ ] Contract-check OpenAPI drift verde o delta documentato in handoff.
