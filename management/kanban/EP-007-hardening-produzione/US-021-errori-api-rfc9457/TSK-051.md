# TSK-051 — Assert ProblemDetail extension top-level

## Context

I test IT e contract oggi assertano `$.properties.ticker`. US-021 richiede migrazione a `$.ticker` in un unico changeset con il converter BE.

## Technical Specs

- **QA:** Aggiornare assert JSON in:
  - `SearchControllerIT.kt` — scenario 404 `GET /api/search/XXXXXXXX`
  - `AnalysisControllerIT.kt` — scenario 404 ticker unknown
  - `SearchControllerWebMvcTest.kt`, `AuthControllerContractTest.kt` se assertano `properties.*`
  - `OpenApiContractSupport.kt` / contract-check se validano shape errore
- **Path target:** `jsonPath("$.ticker")` (non `$.properties.ticker`).
- **Endpoint coperti:** almeno `/api/search/{ticker}`, `/api/analysis/{ticker}` (404 FMP ticker not found).

## Implementation Steps

1. Cercare `properties.ticker` e `properties.` in `src/backend/src/test`.
2. Sostituire assert con path top-level; aggiungere assert negativo che `properties` non contenga extension business.
3. Eseguire `./gradlew test` modulo backend.
