# TSK-147 — Contract test OpenAPI drift: dcfIntrinsicValue description per-share

## Context

US-052 richiede che il contratto OpenAPI rifletta la nuova semantica per-share del campo `dcfIntrinsicValue`. Il contract test esistente (TSK-037/TSK-047 pattern) deve essere esteso per verificare che la description del campo nel documento OpenAPI generato non sia quella precedente ("intrinsic value (USD)" o simile) ma contenga esplicitamente "per share".
[^src: management/kanban/EP-007-hardening-produzione/US-052-dcf-fair-value-per-share/US-052.md §Acceptance Criteria]

## Technical Specs

- **Suite:** aggiornare o estendere il test di drift OpenAPI esistente (probabile file `OpenApiContractTest.kt` o `ContractCheckIT.kt` in `src/backend/src/test`).
- **Assert target:** il documento OpenAPI generato a runtime (endpoint `GET /v3/api-docs`) deve contenere, per il campo `dcfIntrinsicValue` nello schema `RuleEngineResultResponse`, una description che includa la stringa `"per share"` (case-insensitive).
- **Assert negativo:** la description non deve contenere solo la stringa generica `"intrinsic value (USD)"` senza menzione di "share".
- **Schema da verificare:** `components.schemas.RuleEngineResultResponse.properties.dcfIntrinsicValue.description`.
- Se il progetto usa il contract-check workflow GitHub Actions (`contract-check.yml`), verificare che il test sia incluso nello stesso step `be-test`.

## Implementation Steps

1. Individuare il file di contract test OpenAPI esistente nel modulo backend.
2. Aggiungere un test case che esegue `GET /v3/api-docs`, naviga il JSON fino a `$.components.schemas.RuleEngineResultResponse.properties.dcfIntrinsicValue.description` e verifica che contenga "per share".
3. Aggiungere assert negativo se utile per evitare falsi positivi futuri.
4. Eseguire `./gradlew :backend:test` verificando che il nuovo test passi.

## Definition of Done

- [ ] Contract test asserisce che `dcfIntrinsicValue.description` contiene "per share".
- [ ] Il test fallisce se la description viene accidentalmente rimossa o reimpostata al valore precedente.
- [ ] `./gradlew :backend:test` verde.
- [ ] Nessuna regressione sui contract test esistenti (ruleId invariati, struttura OpenAPI intatta).

## Dependencies

- TSK-145 (description OpenAPI aggiornata nel sorgente — prerequisito per il test di drift)
- TSK-146 (suite test backend verde prima di aggiungere ulteriori test nella stessa run)
