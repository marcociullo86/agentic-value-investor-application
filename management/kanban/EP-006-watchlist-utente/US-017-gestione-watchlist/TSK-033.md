# TSK-033 — AuthController: POST /api/auth/register, /login, /refresh, /logout

## Obiettivo

Implementare il layer di autenticazione JWT stateless con Spring Security.

## Scope tecnico

- `AuthController`:
  - `POST /api/auth/register`: crea `User`, hash BCrypt cost 12, ritorna `UserProfile`.
    [^src: design_&_architecture/api/openapi.yaml §/api/auth/register]
  - `POST /api/auth/login`: valida credenziali, emette access token JWT (TTL 15min) +
    refresh token opaco (UUID, TTL 30 giorni, persistito in `refresh_tokens`).
    [^src: design_&_architecture/api/openapi.yaml §/api/auth/login]
  - `POST /api/auth/refresh`: scambia refresh token → nuovo access token.
  - `POST /api/auth/logout`: revoca refresh token (`revoked_at = now()`).
  [^src: design_&_architecture/decisions/ADR-006-authentication.md §Architettura]
- `JwtService` (libreria `jjwt 0.12+`): issue + validate JWT HS256, claim `sub`, `email`,
  `iat`, `exp`. Secret da `JWT_SIGNING_SECRET` env var.
  [^src: design_&_architecture/decisions/ADR-006-authentication.md §Token]
- `SecurityConfig`: `SecurityFilterChain`, permit all per `/api/auth/**`, `/api/search/**`,
  `/api/screener`, `/api/analysis/**`, `/api/historical/**`, `/actuator/health`.
  Authenticate per `/api/watchlist/**`, `/api/moat-checklist/**`, `/api/dcf-overrides/**`.
  [^src: design_&_architecture/decisions/ADR-006-authentication.md §Endpoint policy]
- `JwtAuthenticationFilter`: valida `Authorization: Bearer` su ogni request protetta.
- `UserDetailsServiceImpl`: carica `User` da `UserRepository`.
- `PasswordEncoderConfig`: `BCryptPasswordEncoder(12)` bean.
- `users.email`: UNIQUE su `lower(email)`. Email già registrata → 409 Conflict.

## Criteri di completamento (DoD)

- [ ] Registrazione + login → access token JWT valido + refresh token.
- [ ] Refresh token scambia nuovo access token.
- [ ] Endpoint protetto con token scaduto → 401.
- [ ] Email già registrata → 409 ProblemDetails.
- [ ] Integration test `AuthControllerIT` con Testcontainers.
