# TSK-028 — Flyway migrations V005 + V008: watchlists, watchlist_items, fmp_api_event_log

## Obiettivo

Creare le migration rimanenti per watchlist e log eventi FMP.

## Scope tecnico

- `V005__create_watchlists.sql`:
  - `watchlists`: `id UUID PK`, `user_id FK → users(id) ON DELETE CASCADE`,
    `name VARCHAR(120) NOT NULL DEFAULT 'My Watchlist'`, `is_default BOOLEAN DEFAULT true`,
    `created_at TIMESTAMPTZ DEFAULT now()`.
    [^src: design_&_architecture/data/er-diagram.md §watchlists]
  - Partial unique index: `(user_id) WHERE is_default = true` (una sola watchlist default).
  - `watchlist_items`: `id UUID PK`, `watchlist_id FK → watchlists(id) ON DELETE CASCADE`,
    `ticker FK → stocks(ticker)`, `added_at TIMESTAMPTZ DEFAULT now()`.
    [^src: design_&_architecture/data/er-diagram.md §watchlist_items]
  - Unique: `(watchlist_id, ticker)`.
- `V008__create_fmp_event_log.sql`:
  - `fmp_api_event_log`: `id BIGSERIAL PK`, `occurred_at TIMESTAMPTZ DEFAULT now()`,
    `event_type VARCHAR(40) NOT NULL`, `ticker VARCHAR(10) NULL FK → stocks(ticker)`,
    `endpoint VARCHAR(40) NULL`, `http_status INT NULL`, `detail TEXT NULL`.
    [^src: design_&_architecture/data/er-diagram.md §fmp_api_event_log]
  - Indice: `(event_type, occurred_at DESC)`.

## Criteri di completamento (DoD)

- [ ] V005 e V008 applicano senza errori dopo V001-V004+V006+V007.
- [ ] Partial unique index su `watchlists` verificabile.
- [ ] Unique constraint `(watchlist_id, ticker)` su `watchlist_items`.
- [ ] `flyway validate` pulito (tutti V001-V008).
