# TSK-322 — FE NetNetBadge + 2 formatter NCAV

## Obiettivo

Creare il componente `NetNetBadge` e i 2 formatter per i ruleId `NCAV_LATEST` e `NET_NET_RATIO` in
`formatters.ts`, da usare nel TrafficLightPanel.

## Scope

### 1. Estensione `formatters.ts` — 2 nuovi formatter (ADR-029 §6)

Aggiungere a `src/frontend/lib/rule-signals/formatters.ts` (creato in TSK-319):

```typescript
NCAV_LATEST: (s) => {
  // s as RuleSignalNcavLatest
  return {
    title: 'NCAV (Net Current Asset Value)',
    subtitle: `NCAV per azione: $${fmtMoney(s.ncavPerShare)} (totale: ${fmtMoneyCompact(s.ncavTotal)})`,
    tooltip: 'Net Current Asset Value = Attivo Corrente - Passività Totali (Graham Cap.15)',
  };
},
NET_NET_RATIO: (s) => {
  // s as RuleSignalNetNetRatio
  return {
    title: 'Net-Net Ratio (Graham)',
    subtitle: `Prezzo $${fmtMoney(s.priceLatest)} vs 2/3 NCAV $${fmtMoney(s.ncavPerShare ? s.ncavPerShare * (2/3) : null)} (ratio ${fmtRatio(s.ratio)})`,
    tooltip: 'GREEN se prezzo < 2/3 × NCAV per azione — criterio Graham Cap.15 (soglia 0.6667)',
  };
},
```

Paranoid fallback identico agli altri 13 formatter.

### 2. Componente `NetNetBadge`

File: `src/frontend/components/analysis/NetNetBadge.tsx`

- Visibile **solo se** il segnale `NET_NET_RATIO` è `GREEN`.
- Riusa `<Badge>` di shadcn/ui (design token system ADR-023), stesso pattern di `<MrMarketBadge>`
  (EP-013).
- Stile: colore verde/accent coerente con segnale GREEN.
- Testo visibile: "Net-Net".
- `aria-label="Criterio Graham Net-Net soddisfatto"` (WCAG AA — non solo colore).
- Tooltip: "Prezzo inferiore ai 2/3 del Net Current Asset Value — criterio Graham Cap.15".

Props:
```typescript
interface NetNetBadgeProps {
  signals: RuleSignal[];
}
```

Logic:
```typescript
const netNetSignal = signals.find(s => s.ruleId === 'NET_NET_RATIO');
if (!netNetSignal || netNetSignal.signal !== 'GREEN') return null;
```

### 3. Integrazione in `AnalysisPage` / header pannello segnali

Posizionare `<NetNetBadge signals={analysis.signals} />` nella pagina `/analysis` accanto al
titolo del ticker (o nel header del pannello segnali — il fe-dev sceglie la posizione più coerente
con il layout esistente del badge Mr. Market EP-013 e documenta in handoff).

## Invarianti

- Il TrafficLightPanel accoglie le 2 nuove righe NCAV senza modifica al codice del pannello stesso
  (rendering data-driven — ADR-029 §6).
- Nessuna modifica ai 13 ruleId esistenti.
