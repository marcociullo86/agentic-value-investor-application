# TSK-200 — QA Test networkErrorInterceptor: 4 scenari rete

## Context
US-066 AC richiede test per 4 categorie errori di rete: offline, timeout, server 500, validazione 422.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-066-errori-rete-categorizzati/US-066.md §AC]

## Technical Specs
- **QA:** Vitest + mock fetch/navigator
- **Scenari:**
  - Simulazione offline (navigator.onLine = false) → messaggio "Sei offline"
  - Simulazione timeout (AbortController) → messaggio retry
  - Errore 500 con X-Correlation-Id → messaggio con "contatta supporto" + correlationId copiabile
  - Errore 422 → messaggio con indicazione campo da correggere

## Implementation Steps
1. Test offline: mock navigator.onLine = false, verifica notifica error
2. Test timeout: mock AbortError, verifica notifica warning
3. Test 500: mock response 500 con header X-Correlation-Id, verifica correlationId
4. Test 422: mock response 422 con body validazione, verifica campo indicato

## Definition of Done
- [ ] 4 scenari coperti
- [ ] Correlation ID propagato nel test 500
- [ ] Messaggi coerenti con UX spec
- [ ] Code review approvata
