# EP-015 — Notifiche Errori Frontend Accessibili

> Dotare il frontend di un sistema centralizzato di notifiche errori che comunichi stati problematici in modo chiaro, accessibile WCAG 2.2 AA e azionabile, senza mai esporre stack trace o codici HTTP raw all'utente.

## Obiettivo
Implementare il sistema di notifiche descritto in REQ-02: un servizio centralizzato di notifiche (toast/snackbar) con API tipizzata a 4 livelli (success, info, warning, error), mappatura dei codici errore backend a messaggi user-friendly localizzati, Correlation ID copiabile nelle notifiche di errore, gestione categorizzata degli errori di rete (offline, timeout, server, validazione), validazione form inline con summary accessibile, e piena conformità WCAG 2.2 AA (role, aria-live, contrasto, auto-dismiss, tastiera). [^src: wiki/concepts/frontend-error-notifications.md §Dettaglio]

## Valore di business
- L'utente riceve messaggi azionabili ("Riprova tra qualche istante") invece di codici tecnici ("500 Internal Server Error").
- Il Correlation ID copiabile riduce i tempi di risoluzione ticket supporto: l'utente incolla l'ID, il supporto filtra i log backend.
- Zero violazioni critiche WCAG nelle notifiche garantisce accessibilità a utenti con disabilità visive e motorie.

## Confidence: 85%
I requisiti sono esaustivi con tabelle di specifiche WCAG, categorie errore e CTA attesi. L'integrazione Correlation ID frontend è ben documentata. Il 15% di incertezza riflette: (a) infrastruttura i18n non ancora presente — la synthesis nota che il progetto ha stringhe italiane hardcoded nei rationale del Rule Engine; la localizzazione dei messaggi errore richiede un layer i18n che potrebbe essere un prerequisito; (b) dimensione dell'epica (5 storie con componente accessibilità significativo). [^src: wiki/syntheses/fintech-hardening-requirements-map.md §Requisiti non funzionali trasversali]

## Dipendenze
- EP-014 US-059 (Correlation ID middleware): il backend deve propagare `X-Correlation-Id` nelle response HTTP affinché il frontend lo catturi e lo esponga nelle notifiche.
- EP-016 (accessibilità baseline): le notifiche condividono i vincoli WCAG 2.2 AA con la baseline accessibilità di REQ-03.
