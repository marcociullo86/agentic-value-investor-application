# TSK-202 — QA Test FormErrorSummary: inline + summary + aria + screen reader

## Context
US-067 AC richiede verifica inline error, summary, aria-describedby e annuncio screen reader.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-067-validazione-form-accessibile/US-067.md §AC]

## Technical Specs
- **QA:** Vitest + React Testing Library + axe-core
- **Scenari:**
  - Submit con campo invalido → messaggio inline sotto il campo
  - Campo invalido collegato via `aria-describedby`
  - Summary appare in cima al form dopo submit fallito
  - Summary annunciata da screen reader (aria-live="assertive")
  - Form login, register, watchlist usano il nuovo pattern

## Implementation Steps
1. Test inline: submit con campo vuoto, verifica messaggio sotto il campo
2. Test aria-describedby: verifica attributo su campo invalido
3. Test summary: submit fallito, verifica lista errori in cima
4. Test screen reader: axe-core verifica aria-live
5. Test form esistenti: login, register, watchlist

## Definition of Done
- [ ] Inline error testato
- [ ] aria-describedby verificato
- [ ] Summary testata
- [ ] 3 form esistenti coperti
- [ ] Code review approvata

## Dependencies
- TSK-201 (FormErrorSummary + form aggiornati)
