# TSK-201 — FE FormErrorSummary + aggiornamento form esistenti

## Context
US-067 richiede errori di validazione inline + summary accessibile in cima al form, con aggiornamento dei form esistenti.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-067-validazione-form-accessibile/US-067.md §AC]
[^src: design_&_architecture/decisions/ADR-022-frontend-error-notifications.md §5]

## Technical Specs
- **FE:** `components/forms/form-error-summary.tsx`
- **Integrazione:** React Hook Form + Zod (già nello stack)
- **Errori inline:** messaggio sotto il campo invalido, collegato via `aria-describedby`
- **Summary:** appare in cima al form al submit fallito, `aria-live="assertive"`, focus programmato
- **Form da aggiornare:** login, registrazione, watchlist (add ticker)
- **Messaggi:** localizzati via i18n

## Implementation Steps
1. Creare `FormErrorSummary` component con lista errori e link ai campi
2. Implementare `aria-describedby` su ogni campo invalido
3. Implementare focus programmato sulla summary al submit fallito
4. Aggiornare LoginForm per usare FormErrorSummary
5. Aggiornare RegisterForm per usare FormErrorSummary
6. Aggiornare WatchlistForm per usare FormErrorSummary

## Definition of Done
- [ ] Errori inline sotto il campo specifico
- [ ] `aria-describedby` su campi invalidi
- [ ] Summary in cima al form con `aria-live`
- [ ] 3 form esistenti aggiornati
- [ ] Messaggi localizzati
- [ ] Code review approvata
