# TSK-203 — FE Hardening a11y NotificationToast: contrasto + icone + multi-canale

## Context
US-068 richiede conformità WCAG 2.2 AA completa sulle notifiche: contrasto verificato, auto-dismiss con tempi adeguati, icone distinte per livello.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-068-accessibilita-notifiche-wcag/US-068.md §AC]
[^src: design_&_architecture/decisions/ADR-022-frontend-error-notifications.md §2]

## Technical Specs
- **FE:** Hardening `NotificationToast`
- **Contrasto:** testo >= 4.5:1, icone e bordi >= 3:1 (usando token semantici EP-016)
- **Auto-dismiss:** minimo 6s, >= 8s per testi lunghi; pausa al focus e hover confermata
- **Icone:** icona distinta per ogni livello (success ✓, info ℹ, warning ⚠, error ✗)
- **Esc:** chiude notifica più recente (già in TSK-195, qui verifica e fix)
- **Multi-canale:** informazione non veicolata solo tramite colore

## Implementation Steps
1. Verificare contrasto colori toast con tool di misura
2. Aggiustare token colori se necessario per raggiungere 4.5:1 / 3:1
3. Verificare e confermare auto-dismiss timing (6s / 8s)
4. Verificare pausa al focus/hover
5. Assicurare icone distinte e semantiche per ogni livello
6. Verifica multi-canale: icona + colore + testo

## Definition of Done
- [ ] Contrasto testo >= 4.5:1 verificato
- [ ] Contrasto icone/bordi >= 3:1 verificato
- [ ] Auto-dismiss >= 6s, pausa confermata
- [ ] Icona distinta per livello
- [ ] Multi-canale informazione
- [ ] Code review approvata

## Dependencies
- TSK-195 (NotificationToast base)
