# TSK-204 — QA axe-core audit notifiche + contrasto + screen reader

## Context
US-068 AC richiede audit axe-core zero violazioni, contrasto strumentale, screen reader e auto-dismiss verificato.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-068-accessibilita-notifiche-wcag/US-068.md §AC]

## Technical Specs
- **QA:** Vitest + axe-core + Playwright
- **Scenari:**
  - axe-core: zero violazioni critiche relative alle notifiche
  - Screen reader: notifiche info → polite, error → assertive (annuncio immediato)
  - Contrasto: testo >= 4.5:1, icone >= 3:1 (tool misura automatico)
  - Auto-dismiss: non prima di 6s; pausa confermata al focus/hover
  - Esc chiude notifica più recente
  - 4 tipi (success, info, warning, error) distinguibili senza colore

## Implementation Steps
1. axe-core scan su componente NotificationToast per ogni livello
2. Test screen reader: verifica aria-live polite/assertive
3. Test contrasto: misura automatica rapporto colore testo/sfondo
4. Test timing: verifica auto-dismiss >= 6s, pausa al focus
5. Test Esc: verifica chiusura notifica più recente
6. Test distinguibilità: 4 livelli distinguibili senza colore (icona diversa)

## Definition of Done
- [ ] axe-core zero serious/critical
- [ ] Screen reader polite/assertive corretto
- [ ] Contrasto verificato strumentalmente
- [ ] Auto-dismiss timing verificato
