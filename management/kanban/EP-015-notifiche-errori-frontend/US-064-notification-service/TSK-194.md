# TSK-194 — FE NotificationProvider + useNotification hook

## Context
US-064 richiede un servizio centralizzato di notifiche con API tipizzata a 4 livelli. Il NotificationProvider gestisce la coda notifiche ed espone l'hook useNotification.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-064-notification-service/US-064.md §AC]
[^src: design_&_architecture/decisions/ADR-022-frontend-error-notifications.md §1]

## Technical Specs
- **FE:**
  - `components/notifications/notification-provider.tsx` — React Context con coda notifiche
  - `hooks/use-notification.ts` — hook `useNotification()` con `notify.success()`, `notify.info()`, `notify.warning()`, `notify.error()`
- **API tipizzata:**
  ```typescript
  type NotificationLevel = 'success' | 'info' | 'warning' | 'error';
  interface NotificationOptions {
    title: string; message: string; level: NotificationLevel;
    correlationId?: string; actions?: Array<{ label: string; onClick: () => void }>;
    autoDismiss?: boolean; duration?: number;
  }
  ```
- **Montaggio:** NotificationProvider nel root layout Next.js
- **Non-blocking:** notifiche toast/snackbar, mai modali

## Implementation Steps
1. Creare `NotificationProvider` con React Context e coda state
2. Creare `useNotification` hook con metodi tipizzati per 4 livelli
3. Implementare logica coda: aggiunta, rimozione, auto-dismiss
4. Montare nel root `layout.tsx`
5. Verificare che i metodi espongono firma tipizzata corretta

## Definition of Done
- [ ] Provider espone metodi per 4 livelli
- [ ] Coda notifiche funzionante
- [ ] Montato nel root layout
- [ ] Firma tipizzata TypeScript
- [ ] Code review approvata
