# TSK-195 — FE NotificationToast wrapper shadcn/ui con WCAG + Correlation ID copiabile

## Context
US-064 richiede toast con Correlation ID copiabile e garanzie WCAG. Il componente wrappa shadcn/ui Toast con semantica accessibile.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-064-notification-service/US-064.md §AC]
[^src: design_&_architecture/decisions/ADR-022-frontend-error-notifications.md §2]

## Technical Specs
- **FE:** `components/notifications/notification-toast.tsx`
- **WCAG roles:**
  - success/info: `role="status"` + `aria-live="polite"`
  - warning/error: `role="alert"` + `aria-live="assertive"`
- **Correlation ID:** click-to-copy badge visibile quando `correlationId` presente
- **Auto-dismiss:** 6s default, 8s per testi > 80 chars, pausa al focus/hover
- **Azioni:** notifiche con azioni non si chiudono automaticamente
- **Tastiera:** Esc chiude la notifica più recente
- **Multi-canale:** icona + colore + testo per ogni livello (info mai solo tramite colore)

## Implementation Steps
1. Creare `NotificationToast` wrapper sopra shadcn/ui Toast
2. Implementare role semantici condizionali per livello
3. Implementare Correlation ID badge click-to-copy (navigator.clipboard)
4. Implementare auto-dismiss con pausa focus/hover
5. Implementare chiusura Esc
6. Icona distinta per livello (success, info, warning, error)

## Definition of Done
- [ ] WCAG roles corretti per livello
- [ ] Correlation ID copiabile (click-to-copy)
- [ ] Auto-dismiss 6s/8s con pausa
- [ ] Esc chiude notifica più recente
- [ ] Icona distinta per ogni livello
- [ ] Code review approvata
