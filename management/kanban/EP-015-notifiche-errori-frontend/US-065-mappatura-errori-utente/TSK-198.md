# TSK-198 — QA Test errorCodeMap: mapping + fallback + nessun HTTP raw

## Context
US-065 AC richiede verifica che tutti i codici sono mappati, fallback funzionante, nessun codice HTTP raw nelle notifiche.
[^src: management/kanban/EP-015-notifiche-errori-frontend/US-065-mappatura-errori-utente/US-065.md §AC]

## Technical Specs
- **QA:** Vitest
- **Scenari:**
  - 8 codici documentati hanno mapping con messaggio user-friendly
  - Codice non mappato → messaggio generico localizzato
  - CTA coerente per tipo errore (riprova, login, supporto)
  - Nessun codice HTTP raw (es. "500", "404") appare nelle notifiche per 5 scenari
  - Stringhe provengono dal file i18n (non hardcoded)

## Implementation Steps
1. Test mapping 8 codici: verifica messaggio e CTA per ciascuno
2. Test fallback: codice inventato → messaggio generico
3. Test anti-raw: simulare 5 errori, verifica assenza HTTP codes nelle stringhe
4. Test i18n: verifica che le stringhe provengono dal file locale

## Definition of Done
- [ ] 8 codici testati
- [ ] Fallback generico verificato
- [ ] Nessun HTTP raw in UI
- [ ] Code review approvata

## Dependencies
- TSK-197 (errorCodeMap + i18n)
