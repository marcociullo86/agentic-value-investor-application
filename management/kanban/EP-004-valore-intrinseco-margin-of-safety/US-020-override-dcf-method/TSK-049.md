# TSK-049 — OpenAPI spec: allineamento contratto ADR-011

## Context

ADR-011 §Conseguenze richiede l'aggiornamento dell'OpenAPI spec per documentare: il nuovo `GET /api/dcf-overrides/{ticker}`, il `422` su `POST /api/dcf-overrides`, il campo `dcfMethodSource` nello schema `RuleEngineResult`, e il header `Vary: Authorization` su `/api/analysis/{ticker}`. L'OpenAPI spec è la fonte di verità per il contract-test drift check (TSK-037).
[^src: design_&_architecture/decisions/ADR-011-dcf-overrides-api.md §Conseguenze]
[^src: design_&_architecture/decisions/ADR-007-api-contract.md §Convenzioni]

## Technical Specs

- **BE (doc):** file `design_&_architecture/api/openapi.yaml`.
- **Modifiche richieste:**
  1. Schema `DcfMethodSource`: nuovo enum `[DEFAULT_POLICY, USER_OVERRIDE]` in `components/schemas`.
  2. Schema `RuleEngineResult`: aggiungere `dcfMethodSource` come campo `required`, `$ref: DcfMethodSource`.
  3. Path `GET /api/dcf-overrides/{ticker}`: aggiungere con responses `200` (schema `DcfOverride`) e `404` (schema `ProblemDetail`).
  4. Path `POST /api/dcf-overrides`: aggiungere response `422` con schema `ProblemDetail` e `extensions` documentati.
  5. Path `GET /api/analysis/{ticker}`: aggiungere header response `Vary: Authorization`.
- Verificare che `DELETE /api/dcf-overrides/{ticker}` documenti già `204` idempotente; se assente, aggiungere.
[^src: design_&_architecture/decisions/ADR-011-dcf-overrides-api.md §1. Endpoints (estensione di ADR-007)]
[^src: design_&_architecture/decisions/ADR-011-dcf-overrides-api.md §3. Flag dcfMethodSource nel RuleEngineResult (AC#1, AC#6)]

## Implementation Steps

1. Aprire `design_&_architecture/api/openapi.yaml`.
2. Aggiungere `DcfMethodSource` in `components/schemas`.
3. Aggiornare `RuleEngineResult` con `dcfMethodSource`.
4. Aggiungere operazione `GET /api/dcf-overrides/{ticker}`.
5. Aggiungere response `422` a `POST /api/dcf-overrides`.
6. Aggiungere header `Vary: Authorization` a `GET /api/analysis/{ticker}`.
7. Eseguire `openapi-generator validate` o equivalente per verificare la sintassi YAML.

## Definition of Done

- [ ] `DcfMethodSource` enum presente in `components/schemas`.
- [ ] `RuleEngineResult.dcfMethodSource` campo required.
- [ ] `GET /api/dcf-overrides/{ticker}` con responses 200, 401, 404 documentate.
- [ ] `POST /api/dcf-overrides` con response 422 documentata (schema ProblemDetail + extensions).
- [ ] `GET /api/analysis/{ticker}` con header `Vary: Authorization`.
- [ ] YAML valido (nessun errore di sintassi).
- [ ] Contract-test drift check (TSK-037) passa dopo aggiornamento.
