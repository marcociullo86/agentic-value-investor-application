# TSK-017 — Flyway migration V007: dcf_method_override

## Obiettivo

Creare la migration per la tabella `dcf_method_override` che persiste l'override
metodo DCF per (user, ticker).

## Scope tecnico

- `V007__create_dcf_overrides.sql`:
  - Tabella `dcf_method_override`: `id UUID PK`, `user_id UUID NOT NULL FK → users(id)
    ON DELETE CASCADE`, `ticker VARCHAR(10) NOT NULL FK → stocks(ticker)`,
    `forced_method VARCHAR(32) NOT NULL CHECK (forced_method IN ('GREENWALD','FCF_FALLBACK'))`,
    `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`.
    [^src: design_&_architecture/data/er-diagram.md §dcf_method_override]
