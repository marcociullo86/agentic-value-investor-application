# TSK-019 — MarginOfSafetyEvaluator + AnalysisController endpoint principale

## Obiettivo

Implementare l'evaluator MoS e assemblare l'endpoint `/api/analysis/{ticker}` che
restituisce il `RuleEngineResult` completo.

## Scope tecnico

- `MarginOfSafetyEvaluator.evaluate(currentPrice, dcfResult)`:
  - Verde se `currentPrice < dcfIntrinsicValue * 0.70`.
  - Giallo se `dcfIntrinsicValue * 0.70 ≤ currentPrice < dcfIntrinsicValue`.
  - Rosso se `currentPrice ≥ dcfIntrinsicValue`.
  - `NOT_CALCULABLE` se `dcfIntrinsicValue == null`.
  [^src: management/kanban/EP-004-valore-intrinseco-margin-of-safety/US-013-margin-of-safety/US-013.md §Business Rules]
- Prezzo corrente da `FmpCacheService.getOrFetchProfile(ticker).price`.
  [^src: design_&_architecture/api/endpoints-overview.md §EP-003+EP-004]
- `AnalyzeTickerService.analyze(ticker)`: pipeline completa (FMP fetch parallelo →
  `FinancialDataset` → `RuleEngineService` → `GrahamNumberCalculator` →
  `DcfCalculator` → `MarginOfSafetyEvaluator` → persisti `RuleEngineResultEntity`).
  [^src: design_&_architecture/components/backend-components.md §Flusso pipeline analisi]
- `AnalysisController.getAnalysis(ticker)`:
  - `GET /api/analysis/{ticker}` → 200 `RuleEngineResult`.
    [^src: design_&_architecture/api/openapi.yaml §/api/analysis/{ticker}]
  - Headers: `X-Data-Snapshot-At`, `X-Data-Stale`.
  - 404 se ticker non esiste in FMP, 503 se FMP down e nessuna cache.
- `RuleEngineResultEntity` persistito via `RuleEngineResultRepository`.
  [^src: design_&_architecture/data/er-diagram.md §rule_engine_result]

## Criteri di completamento (DoD)

- [ ] `GET /api/analysis/AAPL` restituisce 200 con `signals[]` (7 entry), `grahamNumber`,
  `dcfIntrinsicValue`, `mosSignal`, `currentPriceAtEval`.
- [ ] Prezzo < 70% DCF → `mosSignal: "GREEN"`.
- [ ] DCF non disponibile → `mosSignal: "NOT_CALCULABLE"` (non `GREEN`).
- [ ] `RuleEngineResultEntity` trovabile in DB dopo la call.
- [ ] Integration test `AnalysisControllerIT` con FMP mock + Testcontainers.
