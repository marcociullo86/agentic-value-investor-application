# US-011 — Calcolo Graham Number

## Descrizione
Come investitore retail, voglio vedere il Graham Number dell'azienda calcolato sui dati correnti, affinché disponga di una stima rapida del prezzo massimo difensivo come riferimento di confronto. [^src: wiki/concepts/value-investing-rule-engine.md §Calcolo Valore Intrinseco (RF4)]

## Business Rules
- Formula: `Graham Number = sqrt(22.5 * EPS * BVPS)`.
- Si usano EPS e Book Value Per Share dell'esercizio più recente disponibile.
- Se EPS o BVPS sono negativi/nulli il Graham Number è "Non Applicabile" e segnalato come tale.

## UI Reference
[^src: wiki/concepts/value-investing-rule-engine.md §Output del Rule Engine: il "Traffic Light"]

## Acceptance Criteria
- [ ] Per un'azienda con EPS e BVPS validi il sistema restituisce il Graham Number.
- [ ] Se EPS o BVPS sono ≤ 0 il sistema restituisce "Non Applicabile" senza errore.
- [ ] L'output include il timestamp dei dati sorgente.
