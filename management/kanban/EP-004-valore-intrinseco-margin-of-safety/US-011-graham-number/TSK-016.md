# TSK-016 — GrahamNumberCalculator

## Obiettivo

Implementare il calcolatore Graham Number integrato nel Rule Engine.

## Scope tecnico

- `GrahamNumberCalculator.calculate(eps: Double?, bvps: Double?): GrahamResult`:
  - Formula: `sqrt(22.5 * eps * bvps)`.
  - Se `eps ≤ 0` o `bvps ≤ 0` o uno dei due è `null` → `GrahamResult(value=null,
    applicable=false)`.
  [^src: management/kanban/EP-004-valore-intrinseco-margin-of-safety/US-011-graham-number/US-011.md §Business Rules]
- Integrazione in `RuleEngineService.evaluateAll()` → popola `grahamNumber` nel risultato.
  [^src: design_&_architecture/components/backend-components.md §GrahamCalc]
- `RuleEngineResult.graham_number`: `NUMERIC(18,4) NULL` (NULL se Not Applicable).
  [^src: design_&_architecture/data/er-diagram.md §rule_engine_result §graham_number]
- EPS e BVPS presi dall'esercizio più recente disponibile nel `FinancialDataset`.
- `dataSnapshotAt` incluso nell'output (US-011 AC).
  [^src: management/kanban/EP-004-valore-intrinseco-margin-of-safety/US-011-graham-number/US-011.md §AC]

## Criteri di completamento (DoD)

- [ ] EPS 5.0, BVPS 20.0 → `sqrt(22.5*5*20) = 47.43`.
- [ ] EPS -1.0 → `Not Applicable` (valore null, no eccezione).
- [ ] Unit test `GrahamNumberCalculatorTest`: caso valido, EPS negativo, BVPS null.
