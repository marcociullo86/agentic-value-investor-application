# US-088 — Log completo delle interazioni LLM (prompt + risposte)

## Descrizione
Come operatore/sviluppatore, voglio vedere nei log l'intera interazione con l'LLM (system prompt, user prompt e risposta raw) per ognuna delle 11 chiamate Munger (10 query + 1 sintesi) e per la sintesi news, così da poter verificare cosa è stato mandato e cosa ha risposto il modello (oggi appare solo `llmCalls=11`).

## Business Rules
- Logging gated da configurazione `deep-analysis.llm.log-interactions` (default `false` in prod, attivabile via env `DEEP_ANALYSIS_LLM_LOG_INTERACTIONS=true`). Quando attivo, logga a livello INFO/DEBUG.
- Per ogni chiamata logga: contesto (ticker, tipo chiamata = munger-query[N]/munger-synthesis/news-synthesis), system prompt, user prompt, risposta raw, durata ms, token/costo se disponibili da `LlmCostCounterService`.
- Troncamento difensivo dei payload a una soglia configurabile (`max-chars`, default 8000) per evitare bloat dei log.
- Correlazione: usare un id di correlazione (runId) già presente nel MDC dei log per legare le interazioni a un `deep_analysis_run`.
- Nessun dato PII: i prompt contengono solo dati pubblici (filing SEC, news). Rispettare comunque la policy PII logging esistente (ADR-021).

## Acceptance Criteria
- [ ] Con flag attivo, un'analisi `invoke_llm=true` produce nei log le 11 interazioni Munger + la sintesi news con prompt+risposta (troncati).
- [ ] Con flag disattivo (default), nessun prompt/risposta nei log (solo i conteggi attuali).
- [ ] La soglia di troncamento è configurabile e applicata.
- [ ] Le interazioni riportano ticker e tipo chiamata; test unitario verifica l'attivazione del logging gated.
