# TSK-184 — FE Token CSS semantici: colors + typography + shape + tailwind.config.ts

## Context
US-069 richiede un sistema di design token semantici per colori, tipografia e shape, derivati da seed color. ADR-023 decide: shadcn/ui + token M3-aligned sopra CSS custom properties.
`pending_clarification: [Q_004]` — ADR-023 (status: proposed) risolve Q_004 ma non ancora accepted. Si procede con opzione (b) per policy soft.

## Technical Specs
- **FE:** File CSS:
  - `styles/tokens/colors.css` — token semantici OKLCH M3-aligned (primary, secondary, tertiary, surface, surface-container, outline, error, success, warning, info)
  - `styles/tokens/typography.css` — scala display/headline/title/body/label
  - `styles/tokens/shape.css` — corner radius none/small/medium/large/full
- **Tailwind:** estendere `tailwind.config.ts` con token semantici: `colors`, `borderRadius`
- **Seed color:** configurabile — cambiare il seed rigenera tutti i ruoli coerentemente

## Implementation Steps
1. Creare `styles/tokens/colors.css` con variabili OKLCH per tutti i ruoli semantici M3
2. Creare `styles/tokens/typography.css` con scala semantica
3. Creare `styles/tokens/shape.css` con corner radius tokenizzati
4. Estendere `tailwind.config.ts` con mapping CSS variables → classi Tailwind
5. Importare token CSS nel global stylesheet

## Definition of Done
- [ ] File token semantici creati (colors, typography, shape)
- [ ] `tailwind.config.ts` esteso con classi semantiche
- [ ] Cambiare seed color aggiorna coerentemente tutti i derivati
- [ ] Scala tipografica definita (5 livelli)
- [ ] Corner radius tokenizzati (5 valori)
- [ ] Code review approvata
