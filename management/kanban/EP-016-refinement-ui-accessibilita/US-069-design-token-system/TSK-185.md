# TSK-185 — FE Migrazione 5 componenti principali a token semantici

## Context
US-069 richiede che almeno 5 componenti UI principali usino token semantici invece di valori hardcoded.
[^src: management/kanban/EP-016-refinement-ui-accessibilita/US-069-design-token-system/US-069.md §AC]
[^src: design_&_architecture/decisions/ADR-023-design-token-system-shadcn.md §4]

## Technical Specs
- **FE:** Migrazione da classi Tailwind hardcoded (`bg-blue-600`) a classi semantiche (`bg-primary`)
- **Componenti target:** Button, Card, Input, Navigation, Dialog (shadcn/ui wrappers)
- **Tipografia:** uso coerente della scala (display, headline, title, body, label)
- **Shape:** corner radius coerenti (card → shape.medium, dialog → shape.large)

## Implementation Steps
1. Migrare Button: colori primary/on-primary, hover state
2. Migrare Card: surface-container, outline, shape.medium
3. Migrare Input: surface, outline, shape.medium, focus primary
4. Migrare Navigation: surface, on-surface, primary per active
5. Migrare Dialog: surface, shape.large, overlay
6. Verificare coerenza visuale post-migrazione

## Definition of Done
- [ ] 5 componenti migrati a token semantici
- [ ] Nessun colore/radius hardcoded nei 5 componenti
- [ ] Scala tipografica usata coerentemente
- [ ] Corner radius coerenti su componenti simili
- [ ] Regressione visuale verificata
- [ ] Code review approvata

## Dependencies
- TSK-184 (token CSS + tailwind.config.ts)
