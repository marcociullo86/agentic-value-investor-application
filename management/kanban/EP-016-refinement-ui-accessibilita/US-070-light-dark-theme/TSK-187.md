# TSK-187 — FE ThemeProvider + useTheme + dark tokens + anti-FOUC

## Context
US-070 richiede switch light/dark persistente, rispetto prefers-color-scheme come default, e nessun FOUC.
[^src: management/kanban/EP-016-refinement-ui-accessibilita/US-070-light-dark-theme/US-070.md §AC]
[^src: design_&_architecture/decisions/ADR-023-design-token-system-shadcn.md §5]

## Technical Specs
- **FE:**
  - `components/theme/theme-provider.tsx` — React Context + classe `dark` su `<html>`
  - `hooks/use-theme.ts` — hook per toggle + stato corrente
  - `styles/tokens/colors-dark.css` — override token semantici sotto `.dark { }`
  - Anti-FOUC: script inline `beforeInteractive` nel `<head>` che applica classe prima del render
- **Persistenza:** `localStorage('theme')`, sopravvive a reload e logout/login
- **Default:** `prefers-color-scheme` del sistema operativo
- **Pattern:** Tailwind dark mode con classe `dark`

## Implementation Steps
1. Creare `colors-dark.css` con override token per dark theme
2. Creare `ThemeProvider` con logica prefers-color-scheme + localStorage
3. Creare `useTheme` hook
4. Implementare anti-FOUC script in `layout.tsx` con `beforeInteractive`
5. Integrare `ThemeProvider` nel root layout Next.js
6. Aggiungere toggle accessibile da tastiera in navigation

## Definition of Done
- [ ] Toggle light/dark funzionante e accessibile da tastiera
- [ ] Persistenza dopo reload
- [ ] Default da prefers-color-scheme
- [ ] Nessun FOUC al cambio/reload
- [ ] Contrasto WCAG AA in entrambi i temi
- [ ] Code review approvata

## Dependencies
- TSK-184 (token CSS semantici light come base)
