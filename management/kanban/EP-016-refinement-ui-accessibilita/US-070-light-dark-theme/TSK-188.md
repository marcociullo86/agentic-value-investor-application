# TSK-188 — QA Test ThemeProvider: prefers-color-scheme + persistenza + FOUC + contrasto

## Context
US-070 AC richiede verifica default sistema, persistenza, assenza FOUC e contrasto WCAG AA in entrambi i temi.
[^src: management/kanban/EP-016-refinement-ui-accessibilita/US-070-light-dark-theme/US-070.md §AC]

## Technical Specs
- **QA:** Vitest + Playwright
- **Scenari:**
  - prefers-color-scheme: dark → tema dark al primo accesso (no override precedente)
  - Toggle light → dark → reload → tema dark persistito
  - Cambio tema non causa flash visibile (no FOUC)
  - Contrasto testo >= 4.5:1 in light theme (tool misura)
  - Contrasto testo >= 4.5:1 in dark theme (tool misura)

## Implementation Steps
1. Vitest: mock prefers-color-scheme, verifica classe dark applicata
2. Vitest: simula toggle + reload, verifica persistenza localStorage
3. Playwright: navigazione con screenshot, verifica no FOUC
4. Contrasto: axe-core audit su pagina light e dark

## Definition of Done
- [ ] Default prefers-color-scheme verificato
- [ ] Persistenza verificata
- [ ] No FOUC confermato
- [ ] Contrasto AA verificato entrambi temi
