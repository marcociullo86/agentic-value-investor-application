# TSK-189 — FE Token motion + state layer opacità + prefers-reduced-motion

## Context
US-071 richiede stati interattivi con state layers a opacità tokenizzata, transizioni con easing/durate tokenizzate, e rispetto di prefers-reduced-motion.
[^src: management/kanban/EP-016-refinement-ui-accessibilita/US-071-stati-interattivi-motion/US-071.md §AC]
[^src: design_&_architecture/decisions/ADR-023-design-token-system-shadcn.md §6]

## Technical Specs
- **FE:** `styles/tokens/motion.css`
  - Easing: `--motion-easing-emphasized`, `--motion-easing-standard`
  - Durate: `--motion-duration-short` (150ms), `--motion-duration-medium` (300ms), `--motion-duration-long` (500ms)
  - State layers: `--state-hover-opacity: 0.08`, `--state-focus-opacity: 0.12`, `--state-pressed-opacity: 0.16`
  - `@media (prefers-reduced-motion: reduce)` → tutte le durate a 0ms
- **Focus visibile:** sempre presente, mai rimosso senza alternativa (SC 2.4.11/2.4.13)

## Implementation Steps
1. Creare `styles/tokens/motion.css` con easing, durate, state layer opacità
2. Implementare media query `prefers-reduced-motion: reduce` che azzera durate
3. Applicare state layers ai componenti interattivi (button, link, input) come overlay opacity
4. Verificare focus visibile su tutti gli elementi interattivi

## Definition of Done
- [ ] Token motion definiti (easing, durate, state layers)
- [ ] prefers-reduced-motion → durate 0ms
- [ ] State layers con opacità tokenizzata (non colori hardcoded)
- [ ] Focus visibile sempre presente
- [ ] Code review approvata
