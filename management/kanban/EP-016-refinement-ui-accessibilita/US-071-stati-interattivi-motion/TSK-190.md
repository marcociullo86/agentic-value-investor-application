# TSK-190 — QA Test motion: reduced-motion + state layers + focus visibile

## Technical Specs
- **QA:** Vitest + Playwright
- **Scenari:**
  - prefers-reduced-motion: reduce → durate <= 100ms su 3+ componenti animati
  - State hover/focus usano opacità tokenizzata (non colori diversi hardcoded)
  - Transizioni usano easing/durata da token (non valori inline)
  - Focus visibile presente su ogni elemento interattivo in navigazione tastiera

## Implementation Steps
1. Vitest: verifica CSS computed con prefers-reduced-motion → durate 0ms
2. Vitest: snapshot state layer hover/focus verificando opacity token
3. Playwright: navigazione tastiera, verifica outline focus su 5+ componenti
4. Verifica assenza valori di transizione inline nei componenti
