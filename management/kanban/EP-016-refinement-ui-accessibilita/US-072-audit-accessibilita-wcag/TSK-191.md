# TSK-191 — FE Audit e fix WCAG 2.2 AA baseline su tutte le viste

## Context
US-072 richiede conformità WCAG 2.2 AA su tutta l'applicazione: contrasto, target touch, focus, tastiera, heading, form labels, alt, zoom.
[^src: management/kanban/EP-016-refinement-ui-accessibilita/US-072-audit-accessibilita-wcag/US-072.md §AC]
[^src: design_&_architecture/decisions/ADR-023-design-token-system-shadcn.md §7]

## Technical Specs
- **FE:** Audit e fix su tutte le viste principali (login, dashboard, analisi, deep analysis, top picks, watchlist, screener, profilo)
- **Criteri:**
  - h1 unico per vista, no salti heading
  - Focus visibile su tutti gli elementi interattivi (SC 2.4.11/2.4.13)
  - `<label for>` o `aria-label` su tutti i form input
  - `alt` semantico su immagini informative; `aria-hidden="true"` su decorative
  - Target touch >= 24x24 CSS px
  - Zoom 200% senza loss of content o scroll orizzontale
  - Contrasto testo >= 4.5:1, UI components >= 3:1
  - Tastiera: tutte le interazioni completabili, ordine tab logico

## Implementation Steps
1. Eseguire axe-core su ogni vista, catalogare issue
2. Fix heading hierarchy: un solo h1 per vista
3. Fix form labels: aria-label/labelFor dove mancante
4. Fix alt immagini e aria-hidden icone decorative
5. Fix target touch size dove < 24x24
6. Verifica zoom 200% e fix layout overflow
7. Verifica contrasto con token semantici

## Definition of Done
- [ ] h1 unico per vista su tutte le pagine
- [ ] Focus visibile su tutti gli interattivi
- [ ] Form labels corretti
- [ ] Alt e aria-hidden corretti
- [ ] Zoom 200% senza issue
- [ ] Contrasto AA rispettato
- [ ] Code review approvata
