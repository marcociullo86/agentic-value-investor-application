# TSK-193 — QA Test E2E accessibilità tastiera + screen reader

## Context
US-072 AC richiede flussi critici completabili senza mouse e annuncio corretto con screen reader.
[^src: management/kanban/EP-016-refinement-ui-accessibilita/US-072-audit-accessibilita-wcag/US-072.md §AC]

## Technical Specs
- **QA:** Playwright
- **Test tastiera:** flussi critici completabili da sola tastiera:
  - Login → navigazione → analisi ticker
  - Deep analysis → risultati
  - Top picks → filtro → navigazione dettaglio
  - Watchlist → aggiunta/rimozione
- **Screen reader:** verifica annuncio heading, form label, risultati analisi
- **Zoom:** zoom 200% su tutte le viste senza loss of content

## Implementation Steps
1. Test Playwright tastiera: login flow senza mouse
2. Test Playwright tastiera: analisi ticker flow
3. Test Playwright tastiera: top picks + filtro
4. Test Playwright tastiera: watchlist
5. Verifica screen reader (checklist manuale documentata)
6. Test zoom 200%: screenshot comparison

## Definition of Done
- [ ] 4 flussi critici completabili senza mouse
- [ ] Checklist screen reader documentata e verificata
- [ ] Zoom 200% senza issue
- [ ] Code review approvata
